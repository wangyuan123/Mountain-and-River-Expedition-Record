军情终端排版 (Modern Clean Text-SLG)

⚡ 重构设计特性与战术主动权

• 极致信息密度：单行卡片高度严格压至 38~44px，一屏可展示 6~8 条军情无需滚动翻页。
• 字符级视觉元素：状态 Badge（[敌袭!]、[侦察]、[出征]、[返航]、[驻防]）与纯文本微型进度条（[■■■■■■■□□□] 75%）。
• 🎯 出城拦截战术主动权：点击侦查卡片下方高亮 [出城拦截] 按钮，即刻进入截击出征界面！支持选配空军战斗机（野马P-51）或防空装甲车（猎鹿犬防空型）出城迎击，根据敌机航程与我方航速动态求解相向迎面相遇拦截点并在大地图生成截击行军；部队抵达拦截空域后发生空战交火，成功击落瓦解敌军情报后掉头返航，返城后安全入库归建！
• 📢 一键呼叫救援：点击卡片或展开情报上的 [呼叫救援]，将当前可见军情（侦查或敌袭）以求援战报分享到军团，成员点击后在弹窗查询与来袭详情一致的情报；支持快捷键 S 紧急呼救。情报以分享时为准。
• 🛡️ 单城/全城护盾与钻石消耗：点击敌袭卡片 [开罩]，弹出城防护盾系统！支持勾选单个城市或一键全选所有城市开启护盾（8小时/城），按所选城市数量精准扣除对应钻石（💎 200/城），已生效护盾自动顺延叠加！
• 保留经典快捷键位与极速响应：支持键盘快捷键 0 返回大厅、R 刷新信号、S 一键呼救、1~4 快速切换过滤标签。
• 操作闭环点触即发：[开罩] [布阵] [呼叫救援] [出城拦截] [电子干扰] [⚡加速50%] [召回] 均为直接触达。
