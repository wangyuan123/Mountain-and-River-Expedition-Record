# 新手资源与阶段补给设计

日期：2026-10-29。目标：为初期建设、基础科研、首次扩军与操作试错提供启动资金，以真实行动和毕业奖励衔接后续发展。

## 数量与发放时机

## 累计口径

完成引导并领取上述两封资源邮件，累计发放粮、钢、油、稀各140000，黄金160000，钻石150。

初始仓库仍有黄金箱2个（各50000黄金）、资源箱2个（各粮钢油稀50000）。全部打开后，累计发放四类基础资源各240000、黄金260000。

累计发放不是最终余额：未扣建设、科研、生产、行军和战损等费用，未计自然产出、野地收益、日常签到、VIP0免费军饷、主线、探索及付费商品。

## 发放与兼容约束

- 沿用账号锁与现有领取回执；阶段补给和毕业奖励自动到账，邮件附件需主动领取。
- 跳过仍一次性结清未领的三次阶段补给；不伪造成果，不发50000毕业奖励、100钻石毕业奖励或完成礼包邮件。重复跳过不重复发放。
- 引导资源仍写入主城；邮件仍遵循现有附件领取规则。前端从服务端读取奖励数值，不另设一套展示配置。
- 初始化只对新角色初始化生效，不重置现有角色余额；既有角色尚未领取的引导奖励按新配置结算，已领取部分不补差额、不重发。
- 已生成邮件保留原附件；后续新生成的两封资源邮件各10000黄金。旧版同来源完成礼包继续被视为已发放。
- 沿用永久完成邮件回执，重复完成、并发请求以及领取后删信均不能重新生成礼包。
- 本次不更改科研费用、生产消耗、自然收入、初始箱子、商城价格及其他礼包。

## 验证与后续观察

回归覆盖真实新角色初始化、八步建设科研侦察首战流程、每阶段五类资源到账、毕业奖励、两封邮件合计20000黄金、跳过与并发幂等、旧邮件兼容及重复领取拒绝。

上线后重点观察首日基础扩军和一次小规模战损恢复是否可持续、钢铁和人口是否成为过早瓶颈，以及启动资金耗尽后的黄金收入能否承接二级科研。观察结果再用于独立调整持续经济，不在本次同步提高全部奖励。
