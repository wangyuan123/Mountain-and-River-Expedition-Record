# 兵种微调：火箭、特种兵与最低火力

历史规则：`balance-v5-positive-20260918`。当前配置见 [v6兵种比例调整](BALANCE_RATIOS_20260918.md)，本文件保留v5记录。本轮基于 [v4 自主数值设计](INDEPENDENT_BALANCE_20260918.md) 微调，不采用其他游戏的具体数值。代码已实现到本地，未部署。

## 调整内容

| 项目 | v4 | v5 | 幅度 |
| --- | ---: | ---: | ---: |
| 火箭射程 | 440 | 520 | +18.2% |
| 火箭对地攻击 | 40 | 48 | +20% |
| 特种兵对工事攻击 | 69 | 104 | +50.7% |
| 全部兵种和城防原先为零的攻击项 | 0 | 1 | 最低基础火力 |
| 火箭对特种兵专项倍率 | 0.75 | 0.6 | 保留渗透反制 |

火箭增强后在一组等加权资源、同成长的 NPC 距离场景中，特种兵反制胜率曾降至 22/64；将火箭对特种兵专项倍率调至0.6后，全部136个经济对照场景恢复64/64胜。火箭对其他目标的专项倍率不变，既保留对地增强，也避免同时抹去特种兵的反炮兵职责。

“所有攻击为正值”覆盖17个兵种及4种城防的全部84项攻击。后勤和侦察单位仍不主动冲锋，卡车、运输机仍为接触距离自卫（射程0）；最低火力不意味着能在任意距离开火，也不保证每次微量伤害都击毁单位。潜艇仍以对海为主，其他攻击仅为1。

## 推导与结算

继续使用原自主推导公式：`攻击 = max(1, round(目标有效生命 × 攻方加权造价 / (目标加权造价 × 理想齐射轮数 × 专项倍率)))`。

- 火箭对地参考重坦，理想齐射轮数由8改为20/3，推导得到48。射程增加80，即基础移动步长200的0.4倍，扩大先手窗口。
- 特种兵攻坚参考榴弹炮，理想齐射轮数由3改为2，按既有反炮兵×2推导得到104。对碉堡使用104，对火炮工事再乘既有专项倍率2。
- 原来的空能力配置 `null` 改为显式 `baseline: true`；统一使用 `minimumAttack: 1`。这些是弱项基础火力，不将其伪装成主武器齐射效率推导结果。
- 每个兵种一次行动仍共享攻击额度，切换领域读取新目标对应攻击。例：100门火箭击毁1个步兵耗0.5份额度，剩99.5份对战斗机只能使用对空1，造成约52.37伤害，不继承对地48。
- 所有正值攻击都进入真实结算；科技和技能继续按相同规则作用，不能把弱项替换为主炮。结算中用于无效或未来零攻击配置的过滤仍保留，但当前配置不会因领域攻击为零而无法攻击。
- 步兵现在可以对射程内飞机使用微弱防空火力；原先“略过无法攻击的飞机”不再适用。卡车、运输机相距很远且双方均不主动前进时，仍会待命至30回合撤退。

输入：[attack-design.json](balance/attack-design.json)。只读复现：`node scripts/balance/derive-attacks.cjs`，输出并核对以下完整攻击表。

## 验证与发布边界

本轮复核主要克制矩阵（17组、5种预算、2档距离、2档成长、32种子、互换攻守），共21,760场。136个等资源/等加权资源场景均为64/64全歼胜；每个直接战斗兵种仍有等资源反制。攻坚和护航场景也重新运行。该结果不代表任意成长差、混编和长期经济都已平衡。

新增/更新的结算验证覆盖：全部21个单位/工事实际攻击四类目标；火箭弱对空接受科技技能后仍使用自身攻击值；从对地切到对空、对海切到对地、后勤切到攻坚时不继承主武器火力；特种兵对四类工事的强化；运输机接触自卫；更远的火箭射程；后勤远距待命。

前后端配置、定位文字、战报版本和静态缓存版本已同步。现有兵力、资源和历史战报不迁移；部署后的战斗（包括到达的在途部队）使用新规则。本轮未部署或重启服务。
