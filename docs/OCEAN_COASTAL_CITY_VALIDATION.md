# 海洋与沿海建城实施验收

完成日期：2026-09-14。方案：`docs/OCEAN_COASTAL_CITY_PLAN.md`。

## 已实现

- 世界记录保存 40,000 格海陆数据，启动首次生成后持久化；无雪地背景。基础海域占比 23.4625%，加入旧地物保护后，本机实际占比 22.6425%（9,057 格）。
- 东部海洋、东南海湾、半岛与小岛；深浅海水、沙岸过渡、可见区域轻量波纹，草木避开海岸和水面。保留现有触控、倾斜画布与分块纹理缓存；减少动态效果设置下波纹静止。
- “海岸”按钮定位最近的四格沿海陆地，避让当前已加载的据点；服务端进一步检查尚未加载的占地。点击空地或按坐标定位可打开 2×2 预览，绿色可建、红色不可建，显示费用、工期及原因。
- 沿海空地按坐标自由建城；保留占领森林/丘陵建城方式。两种入口都校验 2×2 陆地、边界、军衔名额、资源和地图占用，旧野地建城还校验领地归属与未完成行军。
- 世界行锁和占地当前读共同保护并发建城；后者避免 MySQL REPEATABLE READ 下等待锁前建立的旧快照漏读新城市。新玩家出生避开海水及完整城市占地。
- 新城市建设港口需临海；已有港口可继续升级。旧内陆玩家城市保留海军补给连接，距离计入航程，标记为“海路（含旧城补给段）”。
- 舰队从港口城市沿连通海域寻路，攻击临海目标；运输/调遣可前往己方有港口或旧通行资格的城市。陆军沿陆地寻路，隔海陆军需运输机运力，每架 80，按陆军人口扣除运力；运输编队可携舰队同行护航。
- 出征准备与跨城运输显示服务端路线、距离、时间、可携资源及陆军占用运力。实际行军线路保存至行军记录，地图按折线路径显示，返城沿原路反转；原有在途行军保持原时间。
- 出征失败保留兵力配置，避免路线校验失败后重新输入；提交时防止连续点击重复发送。

## 接口

- `GET /api/game/world/map/terrain`：版本、世界大小、海陆字符串与海域格数。
- `GET /api/game/cities/site?x=…&y=…`：选址结果与费用、工期；预览不扣资源。
- `POST /api/game/cities`：原 `wildId/name` 或新 `x/y/name`，建城统一校验。
- `POST /api/game/world/route`：按实际可用兵力计算路线与预计时间，不扣资源、不派兵。
- 城市列表/详情增加 `coastal/legacyNaval`；己方行军增加 `route/routeMode`。

## 当前边界

- 旧内陆舰队的补给连接是兼容通道，不是地图上新增的河流；新的内陆城市不获得该资格。
- 首版运输能力使用运输机，护航通过运输编队混编实现，没有新增独立护航/拦截任务或运输船。
- 运力在出发时校验；战斗伤亡后沿用原结算与返程规则，没有新增部队因运输机损失而滞留的机制。
- 地形保护针对升级时已有资产和正常建城/出生流程。旧的管理用全世界重建、旧格式全量导入不属于本次迁移流程；使用这些操作前应另行备份并验证地形兼容，不能代替数据库备份恢复。
