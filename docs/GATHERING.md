# 资源野地采集模式

2026-09-26。已占领资源地的“派兵采集”进入采集出发准备界面，可选择：

- **采集全自动**：采集完成后自动收获并自动按原路线回城。默认选择，旧任务和未传模式的客户端继续使用此模式。
- **采集全手动**：需要玩家自主终止采集任务，需要亲自下达命令选择部队回城。采满后部队仍留在野地；玩家先点“终止采集”，再对该支部队点“部队回城”。

从新手指引“派出采集队”进入出征界面时，默认选中全自动，全手动选项置灰禁用，提交也固定为全自动，确保资源自动返城入库后继续指引。普通采集仍可自行选择模式。

部队到达野地并开始采集后，野地模型顶部显示“采集剩余 分:秒”，每秒更新；同一野地多队采集时显示队数和最晚完成的剩余时间。驻军采集也显示倒计时。到点显示等待自动返城或等待收获；出征途中、已终止或返程中的部队不显示采集倒计时。

军情页、地图野地详情和我的领地列表均提供每支采集部队的状态与手动操作。提前终止按实际采集时间向下取整保留收获；终止后不继续累积、不重新开启采集，也不自动回城。返程使用出发时的路线逆序和单程时长，抵达出发城市后才归还部队、释放随军军官并入库资源。野地归属不会因终止或返城而改变。

## 已有驻军的“采集 → 收获”入口

地图详情和“我的领地”列表点击“采集”后，先打开驻军采集准备弹窗，同样提供以上两种模式和完整说明，默认选中全自动。取消弹窗不会开始任务。

- **全自动**：显示自动采集状态，不提供手动“收获”按钮。采满后服务端自动收获，创建有实际行军时间的返城任务；即使当前没有其他行军也会推进。
- **全手动**：保留“收获”按钮。可提前收获并按实际采集时间结算，采满也不会自动终止。点击“收获”后驻军和资源仍留在野地，入口改为“部队回城”；玩家再次下达命令后才出发。
- **结算和归属**：收获时只扣减野地资源，部队抵达各自出发城市后才归还兵力、入库资源并触发采集任务进度。重复收获不重复计量，撤军不会放弃领地。采集中或收获待返城时不能再次开启驻军采集，也不能直接放弃领地绕过结算。
- **返城路线**：记录各批驻军的进驻路线、出发城市和单程时长；返城时逆序使用原路线。多个城市的驻军分别返城，按运载能力分配收获。已有历史驻军没有可恢复的原路线时，以开始采集的城市规划并保存兼容路线；升级前已在采集的旧任务使用主城兼容路线。
- **兼容性**：升级前的驻军采集和未传模式的旧驻军客户端保留手动模式，不会突然自动撤军。这与旧“派兵采集”默认自动的规则分别处理。

驻军入口沿用 POST /api/game/wild/gather，提交 wildTileId 和 gatherMode（auto / manual），不传 army。手动收获沿用 /harvest，下达返城命令沿用 /recall。驻军采集的模式、启动城市、待返城收获量及分批进驻路线由 V49__stationed_gather_modes.sql 持久化；地图详情仅向领地主人返回采集状态。

出征接口增加可选的 `gatherMode`（`auto` / `manual`）。全手动终止使用 `POST /api/game/world/stop-gather`，请求体为 `{ "marchId": 行军ID }`；终止后通过既有的 `cancel-march` 接口下达原路回城命令。模式、实际采集起始时间和已终止状态持久化到行军记录，数据库升级使用 `V48__march_gather_modes.sql`。
