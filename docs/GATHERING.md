# 资源野地采集模式

初版：2026-09-26；手动采集统一更新：2026-10-23。

派兵采集和驻军采集均只保留手动流程，不再提供模式选择或采集后自动废弃配置。

1. 玩家确认派兵采集，部队到达后按本次指令采集；已有驻军由玩家点击“采集”并确认开始。
2. 本队达到负重或本次可采资源上限后停止增长，部队仍留在野地，等待玩家点击“收获”。玩家也可提前收获，按实际采集时间向下取整保留采量。
3. 收获只结束采集并结清野地消耗，部队与货物留在野地，不自动回城、不恢复采集。玩家必须再点击“部队回城”。
4. 部队按出发路线逆序和原单程时长返城，抵达出发城市后才归还兵力、释放随军军官并入库资源。返城不改变野地归属。
5. 放弃野地必须由玩家另行确认；采集中或已收获待命的任务须先下达回城命令，不能通过放弃绕过采集结算。

未开启采集的普通驻军随玩家确认放弃野地创建返程行军，沿各批驻军的原路线返回各自出发城市，抵达后才归还兵力，不能立即增加城内兵力。历史驻军缺少路线时按领地所属城市补全返程，不受当前选中城市影响；野地立即恢复中立不影响已经创建的返程队伍。

大地图与领地列表统一隐藏存在未召回采集任务的野地废弃入口，包括去程、采集中、采满待收获、已收获待回城；下达回城命令后恢复入口。旧页面和直接接口请求仍由服务端拦截，并分别提示“尚未收获”“已收获并留守”“采集部队尚未召回”，避免在已收获后仍称“正在采集”。同一野地有多支队伍时，必须对所有采集队伍下达回城命令；历史未结算返程继续阻止废弃。

军情页、地图野地详情和我的领地列表均提供每支任务的状态与手动操作。采集剩余时间和累计时长继续每秒更新；采满显示“待收获”，收获后显示“等待回城命令”。同一野地多队采集时显示队数和最晚完成的剩余时间。出征途中、已终止或返程中的部队不显示采集倒计时。

本人资源野地的地图详情始终展示剩余资源数量，采集中按实时估算同步更新；资源耗尽时也显示“剩余资源：0”和“资源已耗尽”。有空闲驻军时保留“采集”入口，剩余为零则禁用；采集中与已收获待返城分别展示“收获”和“部队回城”，不能重新开始采集。

新手指引与普通采集使用同一套手动流程，任务在资源实际返城入库后才完成。关闭页面、离线、切换城市或重复 Tick 均不会替玩家执行收获、回城或放弃。

## 历史任务与升级（2026-10-23）

`V119__manual_gather_only.sql` 将既有派兵及驻军采集改为手动，未执行的自动废弃配置取消并恢复保留。保留采集起止时间、已采货物、兵力及路线，采满任务不重新计时；已经开始返程的队伍继续实际返程，不重置或重复入库。

服务端已移除自动推进分支，历史 `auto` 字段也不能触发收获、回城或放弃。历史自动废弃设计仅留作变更记录，见[已废止方案](WILD_GATHER_AUTO_ABANDON_DESIGN_20261022.md)。

## 采集速度与时长（2026-10-22）

- 派遣采集与驻军采集的基础速度统一为 **100资源/秒**。本次采集量为野地剩余资源与部队负重上限两者中的较小值；满负重后本次任务结束，不会继续累计。
- 派遣部队采集叠加本次出征军官的后勤属性：`采集速度倍率 = min(3, 1 + 后勤 / 100)`。时长为 `max(60秒, ceil(本次采集量 / (100 × 采集速度倍率)))`；没有随队军官时倍率为1。
- 驻军采集没有关联随队军官，不享受后勤加成。时长为 `max(30秒, ceil(本次采集量 / 100))`。
- 以1,200万资源为单次采集量，派遣队满后勤（倍率×3）时纯采集时长约 **11小时6分40秒**，不含往返行军；驻军按基础速度采集约 **33小时20分**。单次负重不足时，实际需要多次采集，另计往返与重新派遣时间。
- 速度仅在采集任务开始时用于计算并保存结束时间；调整前已开始的任务不重新计时。

## 采集进度与实时展示（2026-10-22）

大地图野地详情和列表地图的本人资源领地卡片共用 `Game.wildGatherProgress`，展示剩余资源、`已采集：已采量 / 野地总资源量` 和采集进度条。进度条总长度固定对应野地总资源量，不以本次部队负重或本次计划采集量作为分母。

- 采集中按服务端最新可采储量与当前任务的实时估算量展示进度；收获后分别展示“已收获：实际数量”和“剩余资源：最新数量”。已收获货物已结算过野地消耗，不能再次从剩余量扣减；混合队伍分别显示已收获量与仍在采集的估算量。界面估算不会提前给玩家入库资源。
- 每支队伍按服务端核定的本次采集量和起止时间估算进度，核定量已受负重和可采资源限制。达到本次负重上限后，该队数量、进度和累计采集时长均停止增长；野地仍有资源时进度条可以不足100%。其他尚未采满的队伍仍独立推进，野地汇总量可以继续增长。
- 倒计时到点后切换为采满、达到负重上限、等待手动收获等状态，不继续显示负数。停止、收获及返程以服务端状态和结算为准。
- 列表地图每秒原位更新数量、剩余量、进度条、采集倒计时和累计时长，保留卡片展开与滚动位置；重新渲染时替换旧计时器，离开列表或切换大地图后停止。大地图详情和图上采集倒计时也按秒更新。
- 大地图详情只保留一份野地资源汇总面板；每支派兵采集任务分别显示状态和操作，避免重复插入同一份采集进度。
- 已收获待回城时保留实际货物数量（包括0），隐藏已结束的采集进度条，按钮切换为“部队回城”。即使野地数据未变化，只要独立队伍的阶段或货物变化，也会刷新详情；野地重新占领后的储量以最新接口数据为准，不在前端用旧任务货物追溯扣减。

所有显示均读取统一游戏时间 `Game.gameNow()`；服务器时间同步、失联和停服时的推进规则遵守[时间与结算](DESIGN.md#时间与结算)，不另设浏览器本地采集时钟。

## 累计采集时长与时间格式（2026-10-22）

采集中增加 `累计采集：时长`，让玩家知道本次已经实际采集多久。派兵采集在军情、列表地图和大地图详情的各支任务状态中展示；驻军采集在列表状态和大地图资源面板中展示。多队分别计时，不把各队时长相加，也不在同一详情中重复显示同一队的累计时长。

累计时长按 `max(0, min(当前游戏时间, gatherEndAt) − gatherStartAt)` 计算，取已完成的整秒。不包含去程、返程以及采满后的留守等待时间；未来开始时间显示0秒，缺少有效开始时间的历史记录不推测时长。去程、已终止和返程状态不继续展示滚动累计计时。

展示复用 `Game.formatDuration`，仅省略前导零单位，最高有效单位之后的零单位必须保留，数字不补零：

| 时长范围 | 展示示例 |
| --- | --- |
| 满一天 | `2天3小时4分钟5秒`、`1天0小时0分钟0秒` |
| 不满一天、满一小时 | `3小时4分钟5秒`、`1小时0分钟0秒` |
| 不满一小时、满一分钟 | `4分钟5秒`、`1分钟0秒` |
| 不满一分钟 | `5秒`、`0秒` |

累计时长通过 `Game.formatGatherElapsed` 向下取整到秒，剩余倒计时仍向上取整到秒。此次格式统一不修改采集起止时间、采集速度、负重限制、完成时点或资源结算逻辑。

## 已有驻军的“采集 → 收获”入口

2026-10-08 起，征服野地前可选择“征服成功后操作”：默认“自动撤军”保持胜利后返城；选择“占领目标”则将战后幸存部队直接转为野地驻军。这类驻军与通过“派遣进驻”送达的部队使用同一套采集和撤军入口。两种选项都保留野地归属，战败仍返程；具体接口、结算与已知缺口见 [野地征服与战后驻军](DESIGN.md#野地征服与战后驻军2026-10-08)。

选择“占领目标”不会自动开启采集，玩家需要另行点击“采集”。尚未开启采集时可直接通过野地撤军入口下达回城命令；开始采集后按下述手动规则处理。征服留守时保存原出发城市、路线、单程时长与幸存兵力，供后续采集结束或手动撤军使用；随军军官在转为驻军时已恢复空闲。

地图详情和“我的领地”列表点击“采集”后，先打开手动采集准备弹窗，说明收获、回城和放弃均需分别操作；取消弹窗不会开始任务。

- **手动收获**：可提前收获并按实际采集时间结算，采满也不自动收获。收获后驻军和资源仍留在野地，入口改为“部队回城”。
- **结算和归属**：收获时只扣减野地资源，部队抵达各自出发城市后才归还兵力、入库资源并触发采集任务进度。重复收获不重复计量，撤军不会放弃领地。采集中或收获待返城时不能再次开启驻军采集，也不能直接放弃领地绕过结算。
- **返城路线**：记录各批驻军的进驻路线、出发城市和单程时长；返城时逆序使用原路线。多个城市的驻军分别返城，按运载能力分配收获。已有历史驻军没有可恢复的原路线时，以开始采集的城市规划并保存兼容路线；升级前已在采集的旧任务使用主城兼容路线。

## 接口约束

派兵采集仍使用出征接口，`gatherMode` 省略或传 `manual`；兼容字段 `gatherAfterAction` 省略或传 `retain`。显式 `auto`、`abandon` 或其他无效值在扣兵、占用军官和创建任务前被拒绝。手动收获使用 `POST /api/game/world/stop-gather`，请求体为 `{ "marchId": 行军ID }`；随后通过 `cancel-march` 单独下达原路回城命令。

驻军开始采集沿用 `POST /api/game/wild/gather`，提交 `wildTileId`，`gatherMode` 省略或传 `manual`，不传 `army`；手动收获沿用 `/harvest`，下达返城命令沿用 `/recall`。旧页面显式提交 `auto` 将提示刷新，不会继续自动流程。模式、采集起止时间、收获与待回城状态继续持久化；地图详情仅向领地主人返回采集状态。

## 资源储量与等级体系（2026-10-03 升级）

- **200 倍储量平衡**：野地初始资源储量由原先的 `等级 × 800` 统一放大 200 倍至 `等级 × 160,000`（1 级 160,000，8 级 1,280,000，30 级 4,800,000）。
- **1~30 级全体系**：生成等级范围由 1~8 级全面扩展至 1~30 级。
- **第 Ⅱ 象限资源高地**：大地图第 Ⅱ 象限（X: 200~399, Y: 0~199）投放四类资源野地共 13,200 块（每类 3,300 块：1~20 级各 120 块、21~25 级各 100 块、26~30 级各 80 块），支持玩家跨大陆调度大载重部队进行深度采集。
