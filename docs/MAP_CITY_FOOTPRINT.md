# 城市与据点占地规则

当前规则（2026-10-11）：玩家城市（主城、分城及其他玩家城市）的地图图像与点击范围为 2×2 格；NPC 城市（含模拟 NPC）、日寇据点、流寇、海上编队和野地统一为 1×1 格。玩家城市使用 D 款港口模型，NPC 使用选定 B 款要塞，七类野地各用对应模型。下文带日期的章节保留历史调整记录，当前占地规则以本节为准。

以目标原坐标作为占地左上角，靠近世界右边界或下边界时按对应占地尺寸向内对齐。玩家城市保证四格展示完整落在世界内，单格目标使用自身格中心。模型随地图比例缩放，选中框、名称、状态和行军线连接点使用统一的显示中心。主城按钮定位城市显示中心；坐标查询支持查询玩家城市扩展的格子。跨区块或视口边缘也会保留相交城市。

2026-10-13 更新：当前世界为 800×800，四大战场各占 400×400，全部开放目标加载、选址、传送及符合海陆空规则的行军；下文 2026-10-03 的封闭象限和旧尺寸仅为历史记录。城市传送要求四格完整位于所选战场内且均为空闲陆地，不能跨越中轴或世界边界；显示时的向内对齐不能使非法传送坐标通过。完整范围和条件见 [四大战场地图与城市传送](FOUR_QUADRANTS_MAP_DESIGN.md)。

NPC 城市、据点、流寇和海上编队的生成、刷新与占地冲突修复按单格检查。NPC 外围一格构成 3×3 布点禁区，防止 NPC／流寇紧连；间隔不属于实际占地，资源野地按单格校验当前批次预留的占位。分块密度选点必须同时满足这些约束。

这是地图显示与点击范围调整。服务端城市坐标、建城条件、领地归属及行军距离计算保持原有规则，不删除相邻地块；旧 NPC 与据点冲突按下述维护规则迁移。如果现有单格目标与城市图像重叠，该目标显示在上层并优先响应其自身格子的点击，剩余城市区域可继续打开城市详情。

验证：地图原有 7 项测试和新增布局 5 项测试通过，涵盖四角命中、地图边缘、重叠目标、不同缩放及跨区块显示。浏览器演示数据验证：城市明显大于单格 NPC/野地、点击城市右下角打开正确详情、查询 (101,101) 找到坐标 (100,100) 的城市、主城定位和放大后显示正确。

## 2026-09-14 斜向网格

地图改用 2:1 菱形投影：世界 X 轴对应屏幕向右下 `(1, 0.5)`，世界 Y 轴对应屏幕向左下 `(-1, 0.5)`。底图、细节地形、网格、占地边框、选中框及行军端点共用这一投影；点击、拖动、缩放锚点使用逆变换，视口范围按屏幕四角反算，北方向显示为右上。

原有地图图标的灰色背景已提取为独立透明底 `*-map.webp`，详情页保留原图。转换脚本在 `output/map-projection/prepare-cutouts.py`。城市和部分野地旧原图本身的地面视角并不一致，透明底处理只去底，不会改变其原始透视；玩家港口城另行生成与网格匹配的新版。

自动验证覆盖斜向四格命中、菱形外接框空角不命中、拖动位移、缩放锚点、世界边界与跨区块可见范围。浏览器演示数据中已验证主城点击能打开坐标 `(100,100)` 的详情。

## 2026-09-16 投影方向与倾角优化

地图菱形投影调整：世界 X 轴对应屏幕向左下 `(-1, 0.5)`，世界 Y 轴对应屏幕向右下 `(1, 0.5)`。
CSS 视口 3D 俯视透视倾角由 `rotateX(11deg)` 降低至 `rotateX(5deg)`，减小偏向东南的倾斜后仰拉伸感，使大地图地表更加平稳开阔。
点击、框选、拖拽反算及自动化测试套件同步更新并通过。

## 2026-09-16 取消斜向偏移

主地图统一为上北下南、左西右东：世界 X 轴仅对应屏幕水平方向 `(2, 0)`，世界 Y 轴仅对应屏幕竖直方向 `(0, 1)`，保留原先每格的屏幕宽度与深度。取消 CSS 透视倾斜和 1.03 倍放大，以及城市额外的 1.1025 倍高度拉伸。建筑沿用现有正立素材，朝画面下方即为地图南方。

底图、网格、建筑中心、选中框和行军路线继续使用同一相机投影与逆变换；点击建筑可见像素或其归属铭牌打开相应目标。全屏横竖屏转换仍通过画布四角反算。测试覆盖四个方位、缩放、占地边缘与地图边界。

## 2026-10-06 旧据点占地冲突修复

NPC 人口维护及日寇动态平衡维护检查已有目标与新生成目标的完整占地：NPC 城市一格，流寇四格（2026-10-08 调整）。发生重叠、越界、地形不符或 NPC 间隔不足时，迁移到同类地形的空闲位置；保留 ID、名称、等级、军官、守军损失与击败状态。占用计数确保移除自身预留不会释放其他重叠目标。已有行军引用的目标暂不迁移；没有合适位置时留待后续维护。

## 2026-10-08 NPC 城市单格占地

NPC 城市（`npc`、`simulated_npc`）改为 1×1 格。地图模型宽度、选中框、点击范围、名称与行军线连接点使用该格中心；边界对齐按单格计算。玩家城市与流寇据点仍为 2×2 格。

服务端 NPC 城市生成、占位和冲突迁移按一格检查；建城与其他目标生成时只将 NPC 城市所在格视为实际占地。NPC 外围一格为布点间隔约束，不属于城市占地：单格 NPC 城市预留 3×3 布点禁区，四格流寇预留 4×4 布点禁区，防止 NPC 紧连。迁移保留身份、等级、守军及战果，有行军引用的目标暂不迁移。

验证：10 项地图布局测试通过，覆盖 NPC 单格命中、相邻格不命中、世界边缘及玩家城市／流寇四格规则。后端验证尚未完成。

## 2026-10-11 分块播点与占地约束

NPC 补生、流寇配额补足以及流寇／资源野地刷新使用 16×16 分块密度选点：先在允许范围内寻找同类密度较低且有合法空位的块，再于块内随机选择坐标。资源与 NPC／流寇分别统计，陆海各自均衡，密度分母使用本块同类地形总面积。

选点继续避让玩家城市完整四格及所有目标实际占地；NPC／流寇补点额外避让外围一格。每放置一个目标立即更新本批密度与占位，NPC 的 3×3 间距禁区也立即生效。既有正常目标通过后续刷新逐步改善分布，占地冲突修复仍保留身份、守军和战果，并保护行军引用。
