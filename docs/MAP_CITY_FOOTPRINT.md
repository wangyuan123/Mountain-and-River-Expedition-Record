# 城市与据点四格展示

玩家城市（主城、分城及其他玩家城市）、NPC 城市（含模拟 NPC）、日寇据点与流寇（含海上编队）的地图图像与点击范围统一为 2×2 格；野地保持 1×1 格（2026-10-06 更新）。玩家城市使用 D 款港口模型，NPC 使用选定 B 款要塞，七类野地各用对应模型。

以城市原坐标作为左上角，靠近世界右边界或下边界时向内对齐，保证四格展示完整落在世界内。模型随地图比例缩放，选中框、名称、状态和行军线连接点使用统一的显示中心。主城按钮定位城市显示中心；坐标查询支持查询城市扩展的格子。跨区块或视口边缘也会保留相交城市。

据点与流寇沿用玩家城市的四格展示规则，模型、选中框、名称与行军线端点使用同一占地中心，世界边缘向内对齐。

这是地图显示与点击范围调整。服务端城市坐标、建城条件、领地归属及行军距离计算保持原有规则，不删除相邻地块；旧 NPC 与据点冲突按下述维护规则迁移。如果现有单格目标与城市图像重叠，该目标显示在上层并优先响应其自身格子的点击，剩余城市区域可继续打开城市详情。

验证：地图原有 7 项测试和新增布局 5 项测试通过，涵盖四角命中、地图边缘、重叠目标、不同缩放及跨区块显示。浏览器演示数据验证：城市明显大于单格 NPC/野地、点击城市右下角打开正确详情、查询 (101,101) 找到坐标 (100,100) 的城市、主城定位和放大后显示正确。
