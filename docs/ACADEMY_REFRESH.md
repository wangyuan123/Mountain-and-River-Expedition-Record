# 军校候选人刷新

## 一、 基础刷新规则与额度机制

- 每次成功刷新消耗200黄金，生成10名候选人。
- 每轮最多成功刷新30次；前29次可连续刷新，第30次成功后开始冷却1小时。冷却结束后开启下一轮。
- 每个账号每日最多成功刷新100次，各城市共享轮次、冷却和日额度。
- 每日按北京时间（Asia/Shanghai）0点重置日计数；跨日不重置未满的轮次，也不提前结束冷却。
- 黄金不足、军校未建造、额度用满或冷却中的请求不扣黄金、不增加刷新次数、不替换候选人。
- 后端在同一事务中加玩家行锁、检查额度、扣费和保存候选人，防止并发请求超额。
- 军校页面显示本轮与今日已用次数，后台状态更新时只刷新额度和倒计时区域。
- 数据库升级由 `V53__academy_refresh_quotas.sql` 添加账号额度字段，并清除旧版每次刷新都触发的一小时冷却；保留已有候选人。

## 二、 调遣解密动画与视听仪式感规范

为了改变过去点击刷新后新名单“瞬间干瘪替换”、缺乏抽调将领悬念与仪式感的问题，军校招募引入了完整的**【战区调令·机密档案解密】**视听动画体系。

### 1. 时间轴与动画阶段（标准时长 1.2s，遇 5 星名将 1.4s）

```
0ms                 350ms              600ms               1050ms             1200ms (1400ms)
├─────────────────────┼──────────────────┼───────────────────┼──────────────────┤
[ 战区机密公文袋出现 ]  [ 绝密印章下落盖戳 ]  [ 调令破封/卡背排布 ] [ 10张卡牌3D翻牌揭晓 ] [ 5星悬停特写与光环定格 ]
└─────────── 第一阶段：悬念蓄力 ──────────┘ └─────────── 第二阶段：破封揭晓 ──────────┘
```

* **第一阶段：悬念蓄力（0ms ~ 600ms）**
  * 候选区域平滑切换为**战区机密公文袋**（`WAR DEPARTMENT · 机密调令 NO.AC-2026`）。
  * 配合金色军徽浮动与动态横扫的**雷达扫描光带**，动态文字实时轮播（“正在联络各战区司令部…” → “调阅将校考评档案与战功…”）。
  * 约 350ms 时，一枚红色的**【批准调派 / TOP SECRET】绝密火漆印章**伴随弹性下落重重盖在公文袋上。
* **第二阶段：破封与 3D 阶梯翻牌（600ms ~ 1200ms）**
  * 接口数据与时间轴并行就绪后，公文袋破封收敛，10 张卡片呈**烫金军徽与八角星暗纹卡背**。
  * 卡牌通过 CSS3 `perspective: 1200px`、`transform-style: preserve-3d` 与 `backface-visibility: hidden` 硬件加速，以 45ms 级联步进如多米诺骨牌般从左至右 3D 翻转为正面。
* **第三阶段：五星名将专属出货高光（遇 5 星额外延展 200ms）**
  * 若本批次命中了 5 星名将（UR / SSR），翻到该张卡片时自动触发 **0.2 秒（200ms）悬停特写**（`scale(1.1) translateY(-6px)`）。
  * 从卡片中心向外爆发出一圈**耀眼的钻石金光脉冲冲击波（`star5-burst-glow`）**，大幅增强出货成就感。

## 三、 Web Audio API 算法纯合成音效规范

音效由前端基于原生 Web Audio API 进行数学算法实时合成，**无需下载任何外部音频文件（0KB 体积、0 网络延迟）**，峰值限制在 0.28 内杜绝破音，并与游戏全局音效开关及音量设置（`Game.Sound`）联动。

1. **【战区调令·沉稳盖戳音】(Heavy Seal Stamp Thud，约 350ms 印章落地触发)**
   * **冲击层**：正弦波 140Hz 瞬降至 42Hz（0.12s 指数衰减），塑造重木质印章压在桌面公文上的厚重下沉感。
   * **纸面压实层**：三角波 320Hz 降至 80Hz（0.06s 衰减），模拟印面与纸张挤压碰撞的微弱脆声。
2. **【调遣卡牌·清脆微翻转】(Card Flip Click，翻牌阶段单卡翻转触发)**
   * 正弦波 680Hz 降至 380Hz（仅 35ms 极微弱起伏），10 张卡片连贯翻转时营造出顺滑悦耳的切牌洗牌节奏。
3. **【名将授勋·破晓金钟和弦】(Epic Golden Fanfare Chime，遇 5 星名将悬停触发)**
   * **大三和弦共振**：C5 (523Hz) + E5 (659Hz) + G5 (784Hz) + C6 (1046Hz) 琶音向上推进（0.55s 丰满余韵），带有殿堂级授勋庄严感。
   * **金光扫频**：正弦波 1200Hz 优雅滑向 2600Hz 的晶莹泛音，模拟金芒与钻石光环扩散时的空灵破晓感。

## 四、 防卡手操作体验与性能保障

1. **即时跳过机制 (Instant Skip)**：
   * 动画播放过程中，点击候选区域或屏幕任意位置，立即清除定时器并添加 `.is-skipped` 抹去延时，所有卡片瞬间完成翻转定格，支持高频点击。
2. **极速刷新开关 (Fast Refresh)**：
   * 军校界面刷新按钮右侧新增 **【极速刷新】复选框**，状态自动持久化保存到浏览器的 `localStorage['sf_academy_fast_refresh']`。
   * 勾选后，点击刷新将直接跳过公文袋与翻牌动画，瞬间刷新名单，满足重度批量连刷的需求。
3. **防重入请求锁**：
   * 动画播放期间，刷新按钮自动切换为“⏳ 调遣将领中...”禁用状态，彻底杜绝手速快或网络波动造成的连击重复扣费。
4. **主题自适应与预览**：
   * 动画与卡牌样式完全兼容游戏内的经典蓝白主题与暗夜黑主题（`[data-theme="dark"]`）。
   * 独立交互预览页面位于 `frontend/tests/academy-card-preview.html`，可直接在浏览器中测试试听。
