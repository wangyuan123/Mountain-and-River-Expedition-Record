# 海洋、沿海建城与海军适配方案

存档日期：2026-09-14。用户批准先存档、再按两阶段实施。

## 目标和地图规则

- 保留 200×200 世界、倾斜画布、触屏拖动和分块懒加载；大陆为主，增加连通海域、海湾、半岛和少量岛屿。初始海洋目标约 20%～25%，存量地物保护可能使比例降低。
- 海域由服务端保存一次，所有玩家共用；海陆判断、建城和行军使用同一份地形。前端不能自行决定可建位置。
- 海水采用深蓝、浅青近海与沙岸过渡，保留淡草地和土壤；水中不绘制草木。仅可见区域绘制轻量波纹，并尊重减少动态效果设置。
- 玩家新城真实占用 2×2 陆地；NPC、野地继续占 1 格。旧城市原位保留，历史重叠不强制搬迁，但所有新建选址避让完整城市范围。

## 第一阶段：海洋与建城

1. 增加持久化海陆数据及版本。首次生成时保护所有已有城市、NPC、野地和玩家主城坐标，落在海区的旧地物保留陆地缓冲区；不删除资产。
2. 加入地图地形接口和沿海地块检查接口。空地点击显示 2×2 预览、是否临海、不可建原因、费用和工期。
3. 新增按坐标建立沿海分城；保留已占领森林/丘陵建城入口，也执行 2×2 占地校验。沿海空地不必先占领野地。
4. 校验边界、四格陆地、至少一侧临海、城市/NPC/野地冲突、军衔名额、资源和行军中的野地。世界行锁串行化选址提交，避免两人同时占用重叠地块。
5. 地形稳定后，新玩家出生和新增世界地物都避让海洋及城市占地。

## 第二阶段：港口与出征

1. 新城市仅临海可新建港口；既有港口允许继续升级和生产。旧内陆城市保留海军通行资格，通过补给连接到最近海岸，连接距离计入航程，界面明确标示。
2. 舰队沿连通海域寻路，可攻击临海目标，或运输、调遣至有海军通行资格的己方城市；不可直接炮击内陆目标。
3. 陆军沿陆地寻路；跨海时需要运输能力。首版使用已有运输机，按陆军人口计算运力（每架 80）；海陆混编同样检查运力，舰队可以随运输编队护航。暂不增加独立护航任务或新的船种。
4. 空军可跨海直达。所有路径和距离由后端确认后再扣资源、兵力，前端显示实际路线和预计时间；已有出征按原记录完成，不中途改变到达时间。
5. 战斗结算沿用现有兵种和战报机制。本次不新增海上拦截、登陆战加成或封锁经济系统。

## 存量与回滚

- 修改前代码备份：`docs/archive/ocean-before-20260914/source.tar.gz`。其中不包含密钥。
- 数据库通过增量迁移添加字段；不重置世界、不清空玩家。首次地形生成将结果保存到世界记录，重启不会重画海岸。
- 上线前必须备份数据库；本次开发不主动修改线上数据。回滚应用前需停止建城和出征写入，保留已创建城市和路线字段，不直接删除新增字段。

## 验收

- 地形：确定性、海域连通性/占比、旧地物保护、重启稳定、海陆前后端一致。
- 建城：沿海成功；海中、越界、内陆空地、四格冲突拒绝；资源失败不扣款；原森林建城入口正常。
- 海军：沿海航线避陆；内陆目标拒绝；旧城补给兼容；混编运力校验；失败不扣兵；运输/调遣可用。
- 地图：海岸和岛屿视觉检查、预览和取消、刷新与切城、真实行军线、触屏/缩放相关回归。
- 实施完成后，在 `docs/OCEAN_COASTAL_CITY_VALIDATION.md` 记录结果与限制。
