# 战斗科技攻防对应设计

初版日期：2026-10-12；实现日期：2026-10-13。状态：火力密度已接入源码并完成定向验证，尚未部署。2026-10-16已按科技改版将正文公式与当前成长表同步为每级5%、最高50%，规则为`balance-v19-technology-20261016`。第8、11节保留每级10%旧版实验，不作为当前v19实测结果；新验证见[科技改版记录](TECH_REWORK_PROPOSAL_20261016.md)。

## 1. 判断

军队生命属于独立的生存成长，应当有同量级、同成本的持续输出成长作为对应。当前攻击科技与防御科技虽都是每级5%，但防御和生命相乘，攻击只有一个成长因子，导致双方科技一起升高时，单次行动的击杀能力反而下降。

当前形成两对基础战斗科技：

| 输出成长 | 对应生存成长 | 对应关系 |
| --- | --- | --- |
| 攻击科技 `attack_tech` | 防御科技 `defense_tech` | 提高武器攻击与提高减伤能力 |
| 火力密度 `fire_density` | 军队生命 `cmd_hp` | 提高行动火力与提高需要消耗的生命量 |

对应的重点是研发投入、成长幅度和战斗收益可以比较，不是所有科技都必须强行配成两项。射程、机动、侦察和后勤是战术或经济工具；医疗主要影响战后回收，也不应再机械增加“减少伤兵”科技。

“输出科技”供攻守双方使用。增加火力密度不会只加强进攻方，也不会自动保证攻方击败同规模守军；守城优势、军官、配兵和战术仍然存在。

## 2. 为什么现状越养成越难击杀

先固定存活兵数、兵种和距离，不计军官、技能、装备、专项克制，以观察科技本身。设攻击科技A、防御科技D、生命科技H，基础防御为d：

```text
输出 ∝ (1 + 0.05A)
有效防御 = d × (1 + 0.05D)
有效生命 = 基础生命 × (1 + 0.05H)
单次行动击杀能力 ∝ (1 + 0.05A)
                  / [(1 + 0.05H) × (1 + 0.05d × (1 + 0.05D))]
```

同等级A=D=H=L，令t=1+0.05L、k=0.05d，相对相同阵容下的零科技：

```text
现有击杀能力比例 = (1 + k) / (1 + kt)
```

攻击与生命的t正好抵消，防御成长单独降低击杀率。满级防御的等效承伤收益小于×1.5，但叠加满级生命后，整体常驻承伤仍增长超过输出。

| 目标，无城墙/其他加成 | 三项科技共同Lv.0 | 共同Lv.5 | 共同Lv.10 |
| --- | ---: | ---: | ---: |
| 步兵 | 100% | 90.32% | 82.35% |
| 反坦克火箭车 | 100% | 87.27% | 77.42% |
| 重坦 | 100% | 84.03% | 72.45% |
| 战列舰 | 100% | 82.35% | 70.00% |

这些比例是等兵力单次行动的理论击杀能力，不是战斗胜率、全歼回合数或资源战损。生命还会通过延缓减员间接保留后续火力，实际多回合战斗必须另做模拟。

## 3. 备选机制比较（历史方案比较）

| 方案 | 与生命的对应精度 | 战斗特点 | 判断 |
| --- | --- | --- | --- |
| 独立行动火力倍率 | 相同等级时精确抵消生命科技倍率 | 确定、所有目标一致、容易理解和校准 | 推荐 |
| 暴击率，每级+10个百分点，暴击×2 | 数学期望可对应，但单次伤害有随机波动 | 小规模波动大，涉及按军团还是逐兵抽样；满级100%又变回固定翻倍 | 暂不采用 |
| 每级增加概率连击 | 期望可提高，但新攻击可能另选目标、再次触发反击 | 额外改变行动次数、技能和余伤规则 | 不作为基础科技 |
| 破甲/穿透 | 随目标防御变化，不能精确对应生命 | 更像防御科技的克制；低防目标收益小，高防目标收益大 | 可作后续专项路线 |
| 直接增加第二项攻击百分比并与攻击科技相加 | 满级合计攻击×2，不能提供与独立生命倍率对等的输出因子 | 简单但没有独立成长层 | 不满足本次对应目标 |

火力密度在最终伤害的数值效果上，就是独立的增伤乘区。其概念区分是攻击科技提高单次武器威力，火力密度提高一个战斗回合内的有效射击量。明确告诉玩家独立相乘，不伪装成额外射击动画或行动次数。

## 4. 推荐科技定义

| 字段 | 设计值 |
| --- | --- |
| 名称 / 标识 | 火力密度 / `fire_density` |
| 分类 | 军事 |
| 效果标识 | `firepower_all` |
| 等级 | 0～10，缺失字段按0级 |
| 每级效果 | 每次行动火力在基础上+5% |
| 同项累计 | `1 + 0.05 × 等级`，不逐级复利 |
| 生效时机 | 每次实际开火常驻生效，不受军官三回合周期限制 |
| 适用 | 攻守双方所有兵种及参战城防；对地、对空、对海、对工事均按自身武器生效 |
| 首级基础费用 | 钢铁300、粮食160、稀矿30，与军队生命相同 |
| 费用增长 | 1.8，与军队生命相同 |
| 科研中心最低等级 | 3，与军队生命相同；逐级建筑门槛见下一节 |
| 工期 | 沿用全账号单科研队列、现有工期与科研加速公式 |

科技说明的完整口径：

> 提高全军每次行动的有效火力，每级增加5%，最高50%；与攻击科技独立相乘。主动攻击、余伤攻击和反击均生效，不增加行动次数，不改变射程、机动或兵种克制。

等级展示应写“当前行动火力+25%（×1.25）→下一级+30%（×1.30）”。每级增加5个百分点；5→6级实际输出增幅为1.30/1.25−1=4%。攻击科技Lv.10、火力密度Lv.10相乘为×2.25。

## 5. 研发成本与逐级前置

研究至目标等级L的费用：`floor(基础费用 × 1.8^(L−1))`，逐资源向下取整。

| 目标等级 | 钢铁 | 粮食 | 稀矿 |
| --- | ---: | ---: | ---: |
| 1 | 300 | 160 | 30 |
| 5 | 3149 | 1679 | 314 |
| 10 | 59507 | 31737 | 5950 |
| 0→10级合计 | 133513 | 71205 | 13346 |

工期：`round(30 × 1.8^(L−1) / [(1+0.10×max(0,科研中心等级−1)) × (1+0.04×市长格物等级)])`，最低5秒、最高86400秒。军队生命与火力密度沿用相同公式和加速来源。

本城前置与军队生命保持同类进度结构，但使用火力研发设施。设S=max(1,L−2)：

- 科研中心 `lab`：max(3,L)。
- 军工厂 `factory`：L。
- 军校 `academy`：S。
- 稀矿厂 `raremine`：S。
- L≥7时，作战参谋部 `staff`：S。

全部为AND、本城已完成单栋最高等级；科技成果与队列按现有规则全账号共享。例：Lv.1需科研中心3、军工厂1、军校1、稀矿厂1；Lv.5需5/5/3/3；Lv.10需科研中心10、军工厂10、军校8、稀矿厂8、参谋部8。

研发设施主题可以不同，经济费用、最低科研中心与进度台阶应可比。现有攻击/防御科技资源费用相同，但科研中心最低分别为1/2，建筑链也不同；本案先补齐生命对应项，不同时重排既有研发链。

## 6. 伤害与叠加契约

设F=1+0.05×火力密度等级，原伤害计算结果为D，则：

```text
新理论伤害 = D × F
实际应用伤害 = min(新理论伤害, 目标剩余总生命)
理论击杀 = 新理论伤害 / 目标有效生命
```

必须在伤害封顶和击杀计算之前乘F，不能在封顶后将已应用伤害翻倍。主攻击、反击共用这一规则，每次攻击只乘一次。

具体约定：

1. 当前存活兵数仍决定行动额度。F乘入每份额度的伤害；不额外创建第二次攻击事件，兵力显示和出手次数均不变。
2. 余伤打下一目标时，重新读取领域、防御、克制、装备减伤与贴脸倍率，并沿用同一F；击毁目标消耗额度=`目标生命/包含F的每份伤害`。不能在换目标时重置额度或再次乘F。
3. 绝境反击读取反击方自己的F，与反击技能比例独立组合；反击仍不享受贴脸加成。
4. 全军冲锋、火力压制先按当前逻辑处理自身攻击，师夷长技随后追加，整个结果再乘行动火力F；学习参考值不复制敌方火力密度，也不能把己方F算进参考后重复乘。
5. 破甲只影响减伤项，装备减伤仍按当前比例结算。火力密度不忽略防御、生命或装备。
6. 射程和攻击领域不变。反坦克火箭车对空11.5与对地100仍分别使用自身武器，弱项不会借用强项攻击，也不会新增反舰倍率。
7. 实际战斗军官军事、防御属性与八项战斗技能统一从首次交火回合E起，在E、E+3、E+6……回合生效。F常驻，不参与将领周期。
8. 城防与兵种均适用，是为了匹配当前生命、防御科技在数值内核中的作用范围；若要将城防拆出科技体系，应作为另一项完整设计处理。

对应关系准确体现在独立因子：`火力密度对生命的净影响 = (1+0.05F等级)/(1+0.05H等级)`。等级相同正好为1；敌方生命科技不会被直接扣除或禁用，高生命对低火力仍然有效。

## 7. 成长后的预期

四项科技同等级时，相对相同阵容下的零科技：

```text
加入火力密度后的击杀能力比例 = t × (1+k)/(1+kt)
```

| 目标，无其他加成 | 共同Lv.0 | 共同Lv.5 | 共同Lv.10 |
| --- | ---: | ---: | ---: |
| 步兵 | 100% | 112.90% | 123.53% |
| 反坦克火箭车 | 100% | 109.09% | 116.13% |
| 重坦 | 100% | 105.03% | 108.68% |
| 战列舰 | 100% | 102.94% | 105.00% |

结果说明：新增项抵消生命额外减速后，攻击与防御同等级成长基本维持原有节奏，并略微提高输出。由于减伤公式分母含常数100，攻击与防御并非精确互消；低防目标提升略大，高防目标更接近基础节奏。

若设计目标是连低防目标也保持完全相同节奏，需要重构防御公式或设动态补偿；本案不引入这类隐藏规则。每级5%与现有生命系数一致，公式和定向多回合对照已验证；这不代表所有配兵、NPC难度和匹配场景均已平衡。

## 9. 接入范围与发布要求

- 定义与研发：同步 `TechDef`、前端 `data.js`、`constants.js`、科技效果展示、费用说明、建筑前置运行JSON与设计源。单改科技目录会漏掉实际研发资格。
- 战斗：主动与反击伤害入口共用F；余伤守恒；缺字段、无科技和NPC默认F=1。玩家城战与野地出征应使用真实参战科技快照。
- 展示：兵种基础攻击不改写成永久基础值；单兵有效武器攻击、行动火力倍率和最终伤害分开展示。战报明确显示“火力密度×1.25/×1.5”，原始火力字段的口径必须同步，避免已经乘过F的值再次被前端放大。
- 演习：`PvpSnapshotService`当前科技白名单必须新增键；`practiceStats`与实力估算必须包含F，并在说明中明确展示合并后的输出口径。新增键、规则版本、固定参考科技与校准配置一起更新，重新测量技能校准，不能只改版本字符串。
- 兼容：旧账号新增科技为0级，无记录按0读，不免费自动继承生命等级；历史战报不重算。进行中战斗沿用冻结的科技，禁止中途查当前等级赋予新加成。缺键F=1可兼容旧战斗数值，演习的规则兼容检查仍需独立核验。
- NPC：本案不按玩家科技自动给NPC新增火力。既有NPC缺键为0；未来按难度同时配置生命与火力，避免只补一边。军衔考核与NPC关卡需要验证玩家新增科技优势是否符合预期。

不自动赠送等级可保留研发投入，但满级生命老玩家在新科技研发完成前仍会处于旧的消耗节奏，且玩家间可能形成新科技差距。上线验收应同时覆盖只攻方/只守方已研发；补偿或免费等级若另有要求，应单独制定规则。

## 10. 实施验收

1. 0/1/5/10级倍率准确；同项线性累计，与攻击独立相乘；生命与火力同等级在独立因子上精确抵消。
2. 主动、余伤、反击攻守对称；伤害封顶、同次额度守恒，无新行动；全军冲锋、压制、学习、破甲和装备各只叠加一次。
3. 海陆空及工事、0射程后勤、援军配装分组都使用正确科技来源；持续指令和刷新/离线回合不丢失快照。
4. 科研费用、逐级前置、队列工期、取消返还和全账号共享同步；前后端实际效果与描述一致。
5. 对17种当前兵种、4类工事，0/5/10级成长、城墙0/10、技能与配装、多种混编、等数量/等资源、互换攻守、固定种子做对照；记录全歼率、交火回合、资源战损与未受攻击的幸存单位。
6. 演习新快照和估值包含F，旧快照保持旧值或按既有兼容流程结束；重算校准后再验证匹配公平性。

本次范围仅为火力密度，不包含先前讨论的索敌、接触距离、工事射程、城防或终局规则调整。

## 11. 2026-10-13实施结果（历史每级10%版本）

科技定义、每级百分比、前端当前/下一级倍率、10级本城建筑前置、费用与工期、主动及余伤伤害、反击、战报标签、演习冻结科技和估值均已接入。战斗规则为 `balance-v14-fire-density-20261013`；缺项为零级，旧账号不会自动继承军队生命等级，进行中会话不读取账号新等级。

40项后端定向测试通过，覆盖17种兵种和4种工事、四攻击领域、双方、0/1/5/10级、余伤守恒、伤害封顶、技能与装备、科研队列和冻结快照。前端112项相关测试通过。额外64项后端广回归中有6项旧失败，隔离恢复本次修改前的战斗引擎后，同6项以相同结果失败；没有修改这些速度和旧平衡预期。

真实新引擎对600组配置运行8,640场固定种子模拟，包含混编、工事、同数量/同资源、城墙0/10、其他科技0/5/10、配装与技能，以及单方和双方火力密度。双方由0级升至10级时，实验集合A/B平均资源损失分别从42.89%/59.05%升至48.00%/73.18%，任一方全歼的场数从840/1,728升至1,032/1,728；仍有696/1,728场打满回合。集合并不对称，资源等权相加，结果只说明这些阵容消耗加快，不保证24回合全歼或真人公平胜率。开局距离在每组火力对照中保持一致。

演习86组技能配置已重新测量，共564,160场模拟，最大校准残差1.60个百分点。独立混编5,184场的最大损失差偏离仍为8.73个百分点；最差组合在没有新科技、保留当前兵种属性的对照引擎上为7.00个百分点。按实际估值归一化参考兵力的试验改善陆战但恶化海战，因此保留原估值公式与新实测系数，未将独立复核宣称为公平性通过。进一步改善需单独设计技能估值的样本和泛化方案。
