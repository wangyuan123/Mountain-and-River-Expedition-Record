# 军官战术技能扩充与组合介绍

日期：2026-10-30。正式技能池由15项扩为23项；每名军官最多3项、每项最高Lv.5，不设组合互斥。

## 新增技能

| ID | 名称 | 每级成长 | 生效规则 |
| --- | --- | --- | --- |
| ranging | 三轮校射 | 第三轮伤害+8%，满级40% | 同一兵种连续三个回合主动攻击同来源同兵种，第三次增强主目标；换目标、间断攻击清零，第三次后重新计数 |
| barrier | 战地屏障 | 当前总生命值2%，满级10% | 周期生效回合按回合开始的兵力生成，先吸收伤害再计算伤亡，仅本回合有效 |
| last_stand | 背水奋战 | 自身攻击+4%，满级20% | 回合开始本来源本兵种剩余数量低于开战50%；主动与反击适用，不放大学习所得攻击 |
| execution | 残阵收割 | 本次伤害+5%，满级25% | 攻击前目标本来源本兵种剩余数量不高于开战30%，切换目标重新判断 |
| smoke | 烟幕遮断 | 下一回合机动速度-5%，满级25% | 周期生效回合首次主动命中存活目标；多个来源取最高，不影响先手、射程和大地图行军 |
| reprisal | 蓄势反攻 | 先前两回合实际承伤的2%，满级10% | 周期生效回合首次主动攻击追加，最高为该次普通攻击伤害40%；消耗历史记录，不计当前回合、屏障吸收及溢出伤害 |
| ricochet | 跳弹射击 | 第二目标攻击强度3%，满级15% | 周期生效回合首次主动攻击额外命中射程内另一合法部队；独立计算第二目标领域、克制、防御、配装和距离，不递归产生跳弹或其他追加攻击 |
| pursuit | 乘胜追击 | 次回合机动+6%、首次主动攻击伤害+3%，满级30%/15% | 参与歼灭占敌方来源编队开战总人口至少5%的兵种；同回合只取得一次下一回合追击，不影响大地图行军 |

周期为所属编队首次接战回合E、E+3、E+6……。条件技能三轮校射、背水奋战、残阵收割、乘胜追击按自身条件触发，不受三回合窗口限制。

所有新增技能仅作用于所属带兵编队的部队，不给工事或城墙生成屏障，也不以工事、城墙作为校射、收割、烟幕或追击的兵力目标。司令官仍只提供其常驻属性，不启用军官技能。

## 跨回合和来源隔离

- 随机书、通用自选书、已有指定书和VIP定向转化统一使用23项正式池；商城技能书仅售普通书（80钻石）和通用书（800钻石），指定书下架且后端拒绝购买。已有指定书仍可学习和升级，等级和升级材料规则沿用原逻辑。
- 三轮校射以目标来源和基础兵种识别；拆分配装组不增加校射次数或制造额外跳弹目标。残兵比例与追击规模按来源内同兵种汇总计算。
- 屏障、校射、历史承伤、烟幕和追击保存在本场技能状态中。世界会话使用新增的`battle_sessions.skill_state`；协防和演习在既有JSON快照内保存。重启不从实时军官重建技能。
- 普通战斗沿用逐兵种行动；协防仍以同批伤害统一提交，屏障对同一目标只扣一次总吸收额，战损、来源贡献保持守恒。
- 侦查保留“攻击÷（防御+生命）”专用公式、10回合上限和原先手规则，应用校射、屏障、背水、收割和蓄势。侦查没有机动阶段，烟幕与追击的机动部分无作用；单一来源的同名配装组不算跳弹的第二目标。追击攻击部分仍须实际满足歼灭条件。
- 技能事件随战报输出。演习规则版本和实力校准版本随新增技能更新，旧系数不换标签冒充新实测。
