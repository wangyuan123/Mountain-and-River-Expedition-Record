# 兵种征召资源造价调整（2026-10-19）

状态：本地前后端配置已修改，未部署。

## 调整目标与取值

按资源分工增加指定资源需求，其他资源单价沿用当前配置：

- 普通步兵新增石油2、稀矿1，粮食10、钢铁30不变。1000名步兵新增消耗石油2000、稀矿1000，保留低成本定位。
- 特种兵征召粮食40→80（+100%），仍低于火箭车粮食100。
- 防空装甲车、侦查装甲车、轻坦、重坦钢铁统一增加50%，两种装甲车继续同价。突击炮按火炮处理，本次钢铁不变。
- 四种空军（含侦察机与运输机）稀矿约增加50%：10→15、35→55、60→90、20→30。战斗机52.5向上取整到55，其余精确增加50%。
- 反坦克火箭车首轮石油150→225，本轮按最新指定调整为450，稀矿70→120，粮食100、钢铁550不变。
- 战列舰粮食、钢铁、石油、稀矿分别为本轮火箭车单价的20倍；航母四项资源分别为战列舰的2倍，即火箭车的40倍。
- 驱逐舰、潜艇与卡车造价不变。重坦钢铁675可以超过火箭车550，体现装甲偏钢、火箭偏油；火箭车仍是陆军加权造价最高的兵种。

取值是本次资源需求设计选择，并非由战力自动推导，尚不代表全局经济平衡已验证。攻击、防御、生命、射程、人口及基础驻城粮耗、基础行军油耗不在本次调整范围。

## 既有公式的联动

- 征召资源继续按当前单价×数量即时扣除，可征召数量受资源、平民等条件约束。
- 新生产队列的单单位基础秒数为30+floor((粮食+钢铁+石油+稀矿)/10)，再按数量与设施、科技速度结算，因此部分兵种生产时间自然增加。既有订单保存的排期与已付成本不重算。
- 取消生产按订单保存的四项资源退款，不按新单价退款；已有部队不追扣资源。
- 兵种装备配方沿用UnitEquipmentDef中的倍数、下限和取整规则，读取新单价。例如步兵钢盔为钢铁300、石油1、稀矿1；轻坦间隔装甲包为钢铁2160、石油80、稀矿20。已支付装备订单沿用保存成本。
- 伤兵黄金治疗按当前四项征召资源总和的10%逐单位向上取整，战俘黄金招募按25%逐单位向上取整，随当前单价联动。
- 解散钢铁回收继续按当前钢铁单价×数量×30%向下取整。
- 前端界面读取统一的units.cost，data.js缓存版本同步更新。日军名称映射继承相同底层造价。
- 既有等预算报告与早期攻击推导保留历史条件；本次不依据新造价自动调整攻击值。
