# 兵种平衡修订与验证

> 本文保留 v2 的设计与实验快照。当前攻击属性已升级为三域独立攻击，最新规则、数值与验证见 [攻击领域设计](ATTACK_DOMAINS_20260918.md)。

日期：2026-09-18。规则版本：`balance-v2-20260918`。状态：本地代码与自动化验证完成，未部署。

本轮在工作区已有的线性伤害、分类克制与兵种分工改动上完成验证，并将重坦对轻坦倍率从 1.25 校准到 2.25，解决等资源对战在 30 回合内无法兑现克制的问题。保留已有的突击炮对空、火箭对地、重坦掩护设计。

## 最终规则

- 原始火力：`有效攻击 × 当前数量 × 连击倍率`，不再使用攻击平方。
- 目标伤害：`剩余原始火力 × 目标倍率 × 100/(100 + 5 × 有效防御)`。目标全灭扣除实际消耗的原始火力，下一个目标重新计算倍率和减伤，不能继承前一个目标的弱点。
- 不再因为一步移动到距离零获得双倍伤害。单位进入自身射程即停步，移动与攻击各占一次行动。
- 射程仍有先手价值。战斗机射程 360，高于轰炸机 300；潜艇射程 340，高于战列舰 320。对空、对潜效率同时区分，避免通用高攻击火力覆盖一切职责。
- 重坦开场前置 400，只保护其身后的地面单位；特种兵在可攻击范围内绕过这项保护。它不是无条件隔空拦截，也不会保护空军或舰船。
- 科技持续生效，军事属性和猛攻/铁壁/压制仍每三回合触发。压制作用于敌军；防御、破甲、连击不再只对攻方有效。城墙归守城方。
- 同射程同速度轮换先手，同侧按 ID 打破平局，目标选择也有确定的 ID 平局规则；可注入固定随机种子复现实验。
- 沿用 30 回合上限和整数击杀加概率取整。超时与全灭分开统计，不把“守城成功”等同于“兵种单挑获胜”。

## 兵种职责

| 兵种 | 主要用途与限制 |
| --- | --- |
| 步兵 | 廉价数量投入；摩托兵和装甲车有反步兵优势 |
| 摩托兵 | 对步兵类 ×2，面对装甲火力减半 |
| 装甲车 | 对步兵类 ×1.75，受轻坦反制 |
| 轻坦 | 对装甲车 ×1.5、火炮 ×2，机动反炮兵 |
| 重坦 | 24 攻 / 60 防 / 420 血；承担地面掩护，对轻坦 ×2.25；受火箭和轰炸机反制 |
| 突击炮 | 30 攻 / 400 射程，对空 ×2、默认对地 ×0.25；资源 160 钢 / 40 油 / 10 稀矿，人口 2 |
| 火箭 | 45 攻 / 400 射程，对重坦 ×2.5、一般装甲 ×1.75，对空 ×0.1；资源 200 钢 / 60 油 / 20 稀矿，人口 3 |
| 特种兵 | 地面渗透，对火炮与卡车 ×2，可绕过重坦掩护；不再按空军路线与引擎科技处理 |
| 战斗机 | 制空，对轰炸机 ×2、其他空军 ×1.75，默认对地 ×0.35 |
| 轰炸机 | 对重坦和碉堡 ×2、一般装甲 ×1.5，对空 ×0.25 |
| 驱逐舰 | 对潜艇 ×2.5、对空 ×1.25，受战列舰反制 |
| 潜艇 | 对战列舰/航母 ×3，对驱逐舰 ×0.35 |
| 战列舰 | 对驱逐舰 ×1.75，对潜艇 ×0.25 |
| 航母 | 远程航空支援，对空 ×1.5；潜艇是明确反制 |
| 侦察机 | 侦察与反侦察，不主动冲锋，不要求与战斗单位同成本单挑 |
| 卡车、运输机 | 后勤载重分别 50、80，不主动冲锋；运输机保留跨海运力用途 |

城防也采用同一公式与分类倍率。前端军队、城防页面展示分工，17 个兵种和 4 种城防的属性、资源成本有跨前后端一致性测试。

## 验证方法

`BattleBalanceTest` 直接运行重新编译的服务端战斗逻辑，不使用手工复刻公式或旧 class 文件。

- 16 组主要克制，种子 0–31，每个种子互换攻守，共 64 场/场景。
- 战场距离 2200/3000；成长为零科技零军事，以及双方攻击/防御/生命/射程/引擎科技 5 级、军事 50，均无城墙与技能。
- 五种预算：资源总和 56,000；资源加权预算 56,000（钢:油:稀矿=1:2:4）；征兵人口 600；相同产线速度下基础生产时间 7,200 秒；等数量 100。数量向下取整，不超预算。
- 共 320 个场景、20,480 场。等资源与加权资源的预设验收线为克制方全歼率至少 75%；当前 128 个经济场景均为 64/64 全歼。
- 另验证 14 个战斗兵种各有等资源反制（3000 距离、基础成长、互换攻守）。这只排除测试范围内无解的纯兵种，并不证明所有混编都已平衡。

基础成长、3000 距离、等资源总和的代表结果：

| 克制方 | 对手 | 数量 | 全歼率 |
| --- | --- | --- | --- |
| 重坦 | 轻坦 | 98 : 200 | 64/64 |
| 火箭 | 重坦 | 200 : 98 | 64/64 |
| 轻坦 | 火箭 | 200 : 200 | 64/64 |
| 特种兵 | 火箭 | 224 : 200 | 64/64 |
| 突击炮 | 战斗机 | 266 : 180 | 64/64 |
| 战斗机 | 轰炸机 | 180 : 107 | 64/64 |
| 驱逐舰 | 潜艇 | 116 : 103 | 64/64 |

等人口和等数量不强制同样结果。例如 200 火箭对 150 重坦（等人口）在基础成长、3000 距离下为 0/64 全歼、64/64 被全歼；火箭的反重坦优势需要利用较低的资源成本增加数量，人口紧张时需要换编成。完整结果每次测试生成在 `backend/target/balance-summary.csv`。

机制回归覆盖：攻击科技线性增长、普通回合科技生效、压制归属、攻守防御与破甲、城墙归属、射程科技、掩护边界、混编种子复现、余火力守恒及换目标重新折算。既有 PVE、行军、伤兵、新手流程也通过后端全套回归。

## 实际边界

- 两种资源计价是敏感性分析，不是市场价格结论；等生产时间不包含建筑前置、产线数量和建造成本，人口预算不等同于已验证的出征容量上限。
- 舰船对战受现有沿海路线限制；战斗类别使用效率折扣，不引入陆海空绝对免疫。航母反潜弱，仍可能以足够数量取胜。
- 等预算优势明确，但全胜不表示正式对战必胜：投入比例、科技差、将领技能、城防、混编和小数量概率仍会改变结果。尚未穷举混编与所有成长差。
- 规则按新结算生效，已有部队的属性也会采用新定义；不回收已有兵力、不改玩家资源、不重写历史战报，不重新排已有生产队列。历史战报保留当时文本，新战报包含规则版本。
- 本轮不调整商城、经济总产量、赛季或宣战规则。
