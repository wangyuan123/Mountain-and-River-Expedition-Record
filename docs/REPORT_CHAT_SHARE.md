# 战报聊天分享

战斗战报卡片的“分享战报”打开菜单，提供论坛、世界聊天、军团聊天和私聊。私聊可选择最近会话或输入完整玩家名。世界及军团沿用各自的发言资格和冷却，私聊沿用收件人检查及私聊冷却。

服务端验证战报归属后生成随机 UUID 凭证，将链接发送到所选频道。消息中显示“查看分享战报”，接收方点击可打开完整战报；不改变分享者的战报已读状态。持有链接的登录玩家可以查看，分享给世界频道即对该频道玩家开放。读取保留已注销名称脱敏。

接口：`POST /api/game/reports/{id}/share`，请求 `{channel, recipientId}`；`GET /api/game/reports/shared/{token}` 读取完整战报。数据库迁移 `V73__shared_reports.sql` 创建分享凭证表。当前仅支持战斗战报，侦查报告不提供该入口。
