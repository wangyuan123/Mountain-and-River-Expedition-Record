# 步兵大规模作战平衡（2026-10-08）

更新日期：2026-10-10，补充步兵贴脸冲锋翻倍规则。

当前战斗规则沿用 `balance-v11-attrition-counters-20261008`。本轮提高步兵的正面持续火力与接敌距离，让低成本步兵在大编制中成为可靠主力，同时保留装甲单位的防护和重武器的远程、攻坚专长。

| 属性 | 调整前 | 调整后 | 设计意图 |
| --- | ---: | ---: | --- |
| 对地攻击 | 6 | 10 | 提升步枪兵在持续交火中的基础输出，让兵力规模转化为有效火力 |
| 对工事攻击 | 2 | 3 | 允许步兵参与清理轻型阵地，仍远低于突击炮、反坦克火箭车和特种兵 |
| 射程 | 100 | 160 | 减少步兵长距离接敌前的空档，提升正面接敌稳定性 |
| 对空 / 对海攻击 | 5 / 5 | 不变 | 保留低效自卫能力，不扩展步兵的跨域职责 |
| 防御 / 生命 / 移速 | 15 / 120 / 2 | 不变 | 不通过生存或机动属性放大人海战术 |
| 人口 / 造价 | 1 / 粮10、钢30 | 不变 | 维持低成本编组定位，不改变征召与人口节奏 |

战斗按“单兵攻击 × 兵数”累计火力，因此提高对地攻击会自然放大大编制的持续输出，不另加人数倍率。步兵对地攻击 10 仍低于突击炮 34、轻坦 33、重坦 50；对工事攻击 3 也不足以替代专业攻坚单位。装甲车、坦克以及远程火炮仍凭借更高防御、火力或射程保有各自优势。

### 2026-10-10 补充：步兵贴脸冲锋

步兵与当前目标距离为 0 时，主动及余伤攻击的贴脸倍率由 ×1.5 提高到 ×2.0。相同兵力、目标防御和其他加成下，接触后的伤害是非贴脸伤害的两倍，较上一轮贴脸伤害提高约 33.3%。数量越多、冲锋后存活兵力越多，接触输出越高，不再额外叠加按人数增长的倍率。

| 场景 | 当前贴脸系数 | 结算说明 |
| --- | ---: | --- |
| 步兵与当前目标距离为 0 | ×2.0 | 双方主动及余伤攻击均生效，战报显示 `贴脸×2.0` |
| 步兵与当前目标距离大于 0 | ×1.0 | 即使已进入 160 射程，也使用常规火力 |
| 轻坦、重坦、特种兵与当前目标距离为 0 | ×1.5 | 沿用现有接触加成 |
| 其他兵种及绝境反击 | ×1.0 | 不享受贴脸加成 |

实际接触在本回合机动结束后判断，前进、待命等指令本身不赋予加成；保持接触期间的每次主动行动都可生效，目标拉开距离后恢复 ×1.0，不受军官技能周期限制。余伤切换目标时重新读取目标距离、攻击领域和防御，继续使用同一份剩余攻击额度，不因翻倍生成额外攻击次数。

该倍率沿用现有贴脸机制的目标范围，乘在按目标领域选择的有效攻击与防御减伤之后。步兵基础对地攻击仍为 10、对工事仍为 3；无其他加成时，贴脸分别相当于 20 和 6 的火力，仍按目标防御减伤，并受目标总生命值封顶。科技、军官和火力压制先按原规则参与，再乘贴脸系数；对空、对海仍使用自身对应领域攻击，不借用对地攻击。普通属性面板继续展示基础值，战报额外记录实际贴脸倍率。

### 游戏内兵种描述

步兵战斗定位统一使用以下文案：

> 低成本步兵，适合人海冲锋；基础射程160，贴脸（距离为0）时主动及余伤攻击伤害×2，反击不享受加成；攻坚需重武器支援

文案来源为 `frontend/js/data.js` 的 `combatRoles.infantry`，首页兵种详情的“战斗定位”与军队页步兵详情共用该字段。描述明确区分进入射程与实际接触，使玩家能够据此选择继续冲锋；历史原型介绍单独展示，临时贴脸倍率由战报记录。

- 前端与后端单位定义保持一致，步兵四维攻击、射程和经济属性由 `frontend/tests/combat-data.test.cjs` 检查。
