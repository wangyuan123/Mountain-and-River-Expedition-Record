# 二战兵种历史命名（2026-09-18）

## 命名范围

本轮为当前 17 个共享兵种配置选取二战同盟国的真实装备或部队原型，显示格式为“兵种-原型名称（型号或英文名称）”。沿用现有兵种 key，不增加兵种或阵营专属配置。当前同盟国、轴心国与 NPC 共用这套兵种定义，因此这些是统一的展示原型，不表示所有历史阵营都实际装备过它们。

前后端使用相同的完整名称，覆盖兵种/造兵界面、生产队列、派兵界面、征召提示及新生成的战报；已经保存的纯文本战报保留原内容。兵种卡片增加一行“原型”简介。战斗数值、造价、科技、克制与部队存档不因改名而改变。

## 名称与史实边界

- BM-13“喀秋莎”为苏联装备。此处“同盟国”包含苏联、美国、英国等国，并非全部来自同一国家。
- 步兵用 M1 加兰德这一代表装备命名，“加兰德步枪兵”是游戏中的装备描述，不是历史部队番号。WLA 为摩托型号，不能视为其本身装备了车载主炮。
- T17E2 为英国采购使用的 Staghound AA，1943年开始接收，配双联 .50 英寸重机枪；不是装备37毫米主炮的 T17E1，也不是福特生产的六轮 T17。
- M5A1 属于斯图亚特系列；IS-2 中 IS 来自约瑟夫·斯大林的姓名缩写。
- ISU-152 采用“自行加榴炮”这一兵器描述和真实型号，不将中文绰号当作正式型号；历史上属于重型自行火炮，可执行突击攻坚任务。游戏保留已有“突击炮”分类。
- F-5 指 P-38“闪电”的照相侦察改型，不是战后的诺斯罗普 F-5 喷气战斗机。历史照相侦察型通常用相机取代机头武器；当前游戏的微弱自卫攻击属于已有玩法抽象。
- 英国突击队于1940年组建，Commando 是部队称谓，不是枪械型号。陆军博物馆明确记录其爆破训练、突袭及后期突击作战任务。
- Skytrain 在中文资料中也译“空中火车”，本界面统一用“空中列车”。不混入战后的 AC-47 炮艇改装。
- 舰艇全部按舰级命名，括号内是英文舰级名称，不使用 DD-445、BB-61、CV-9 等单舰舷号冒充整级型号。原型介绍按二战用途编写，不采用战后导弹、喷气舰载机等现代化改装。
- 名称和原型简介提供历史背景；游戏攻击、射程、移动速度与载重仍是独立的平衡参数，不等于实物的毫米、公里或吨。当前数值说明继续以 `BALANCE_RATIOS_20260918.md` 为准。
