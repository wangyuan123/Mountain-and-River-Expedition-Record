# 玩家城市接管与敌将俘虏

更新于 2026-10-13（同步征服战破墙胜利条件，保留城市接管和敌将俘虏资格条件）。破墙规则已实现并完成定向验证，尚未部署。

地图和列表统一使用“讨伐”，在出征准备中选择“出征方式”。征服采用下文结算，掠夺采用原掠夺结算，不接管城市、不俘虏指挥官。普通入口默认征服，任务跳转预选对应模式；佯攻、袭扰、游击分别最多 10、15、5 回合，胜利也不获取资源或占领城市。详见 [讨伐设计与实施记录](CAMPAIGN_DISPATCH_DESIGN_20261011.md)。

## 征服战胜利条件

新建真实玩家城征服战会话须满足：**攻方仍有存活参战部队，本场冻结的守军、援军与工事全部清除，墙体生命归零**。守方无参战军队及工事但有墙时，直接进入破墙阶段，不能立即判胜；0级墙在清除守方且攻方存活时获胜。墙体满级10级，每级生命250,000、防御20；防御仅保护墙体，普通部队及工事不获得城墙加成。

消灭最后一组守方后，若墙体在当前兵种射程内，剩余攻击额度同回合转向墙体，并重新计算对工事攻击、墙体防御、距离和贴脸倍率。本回合尚未行动的攻方兵种可用自身完整额度攻墙；不追加额度或机动，余伤不跨回合保留。墙体在射程外时，后续回合按原指令继续机动。

清军与破墙共用35回合，位置与技能周期连续。第35回合完成攻击后再判胜负，该回合余伤破墙仍可获胜；守军已清除但墙体尚存则失败，保留实际守方战损，不发胜利奖励、不降低守城民心、不触发接管或敌将转籍。墙体只在本场累计受损，新战斗按开战等级满血生成；破墙不拆除城防建筑，也不降低等级或工事容量。

仅真实玩家城征服增加破墙条件，玩家城掠夺、NPC、模拟NPC城市、野地、流寇与PVP沿用各自规则。旧会话无墙体快照时按旧胜利规则完成，不中途补墙。完整成长表、数值标定、状态字段及迁移兼容见 [征服战破墙设计](CONQUEST_WALL_BREACH_DESIGN_20261013.md)。

## 接管条件

真实玩家城市在开启占领的讨伐中被击败后，以本次战斗结算后的民心判断。民心为 0，且攻方现有城市数量小于当前军衔上限时，城市归属立即转移。建设中的城市也计入城市名额；关闭占领或进攻失败不接管。

接管保留城市 ID、坐标、建筑等级、建筑建设队列、城内普通资源和城市经济数据。资源留在新取得的城市中，不再重复计入返城战利品。尚未售出的市场委托下架，托管资源归还该城。钻石沿用账号共享钱包规则，留在原玩家账号。

原城军官、军队、城防单位、伤兵、征兵和科研队列、军校候选、在途军队及该城派出的野地驻军清除。原玩家其他城市、已完成的账号科技、道具和账号资料保留。新城状态重置为和平。

未满足接管条件时，城权不变，仍按开启占领的讨伐资源规则结算，并在双方战报中记录未接管原因。

## 战利品负重

掠夺或征服获胜后，需要运回的粮食、钢铁、石油、稀矿和黄金共用一份负重上限：按战后幸存兵种的数量与基础负重汇总，应用出征时冻结的装备、负重科技加成，再扣除随军已有普通资源。2026-10-17起，普通步兵每人基础负重10，卡车每辆500，运输机每架800；纯步兵也可少量搬运，只有未配置负重的兵种或没有幸存兵力时才无普通资源运力。

可获资源总量超过剩余负重时，按各类可获资源比例分配容量，整数余数按最大余数补齐。掠夺仍先扣除仓库保护且不取得黄金；征服未接管城市时，黄金与其他普通资源共同占用负重。双方战报、返程携带和守方扣除均使用限制后的实际数量，未装载资源留在守方。NPC特殊掉落钻石沿用独立奖励规则，不占物资负重。

接管城市时，普通库存直接留在新取得的城市，不装入返程行军，因此不按搬运负重截断。

## 俘虏条件

开启占领的讨伐获胜时，实际参战的玩家守城指挥官忠诚为 0，则转入攻方出发城市的参谋部待命。此条件独立于城池接管资格；名额已满或敌城民心未归零时也可俘虏。

军官保留原 ID、姓名、星级、等级、属性、经验、技能、装备及装备属性、培养点、履历、俸禄和时间记录，仅改变所属玩家、城市槽位和职务（待命）。忠诚仍为 0，可通过赏赐培养。军官身上的装备一起转籍，原玩家不能继续操作该军官或装备。

战斗会话记录开战时的守城指挥官 ID，避免战中更换任命导致俘虏另一名军官。没有军官参战的新会话记录 0；迁移前的历史会话以原城市当前指挥官兼容读取。NPC、野地、关闭占领和败战不触发玩家敌将转籍。

同场接管与俘虏时，先转籍符合条件的指挥官，再清除城市其他军事资产。双方战报记录接管结果和被俘将领，任务仅在真实结果发生时累计。

## 战报中的城市民心

两种动作均显示“讨伐报告”，另列“行动配置”与“接管结果”。真实接管以 `targetType=player`、`cityConquered=true` 和 `cityTakeoverReason=''` 的本场结算快照为依据；缺少接管快照的历史征服奖励标记不补算为城市归属转移，NPC／流寇胜利显示“已击败”。已有战报 JSON 和正文不批量改写。

新战报在「战果结算」保留本方「民心变化」，并增加「敌军城市民心变化」，展示带正负号的实际增减值和「战后」数值，例如 `-2，战后 68`。玩家城市讨伐的征服、掠夺及三种短战模式均记录双方民心，无论是否满足接管条件；底层使用对应出征 action 的结算规则。

同类玩家城战报还冻结双方民怨变化及战后数值；双方本方与敌军城市民怨按接收者视角映射。NPC、野地和历史战报没有民怨快照时不显示该项。

民心按本次战斗涉及的城市结算，与接收战报时选中的城市无关。攻方取行军出发城市，守方取实际被攻击城市；主城民心以玩家记录为准，分城以对应城市记录为准。

| 战报接收者 | 本方民心 | 敌军城市民心 |
| --- | --- | --- |
| 攻方 | 攻方出发城市 | 守方被攻击城市 |
| 守方 | 守方被攻击城市 | 攻方出发城市 |

胜利方民心加 1，守城失败方减 2，进攻失败不影响出发城民心。战后民心限制在 0～100；战报记录 `实际变化 = 战后民心 - 战前民心`，不直接展示尚未应用上下限的固定奖励或惩罚。民心 `1 → 0` 显示 `-1，战后 0`，`0 → 0` 显示 `+0，战后 0`，`100 → 100` 显示 `+0，战后 100`。

真实玩家城征服战或掠夺战中，守城方战败增加民怨，按战前民心分档：71～100 民心时征服 +3、掠夺 +2；41～70 时征服 +2；0～40 时征服 +1。民心不高于70时掠夺不增加民怨；佯攻、袭扰、游击、守城胜利和攻方战败均不增加民怨。先按战前民心确定档位，再结算守城失败的民心 -2；民怨限制在0～100。主城民怨存于玩家经济数据，分城民怨存于被攻击城市，切换当前城市不改变结算对象。征服造成城权移交时先完成民怨结算，民怨随该城及原有经济数据保留。

双方战报 JSON 按接收者视角保存以下字段，持久化读取与在线推送使用同一快照，分享战报保留原持有人的攻守视角：

| 字段 | 含义 |
| --- | --- |
| `moraleChange` | 本方城市实际民心变化 |
| `moraleAfter` | 本方城市战后民心 |
| `enemyMoraleChange` | 敌军城市实际民心变化 |
| `enemyMoraleAfter` | 敌军城市战后民心 |

快照在双方民心结算后生成，作为接管判定的同一次结算结果保存。后续自然恢复、税率调整、切换城市、城权转移或主城恢复均不回写历史战报；主城失守后，即使原玩家提升其他分城或重建主城，战报仍保留原参战城市的民心。

未结算的城市民心在战斗结果中保持可空，不能与真实民心为 0 混同。NPC、野地及没有攻方城市数据的来袭战报，敌军民心字段为空；历史战报缺少这些字段时保留原展示。前端不显示空值或缺失的敌军民心项，真实数值为 0 时正常显示。新增字段保存在既有战报 JSON 中，无需新增数据库迁移，也不回填历史战报。

## 原玩家失守后的恢复

失去分城且该分城正在被选择时，切回原主城。主城失守时，优先提升一座已完成的分城为主城，迁移其城市槽位及返城、驻军引用；只有建设中的分城时选择第一座并使其可用。

最后一座城市失守时，在未占用的完整 2×2 陆地生成基础主城：市政厅、民居、农场、冶炼厂各一级，人口 150，粮食 2000、钢铁 3000、石油 1000、稀有资源 200、黄金 1000，不恢复原军队或军官，也不重置账号科技和道具。

在线城权变化事件清除旧城市请求上下文并刷新地图及状态；断线重连从账号当前城市重新加载，防止客户端继续使用失守城市的鉴权头。

其他城市已派出、尚未送达失守城的运输或调遣改为带着部队与物资返程。排队攻击在开战及手动打开战场时重新校验城权与战争资格，不能攻击已被己方接管的城市。
