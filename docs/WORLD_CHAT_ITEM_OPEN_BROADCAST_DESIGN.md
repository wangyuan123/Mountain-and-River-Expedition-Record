# 世界频道礼包与套装开启广播

## 广播范围与文案

- 覆盖仓库中 12 种整套装备箱、8 种主线阶段礼包及资源箱/礼包（含新增的单资源和分档资源礼包）。
- 格式：`玩家「统帅名」打开了「礼包/装备箱名」，获得：奖励名称×数量、……。`
- 优先使用玩家展示名，未设置时使用用户名；装备箱沿用实际道具名，不把装备穿戴误报为开启套装。
- 只在真正消耗容器并发奖成功后广播一次；购买、领取未开启礼包、普通道具使用和失败请求不广播。
- 打开礼包获得装备箱时，只播报该装备箱的奖励；之后实际开启装备箱时再单独播报三件装备。

## 奖励与事务

- 资源奖励取发奖前后的实际增量；黄金箱自 2026-10-27 起改为固定奖励，具体数量见[资源商城定价设计](RESOURCE_SHOP_PRICING_20261027.md)。
- 阶段礼包额外道具、整套装备名称与数量复用本次实际发放记录。
- 资源已达存储上限、实际未增加时不宣称获得该资源；全部未增加则明确显示无新增奖励。
- 系统聊天记录与扣道具、发奖励在同一事务内保存；复用 WebSocketPushService 的提交后广播机制，事务回滚不留下消息也不推送。

## 兼容性

- 复用既有系统消息、聊天历史及前端渲染，无新增样式或接口。
- 系统消息上限为 512 字，数据库通过 V115 扩展；玩家发言仍限制为 80 字，发言声望限制不影响系统广播。
- 每次成功开启一件容器产生一条记录，不新增冷却或抽奖概率，不改变既有奖励及返回结构。
