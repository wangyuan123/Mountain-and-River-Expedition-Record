## 已实现
- 二维地图，单指/鼠标拖动、惯性、双指缩放、滚轮缩放、键盘与按钮操作。
- 搜索坐标、类型筛选、主城定位、展开地图、列表回退。
- 区域摘要与目标详情独立读取，固定类型+ID操作，沿用现有出征、侦察、宣战、采集和放弃流程。
- 视野裁剪、区域缓存、外围预加载、请求去重/并发限制/超时取消、弱网重试。
- 画布库与图标按需加载，本地 PixiJS 固定版本及许可证。
- 自己的城市/领地标识、行军路线及移动标记；画布更新保持镜头。
- 账号和城市切换隔离；退出页面清理事件、渲染器与定时器。

## 使用与范围
重启后端，使新增地图接口生效，然后刷新前端并点击地图。无需数据库迁移。
当前提供局部战略视图；全图聚合概览、收藏坐标、军团集结标记仍为后续扩展。没有在真实手机上测量帧率，不将目标60帧视为已达成。
