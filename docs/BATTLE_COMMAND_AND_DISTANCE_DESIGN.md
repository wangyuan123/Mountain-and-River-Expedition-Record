**文档版本**：`battle-tactics-v5-20261013`

**战斗规则**：`balance-v13-contact-movement-20261012`
**核心定位**：战中实时指挥微操、两阶段回合制战棋结算与自适应战场距离体系。

## 一、 设计背景与核心哲学

在早期版本中，战场距离采用静态固定的 `2200`（野地战斗）与 `3000`（城战/对战）。这种静态设计带来了诸多体验与数值矛盾：
1. **垃圾跑图回合严重**：3000 距离下加兰德步兵（速度 3，步长 150）需要对走近 10 个回合才能接敌；而在攻打只有固定工事（速度 0）的城池时，攻方步兵需要单向跑 18 个回合，极易触发 30 回合超时判负。
2. **战术指挥空间缺失**：纯数值自动推进碰撞，玩家无法在战中进行拉扯、选位、集火和避险。
3. **兵种移速尺度割裂**：早期特种兵移速被误设为 13（比战斗机还快），十轮卡车移速为 8（比轻坦还快），导致混编部队一踩油门便瞬间脱节。

**本方案确立的核心设计哲学**：
> **“让距离服务于战术情境（Context-Driven），消灭无意义的垃圾跑图回合（Fast Engagement），并赋予玩家调控交火距离与拉扯走位的策略博弈空间（Tactical Agency）。”**

## 二、 动态战场距离系统

### 1. 动态距离公式

初始距离为 `max_攻守存活兵种组合(3 × (攻方步长 + 守方步长) + max(攻方有效射程, 守方有效射程)) + 100`。每个步长与实际机动一致，取 `floor(基础速度 × 装备战场速度倍率 × 引擎科技倍率 × 司令官学识倍率 × 50)`；不包含周期闪电突击、地图行军令或机场行军加成。有效射程包含武器射程科技。纯工事守方步长为0，司令官学识不会让工事移动。

取消1000最低宽度，避免低速、短射程步兵被额外拉长到第五回合才开火；速度和射程按真实兵种组合计算，避免把最快战斗机与最远射程反坦克火箭车叠成不存在的单位。第三回合全速相向前进后，任何组合仍至少超出较长射程100点，便于在战场上看清安全间隔。

### 2. 首次交战与回合节奏

每回合先统一机动，再用更新后的坐标判断交火，距离等于射程即可开火。新建战场通过初始距离保证前三回合不能攻击到对方，最早第四回合交火；不额外设置禁火开关。持续相向前进的常规编成第四回合可首次交战，待命、后退、后勤默认不前进或较低实际速度仍可延后接敌。首次交战表示至少一方获得射程内目标，不保证短射程一方同时能还击。

例如双方都是无科技、无司令官步兵，步长200、射程160，初始距离1460；第三回合机动后相距260，第四回合抵达同一接触点并开火。纯反坦克火箭车互战的步长250、射程1600，初始距离3200；第三回合相距1700，第四回合相距1200并齐射。若双方反坦克火箭车的司令官综合学识均为100，步长为275，初始距离3350；第三回合仍相距1700，第四回合相距1150并齐射。

首次实际交战回合E持久化，八项战斗技能在E、E+3、E+6…回合共同生效，脱离射程不重置。闪电突击在第E回合只即时影响同射程交火先手，后续生效回合同时影响机动与先手。

### 3. 反坦克火箭车射程调整与开火边界

2026-10-10 将反坦克火箭车基础射程由2000降至1600，削弱20%。保留远程对地和反装甲职责，缩短反坦克火箭车独占火力窗口；对空攻击11.5、其他攻击属性、移速及专项倍率沿用当前配置。盟军与日军反坦克火箭车共用该射程，首页和军队页说明、战术面板均从同一兵种属性读取。

有效射程为 `floor(1600 × (1 + 0.10 × 武器射程科技等级))`。初始距离、交火先手、默认索敌、指定集火和余伤切换目标均按有效射程执行，距离等于射程可开火。余伤切换后必须重新检查新目标距离；未进入射程的目标不能消耗攻击份额。

| 武器射程科技 | 有效射程 | 可开火边界 | 超出边界 |
| --- | --- | --- | --- |
| 0级 | 1600 | 距离1600可开火 | 距离1601不可开火 |
| 2级 | 1920 | 距离1920可开火 | 距离1921不可开火 |

降低射程也会降低反坦克火箭车主导的战场初始距离，因此不承诺所有阵容的首次交火都会推迟。纯反坦克火箭车互战按上一节例子在第四回合交火；混编战场的距离由真实兵种组合决定，需要按实际编成与指令判断。

### 4. 纯工事攻城

工事射程同样参与初始距离计算，城防战场不会固定收敛到1200～1500。无科技、无司令官步兵攻击单独碉堡时，初始距离为1750；步兵每回合前进200，第三回合相距1150，第四回合相距950，碉堡可先开火，步兵需要继续推进至自身160射程。

新距离只在创建战场时计算，进行中的会话继续使用已保存的初始距离和坐标，历史战报保留原回合及伤害。

### 5. 2026-10-13 工事射程调整后的火箭车征服战

反坦克炮基础射程由3850降至1850，榴弹炮由3950降至1850，与防空炮一致；碉堡基础射程仍为1050。火箭车基础速度为5、基础射程1600。以下按纯火箭车持续前进，守方只有反坦克炮、榴弹炮或防空炮计算；三类工事原地防守，不计战损、装备、司令官、军官属性及技能。满科技在本节指武器射程与燃烧引擎均为10级，守方仅武器射程科技影响几何结果。

`火箭车步长 s = floor(5 × (1 + 0.05 × 燃烧引擎等级) × 50)`

`火箭车射程 R = floor(1600 × (1 + 0.10 × 武器射程等级))`

`工事射程 F = floor(1850 × (1 + 0.10 × 守方武器射程等级))`

`当前开局距离 D = 3 × s + max(R, F) + 100`

每回合先机动再开火：火箭车首次开火回合为 `ceil((D - R) / s)`，接触回合为 `ceil(D / s)`。接触时剩余步长受敌军位置限制，双方距离归零；火箭车没有贴脸额外伤害倍率。表内是从第1回合起计的理论几何回合，不是消灭守军或征服成功所需回合。

| 火箭车科技 | 守方科技 | 火箭车步长 | 火箭车射程 | 工事射程 | 开局距离 | 火箭车首次开火 | 距离归零（贴脸） |
| --- | --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 0级 | 0级 | 250 | 1600 | 1850 | 2700 | 第5回合 | 第11回合 |
| 10级 | 10级 | 375 | 3200 | 3700 | 4925 | 第5回合 | 第14回合 |
| 10级 | 0级 | 375 | 3200 | 1850 | 4425 | 第4回合 | 第12回合 |
| 0级 | 10级 | 250 | 1600 | 3700 | 4550 | 第12回合 | 第19回合 |

双方同科技时工事均在第4回合进入开火范围，火箭车在第5回合获得射程内目标；满科技双方的射程增长同时拉长开局距离，因此火箭车虽然移动更快，仍较0科技双方更晚接触。若守方只有碉堡，同科技0级双方的火箭车在第4回合开火、第10回合接触；同科技10级双方在第4回合开火、第12回合接触。存在移动驻军、混编、后退命令、战损或其他速度加成时，应按真实编组重新计算。

以上已用当前 `BattleService` 开局距离与逐回合机动/交火核对：每回合复原双方兵数，仅验证几何边界，避免全歼提前结束模拟。当前征服战仍使用 D，没有额外+500距离，城防等级也不增加工事射程；这两项仍是 [城防改造提案](CITY_FORTIFICATION_DESIGN_20261012.md#射程与动态战场距离用户确认规则)。战斗上限为24回合，理论接触落在上限内不代表能够完成征服。

## 三、 战场空间与“阵地底线”物理规则

```
攻方阵地底线 (X = 0) <──────────────── 初始距离 D ────────────────> 守方阵地底线 (X = D)
* 攻方不可后退越过 0                                                 * 守方不可后退越过 D
```

1. **一维坐标轴**：
   - 攻方阵地基准线定在坐标 `0`，向前推进为正方向（$+X$）；
   - 守方阵地基准线定在坐标 $D$，向前推进为负方向（$-X$）；
   - 攻守双方任意两单位之间的相对物理距离为：$\text{Distance} = \max(0, \text{enemyX} - \text{mineX})$。
2. **阵地底线（Baseline Boundary）**：
   - 攻方坐标必须满足 $\text{pos} \ge 0$，守方坐标必须满足 $\text{pos} \le D$；
   - 开战初始，双方所有部队均位于各自阵地底线（攻方坐标统一为 `0`，守方坐标统一为 $D$），**开局点击【后退】无法向后移动**（已触碰底线）；
   - 这一规则从物理上彻底封死了“无限倒车风筝拖平局”的恶性漏洞。
3. **取消开局前置偏移（Formation Offset = 0）**：
   - 开战起点完全平齐对齐，取消任何兵种的开局前置坐标偏移；
   - 重坦（IS-2）与其他单位同一起点出发，其前排掩护效果完全依赖战中机动与站位距离动态判定。

## 五、 两阶段回合制结算引擎（Phase-based Execution）

### 玩家指挥、司令官与带兵将领

玩家（统帅）的机动、集火与托管命令先决定位置及目标；司令官四属性提供常驻攻击、防御、生命、速度倍率，再与带兵将领周期属性及技能独立组合。司令官有效属性含自身成长、装备和套装，每点+0.1%，所有技能均不进入战场技能列表；带兵将领军事、防御仍在第3、6、9…回合生效，八项技能仍以首次交战E为周期起点。

每城一名司令官，攻方取行军来源城、守方取实际目标城，合编援军共享守城司令官。创建会话时保存双方姓名、身份和四属性快照，初始距离、各回合机动、同射程先手及战报共用这份快照；开战后切城、换任、换装或拆楼均不改变本场。市长和城市指挥官原功能保留。完整组合公式、技能边界和迁移见 [司令部与司令官设计](HEADQUARTERS_COMMANDER_DESIGN_20261010.md)。

为了彻底解决旧逻辑中“单兵种边移动边开火导致后续顺位兵种距离失真”的硬伤，回合结算重构为规范的**两阶段（Two-Phase）模型**：

```
       ┌─────────────────────────────────────────────────────────────┐
       │             第 R 回合：接收双方指令 (或读取默认托管)         │
       │             指令集: 前进(ADVANCE) / 后退(RETREAT) /         │
       │                     待命(HOLD)    / 目标(focusTarget)       │
       └──────────────────────────────┬──────────────────────────────┘
                                      │
                                      ▼
       ┌─────────────────────────────────────────────────────────────┐
       │ 【第一阶段：统一机动阶段 (Movement Phase)】                 │
       │ 1. 攻守双方所有存活单位同时结算位移:                         │
       │    攻方: 前进 +step, 后退 -step, 边界约束 [0, D]             │
       │    守方: 前进 -step, 后退 +step, 边界约束 [0, D]             │
       │ 2. 刷新全场各兵种坐标字典 (minePos, enemyPos)               │
       │ 3. 记录机动日志 (如: 后退 400 距离->1800)                    │
       └──────────────────────────────┬──────────────────────────────┘
                                      │
                                      ▼
       ┌─────────────────────────────────────────────────────────────┐
       │ 【第二阶段：战术交火阶段 (Combat Phase)】                   │
       │ 1. 行动序列排序: 全场单位按 [有效射程降序, 速度降序] 排序   │
       │ 2. 目标索敌:                                                │
       │    a. 在线指定 focusTarget 且目标在射程内，优先集火         │
       │    b. 否则优先攻击射程内同兵种，无则攻击最近射程内敌军     │
       │ 3. 开火结算 (边打边退):                                     │
       │    即使本回合执行了【后退】，只要当前物理距离 <= 射程，     │
       │    该单位依然打出完整齐射火力并计算伤亡                     │
       │ 4. 实时扣除伤亡，阵亡单位移出战场                           │
       └─────────────────────────────────────────────────────────────┘
```

### 同步接触与剩余步长

双方先依据回合开始坐标按速度分摊接敌路程。当混编中的前排已经接触时，后续前进单位用本回合剩余步长继续抵达实际接触点；补齐仍受最近存活敌军阻挡，不会超速或越过敌军。待命、后退和零速单位不参与补齐。双方补齐统一读取第一轮机动后的坐标快照，结果不依赖兵种遍历顺序。

贴脸伤害仍要求实际攻击目标距离严格为0：步兵×2，轻坦、重坦和特种兵×1.5。与另一兵种前排接触不能给尚在后方的目标提供加成，余伤换目标时再次检查距离。

### “边打边退（Hit-and-Run）”风筝机制
*   单位在执行【后退】时，第一阶段先拉开 $\text{spd} \times 50$ 的距离；
*   在第二阶段开火时，若拉开距离后的最新距离仍在其射程内，单位正常打出攻击；
*   若敌人移速更快并在第一阶段贴近，后撤未能拉脱射程，双方将在新距离交火；
*   前进、待命或后退改变实际位置与交火窗口；特种兵基础移速8、反坦克火箭车射程1600、防空装甲车基础移速7。

## 六、 战报指令还原规范

战报保存实际机动与交火结果；同一兵种本回合的首次攻击、余伤与机动合并显示，便于按回合复盘。以下展示字段格式，省略号表示本次实际数值：

- 前进：`我方反坦克火箭车-喀秋莎（BM-13）(100) [前进] 推进250 -> 坐标250 (距敌...)`；距敌/距我取双方全部机动完成后距最近存活敌军的真实距离。
- 原地前进：只有距最近存活敌军为0才显示`已接触前排`，有间距则显示`未能推进`；不再将零位移无条件标成`已贴脸`。
- 后退或待命记录实际坐标；在底线后退受阻，距离仍满足射程时可正常开火。
- 反坦克火箭车攻击重坦：`齐射敌重型坦克-斯大林（IS-2）(...) [倍率×3.0 相克 前排承伤] 对地攻击100 本次原始火力... 伤害... 击毁... 剩余攻击额度...%`。
- 防空装甲车攻击战斗机：`[倍率×2.5 相克] 对空攻击34 ...`；日志将33.5四舍五入显示为34，实际结算仍使用33.5。
- 未列专项组合不显示相克倍率标签；指定集火使用`指定集火`标签，绝境反击使用`绝境反击`标签。

所有兵种每次主动开火及余伤攻击均在结果末尾追加`目标距离<数值>`；反坦克火箭车另保留`有效射程<数值>`，例如二级武器射程科技下为`有效射程1920 目标距离1920`。机动距离指最近前排，攻击距离指当前被攻击目标；两个目标不同时，这两项可以不同。`贴脸×1.5`或`贴脸×2.0`仅在当前目标距离为0且兵种适用时显示。没有实际开火时不追加攻击结果字段。

战场面板按我方/敌方视角展示开战司令官及四项倍率，战报保存实际攻守双方快照并标明“技能不参与”；各回合日志区分常驻司令官和带兵将领属性/技能。历史战报保留生成时的规则版本与伤害，不用新倍率改写旧结果；缺司令官字段时沿用旧展示。技能周期与倍率关系见 [军官技能池记录](../output/officer-skills-design-record.md)。

新战报的「战果结算」同时展示本方民心和敌军城市民心的实际变化及战后值。攻方看到守方目标城，守方看到攻方出发城；民心按 0～100 上下限截断后的实际差值记录，接管或重建不改写本场快照。旧战报及没有敌军城市民心数据的战报不显示敌军民心项，真实零值正常展示。字段与边界规则见 [战报中的城市民心](PLAYER_CITY_CONQUEST.md#战报中的城市民心)。
