# 兵种攻击按目标领域拆分

历史规则版本：`balance-v3-domains-20260918`。本文件保留上一轮设计记录；当前配置与验证以 [兵种微调 v5](BALANCE_TUNING_20260918.md) 为准。v4 增加独立攻坚攻击，并调整兵种职责与攻击数值。

## 设计原则

每个兵种和城防都直接定义 `atkGround`、`atkAir`、`atkSea`。攻击地面部队或城防时读取对地攻击，攻击飞机时读取对空攻击，攻击舰船时读取对海攻击。三项独立展示、独立调整，值为 0 就没有对应攻击能力；攻击科技、军官和连击不能把 0 变成可用武器。

专项克制只保留反步兵、反装甲、反潜等差异。原来的通用空地海倍率移入三项面板值，避免“对空攻击已经提高，又整体乘一次对空增益”。例如突击炮对空为 60，直接使用 60；战斗机对空为 67，仅对轰炸机另有 1.15 的专项拦截倍率。

保留当前的兵种分工：突击炮承担机动防空，火箭承担远程对地，重坦承担掩护，特种兵负责渗透。防御、生命、射程、速度、造价、人口和耗粮延续上一版。本轮不新建兵种。

## 专项克制

未列出为 ×1；具体目标优先于类别。

| 兵种 | 专项倍率 |
| --- | --- |
| 步兵 | 装甲 ×0.5 |
| 摩托兵 | 步兵类 ×2；装甲 ×0.5 |
| 装甲车 | 步兵类 ×1.75 |
| 轻坦 | 装甲车 ×1.5；火炮 ×2 |
| 重坦 | 轻坦 ×2.25 |
| 火箭 | 重坦 ×2.5；其他装甲 ×1.75；特种兵 ×0.75；其他步兵类、碉堡 ×1.5 |
| 特种兵 | 火炮、卡车 ×2；装甲 ×0.5 |
| 战斗机 | 轰炸机 ×1.15 |
| 轰炸机 | 重坦、碉堡 ×2；其他装甲 ×1.5；潜艇 ×0.25 |
| 驱逐舰 | 潜艇 ×2.5；战列舰 ×0.5；航母 ×0.75 |
| 潜艇 | 战列舰、航母 ×3；驱逐舰 ×0.35；潜艇 ×0.2 |
| 战列舰 | 驱逐舰 ×1.75；潜艇 ×0.25 |
| 航母 | 步兵类、装甲、火炮 ×1.25；潜艇 ×0.25 |
| 碉堡、榴弹炮 | 步兵类 ×1.5 |
| 反坦克炮 | 装甲 ×2 |

突击炮、防空炮等直接依赖其高对空攻击，不再叠加旧的对空 ×2。对海攻击并不等同于反潜专长：例如轰炸机 55 对海攻击作用于潜艇时，还会受到 ×0.25 的反潜效率限制。

## 结算、选敌与剩余攻击

单个目标的完整一轮伤害：

`对应领域攻击 × 当前兵数 × 攻击加成 × 连击倍率 × 专项克制 × 100/(100 + 5 × 有效防御)`

一次行动共享攻击额度，而不是让三套武器各打一整轮。目标被全歼时，扣除实际消耗的额度，再用剩余额度攻击新目标。切换到不同领域时重新读取相应攻击值、防御和专项倍率。

例：10 门突击炮攻击 1 架侦察机和 100 辆重坦，无科技和军官加成，目标均在射程内。对空攻击 60，侦察机 30 血、6 防，消耗 `30 ÷ (60/1.3) = 0.65` 份额度。剩余 9.35 份转为对地攻击 8，对重坦造成 `9.35×8/4 = 18.7` 伤害，绝不会继续使用对空攻击 60 或额外获得完整一轮攻击。

- 先过滤无法攻击的目标，再检查射程和重坦掩护。
- 候选目标按“对应领域攻击 × 专项倍率”排序，然后比较距离、生命、ID。例如突击炮优先攻击飞机，而不因地面类别倍率相同误选地面目标。
- 移动只朝可攻击目标靠近；近处不能攻击的飞机不会让步兵停在原地。
- 没有可攻击目标时待命。双方不能伤害对方时沿用 30 回合上限，攻方撤退，保留实际幸存者。单一地面军不能靠人数强行击落完全无法攻击的飞机。
- 侦察专用空战直接读取侦察机的对空攻击。概览战力与击杀经验使用 `peakAttack()` 明确取得三项最高值；这个估值不参与实际对目标伤害计算，也不用于预测胜负。

## 展示与验证

军队、城防面板展示三项攻击；军队页说明 0 的含义。战报每次命中注明使用的是对地、对空或对海攻击，并记录剩余攻击额度。静态资源版本已更新，避免浏览器继续展示旧面板。

验证结果：

- 后端 252 项通过，1 项 MySQL 迁移测试因缺少 `WARGAME_TEST_MYSQL_URL` 跳过。
- 前端 150 项通过，包括全部兵种、城防的三域攻击及其他属性与服务端一致性。
- 20,480 场固定种子对照重新使用 v3 运行；128 个等资源/加权资源场景的 16 组主要克制均为每场景 64/64 全歼。14 个战斗兵种仍均有等资源反制。
- 新增实际行动测试：零对空不能被科技或技能绕过；余伤不能跨入无法攻击的领域；弱对空武器不继承主炮攻击；潜艇只攻击海军；移动忽略不可攻击的近处目标；双方无法互伤时无虚构战损。
- 既有跨目标伤害守恒、空转地换算、攻守对称、技能、城墙、PVE、侦察、行军、伤兵回归通过。
