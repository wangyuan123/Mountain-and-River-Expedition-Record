# 资源野地定点刷新设计

## 目标

让资源野地在长期运行中循环供应，同时避免固定资源点被长期把守。已耗尽且无主的野地从地图消失，在下一次固定刷新时间于新的随机空位重生。

## 时间规则

- 每天北京时间 **00:00、03:00、06:00、09:00、12:00、15:00、18:00、21:00** 执行一次；“24 点”是次日 00:00。
- 使用 `Asia/Shanghai` 时区，不依赖服务器所在时区。没有额外的 6 小时冷却，也不按服务器启动时间间隔计算。
- 满足条件的野地在下一个固定时间点处理。例如 02:59 耗尽并变为无主，则 03:00 参与刷新；03:01 才变为无主，则 06:00 参与刷新。
- 服务器停机错过的刷新点不补跑，恢复运行后等待下一个固定时间点。关闭 `game.scheduling.enabled` 时也不会自动刷新。

## 野地生命周期

1. **仍有资源**：野地保持原位置。玩家放弃未耗尽野地，仍按原有放弃逻辑处理，不参与异地重生。
2. **资源耗尽且仍被占领**：继续显示在原位置；占领、采集或驻军中的野地不会被调度器迁移。
3. **耗尽后变为无主**：玩家放弃已耗尽野地，或未占领野地被掠夺至耗尽时，立即从地图列表和目标详情中隐藏。数据库记录及 ID 暂时保留，用于识别待刷新状态和保护未结束行军引用。
4. **定点刷新**：仅处理无主、已耗尽且没有未结束行军引用的野地。随机选取与原位置同为陆地或同为海洋的空位，明确排除原坐标及现有野地、城市完整占地、NPC 所占坐标；找不到空位时留待下一个刷新点。
5. **异地重生**：复用原野地 ID、类型和等级；资源总量恢复为 `等级 × 160000`，`mined` 归零，守军按等级和陆海属性重新生成，侦察状态重置。重生后才重新出现在地图上。

## 兵种约束

- 陆地野地刷新使用陆军/空军配置，不生成海军。
- 海洋野地刷新使用潜艇、驱逐舰、战列舰、航母配置，不生成陆军或飞机。
- 继续使用 `WorldConfig.wildGarrison(level, sea)` 的等级兵力倍率。

## 实现

- `wild_tiles.depleted_at` 记录资源耗尽时间和待刷新状态，不再用于计算等待时长。无主且该字段非空的野地为隐藏待刷新状态。
- 远征采集、驻军采集及掠夺把资源消耗至上限时写入该字段；放弃旧存档中已耗尽但缺少该字段的野地时补写。
- `WildTileRefreshScheduler` 在每天八个固定北京时间点扫描所有世界，将符合条件的隐藏野地迁移至随机空位。
- Flyway 迁移 `V69__wild_tile_refresh.sql` 增加数据库字段。

## 供给说明

当前实现是**循环迁移已有野地**，不是每次刷新额外生成一批野地。类型、等级和总数量保持不变，尚未实现按区域最低数量或在线玩家数量扩容，也不能保证每个局部区域始终有足够野地。有未结束行军或无合适空位时，个别野地会顺延到后续刷新点。

## 2026-10-06 据点四格刷新约束

动态平衡补足日寇据点、已击败流寇定时迁移以及 NPC 城市重生，均检查完整 2×2 四格。四格必须在开放战区边界内、全部为空闲且地形一致（陆地据点全为陆地，海上编队全为海域）。现有 NPC 与流寇完整四格参与避让；每次生成或迁移后立即预留全部四格，防止同批目标重叠。没有合适四格时延后补点或刷新，不强行布置。野地仍按单格刷新；已有据点不批量迁移。
