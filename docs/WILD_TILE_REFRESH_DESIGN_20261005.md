# NPC、流寇与资源野地生成刷新设计

更新时间：2026-10-12。当前规则以本节及“分块密度均衡”章节为准，带日期的旧占地调整章节保留为变更记录。

NPC 城市/要塞（`npc`）已取消，不再补足 12 座人口或战后异地替换。旧城仅在仍有行军、战斗引用时保留供结算使用，地图隐藏并拒绝新出征，引用结束后清理。陆地 `bandit` 统一名为“寇”（记录附 `Lv.等级`）；海洋守军继续保留，定时刷新和 3,300 个陆地等级配额沿用。

## 目标

让资源野地和 NPC／流寇在长期运行中循环供应，刷新和补生优先进入同类目标密度较低的区域。资源野地与 NPC／流寇分别趋于区域均衡，沿用现有地形、占地、间距、数量和等级规则。

## 目标分类与刷新入口

| 目标或入口 | 触发条件 | 生成与状态规则 |
| --- | --- | --- |
| 旧 NPC 城市 `npc` | 启动及定时人口维护 | 不再生成；没有行军或战斗引用时清理，有引用时仅保留用于旧战斗结算 |
| 陆地寇、海域守军 `bandit` | 已击败且没有相关行军引用，在下一个固定刷新点处理 | 复用 ID、等级和军官，陆地名称统一为“寇”，海洋保留原名称；异地恢复对应等级守军并清除击败状态；陆地仍在陆地，海域仍在海域 |
| 资源野地 `wild` | 耗尽且无主、没有相关行军引用，在下一个固定刷新点处理 | 复用 ID、类型、等级，在低资源密度的同类地形分块重生，恢复资源和守军并清除侦察状态 |
| 陆地流寇配额补足 | 世界生成、服务器启动及每次定时刷新后检查 | 按等级补足缺额，新增目标优先进入低 NPC 密度陆地分块；等待刷新的已击败记录仍计入数量配额 |
| 全图初始内容与近城供给 | 首次生成、内容版本升级或新玩家建主城 | 保留现有供给预算、版本控制、近城半径和数量下限，在允许范围内按分块密度选择实际坐标 |

NPC 城市人口维护仅清理退役记录，岛屿与管理员也不再生成该类城市。陆地流寇目标配额为 1～20 级每级 120 个、21～25 级每级 100 个、26～30 级每级 80 个，合计 3,300 个，海洋编队与 NPC 城市不计入这项配额。

## 时间规则

- 每天北京时间 **00:00、03:00、06:00、09:00、12:00、15:00、18:00、21:00** 执行一次；“24 点”是次日 00:00。
- 使用 `Asia/Shanghai` 时区，不依赖服务器所在时区。没有额外的 6 小时冷却，也不按服务器启动时间间隔计算。
- 满足条件的野地在下一个固定时间点处理。例如 02:59 耗尽并变为无主，则 03:00 参与刷新；03:01 才变为无主，则 06:00 参与刷新。
- 服务器停机错过的刷新点不补跑，恢复运行后等待下一个固定时间点。关闭 `game.scheduling.enabled` 时也不会自动刷新。

## 野地生命周期

1. **仍有资源**：野地保持原位置。玩家放弃未耗尽野地，仍按原有放弃逻辑处理，不参与异地重生。
2. **资源耗尽且仍被占领**：继续显示在原位置；占领、采集或驻军中的野地不会被调度器迁移。
3. **耗尽后变为无主**：玩家放弃已耗尽野地，或未占领野地被掠夺至耗尽时，立即从地图列表和目标详情中隐藏。数据库记录及 ID 暂时保留，用于识别待刷新状态和保护未结束行军引用。
4. **定点刷新**：仅处理无主、已耗尽且没有未结束行军引用的野地。优先在同类资源密度较低的 16×16 分块内随机选取与原位置同为陆地或同为海洋的空位，明确排除原坐标及现有野地、城市完整占地、NPC 所占坐标；找不到空位时留待下一个刷新点。
5. **异地重生**：复用原野地 ID、类型和等级；资源总量恢复为 `等级 × 160000`，`mined` 归零，守军按等级和陆海属性重新生成，侦察状态重置。重生后才重新出现在地图上。

## 兵种约束

- 陆地野地刷新使用陆军/空军配置，不生成海军。
- 海洋野地刷新使用潜艇、驱逐舰、战列舰、航母配置，不生成陆军或飞机。
- 继续使用 `WorldConfig.wildGarrison(level, sea)` 的等级兵力倍率。

## 实现

- `wild_tiles.depleted_at` 记录资源耗尽时间和待刷新状态，不再用于计算等待时长。无主且该字段非空的野地为隐藏待刷新状态。
- 远征采集、驻军采集及掠夺把资源消耗至上限时写入该字段；放弃旧存档中已耗尽但缺少该字段的野地时补写。
- `WildTileRefreshScheduler` 在每天八个固定北京时间点扫描所有世界，将符合条件的隐藏野地迁移至同类密度较低分块内的随机空位。
- `BlockSpawnPlanner` 共用分块密度选点规则；同一批次保存可见目标数量和候选空格，每次放置后立即更新计数与占位。
- 定时任务先迁移耗尽废弃野地，再迁移已击败流寇，随后维护陆地流寇等级配额。世界锁保护迁移和整批补点，未结束行军引用仍阻止定时迁移。
- Flyway 迁移 `V69__wild_tile_refresh.sql` 增加数据库字段。

## 供给说明

当前实现是**循环迁移已有野地**，类型、等级和总数量保持不变。刷新优先补到同类密度较低的分块，不按在线玩家数量扩容，也不保证每个局部区域始终有足够野地。有未结束行军或无合适空位时，个别野地会顺延到后续刷新点。

动态平衡补足日寇据点与已击败流寇迁移检查完整 2×2 四格；NPC 城市重生改为检查 1×1 单格（2026-10-08 更新）。完整占地必须在开放战区边界内、全部为空闲且地形一致（陆地目标全为陆地，海上编队全为海域）。现有 NPC 城市按一格、流寇按四格参与占地避让；每次生成或迁移后立即预留对应占地，防止同批目标重叠。没有合适位置时延后补点或刷新，不强行布置。NPC 人口维护会迁移占地冲突或间距不足的目标，保留有行军引用的目标；布点间隔与实际占地区别见 [城市与据点占地规则](MAP_CITY_FOOTPRINT.md)。野地仍按单格刷新。

## 2026-10-11 分块密度均衡

### 分块与统计口径

开放战区按 16×16 格分块，布点边界沿用各入口的开放范围。定时刷新与陆地配额维护取 `min(WorldConfig.SIZE, 世界尺寸)`，当前基础开放边长为 400；展示世界尺寸不用于扩大自动布点范围。

| 密度类别 | 统计对象 | 陆海划分 |
| --- | --- | --- |
| 资源密度 | 所有可见 `WildTile` 记录，包括已占领野地；耗尽且废弃的隐藏野地不计入 | 按目标坐标地形分别统计陆地与海域 |
| NPC 密度 | 可见 NPC 城市与流寇／据点／海上编队合并统计；已击败记录不计入 | 按目标坐标地形分别统计陆地与海域 |

每个目标计为一个地图点，资源储量、资源类型和等级不作为密度权重。同级别或同种资源在各块的数量不要求一致；资源与 NPC 的总量仍由各自的供给规则决定。

### 选点算法

对存在合法候选空格的分块比较新增后的密度：

`D = (N + 1) / A`

- `N`：本块当前可见同类目标数，包含本批次已成功放置的目标。
- `A`：本块在开放范围内的同类地形总格数，包含已被占用的地形格；不是剩余空位数。

优先选择 `D` 最低的块；密度相同随机选块，块内随机取点。海岸、岛屿和边缘小块按实际地形面积折算。例如 256 格陆地上有 4 个目标、16 格陆地上有 1 个目标时，新增后的密度分别为 `5/256` 与 `2/16`，优先选择前者。

选点时继续排除已预留占位及迁移目标的原坐标，NPC／流寇额外遵守间距禁区。低密度块没有合法空位时，尝试其他可用块；成功选点立即增加本块计数并预留占位，后续目标使用更新后的密度。已被新占位或间距约束挡住的候选会从本批列表移除，避免每补一个目标都重新扫描全图。

### 各入口的供给与位置约束

| 入口 | 保留的供给或位置规则 |
| --- | --- |
| NPC 城市补生 | 陆地单格，随机 3～8 级，与 NPC／流寇保留外围一格间隔 |
| 流寇定时刷新 | 同地形迁移，保留等级、数量和身份；旧流寇坐标及本批新坐标均参与占位避让 |
| 野地定时刷新 | 同地形迁移，保留类型与等级，资源总量恢复为 `等级 × 160000` |
| 陆地流寇缺额补点 | 维持全地图 3,300 个的等级配额，缺多少补多少；已击败记录计配额但不计可见密度 |
| 全图陆地内容补充 | 每个原始可用分块最多贡献 1 个 NPC、2 块资源的预算，再按全图密度分配实际位置；不是每块必须固定放置这些数量 |
| 海洋内容补充 | 两轮预算，每轮每个有可用海格的分块贡献 1 个编队，实际坐标按海域 NPC 密度分配 |
| 近城供给 | 可用空间足够时，曼哈顿距离 3 格内至少 4 块、7 格内至少 8 块未占领野地，7 格内补足 2 个陆地 NPC；只在相应半径内选块与选点 |
| 雪原、岛屿和新手引导专用补给 | 首次生成沿用北方连片雪原、逐岛布点或引导路径规则；后续符合条件的普通定时刷新使用共用密度规则 |

NPC／流寇实际占地为 1×1 格，外围一格构成 3×3 布点禁区；玩家城市占地为 2×2 格。资源野地按单格校验当前批次已预留的占位，NPC 间距禁区用于 NPC／流寇之间的布点间隔，不扩大目标的实际占地。详见 [城市与据点占地规则](MAP_CITY_FOOTPRINT.md)。

### 既有地图与空间不足

已有正常目标通过后续刷新、补生和缺额补点逐步改善分布；占领、采集、驻军或有行军引用的目标继续遵守既有保护规则。占地冲突修复仍按原规则处理，不因区域密度差异而主动搬迁正常目标。

定时刷新和流寇配额补点在没有合法空位时顺延；NPC 城市即时替换在没有空闲陆地时报错，相关事务回滚。固定刷新点、目标总供给预算、等级配额及内容版本沿用原规则，本次分块选点不需要新增数据库字段或内容版本迁移。受可用空间和保护条件限制，区域密度只能逐步趋近，不能保证完全一致。
