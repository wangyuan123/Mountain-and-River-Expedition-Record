## 规则和数据边界

- 护盾仍累加时长；行军令同档刷新、高档替换，生效中的高档阻止低档消耗；动员令维持独立计时规则。预览和取消均不扣道具，确认请求不自动重试。
- 切城、换号或增益状态变化后，旧使用弹窗失效；网络结果不确定时提示同步库存和增益，避免重复消耗。
- 任命预览显示该军官自身贡献，包含装备和套装，不表示相对现任军官的净增量。战斗周期窗口与实际技能触发条件分开说明，不凭当前兵力推断历史战报触发结果。
- 粮食支撑时间仅使用当前城市的权威粮账，包含外来驻军耗粮；缺少数据时显示等待同步。详情默认折叠，定时刷新只更新文字，保留展开状态和焦点。
- 奖励汇总只查询状态，不自动领取；邮件只统计最新一页中未领取且未过期的附件，有后续页时明确提示继续检查。邮件未读数不当作可领奖数。
- 迁城清单与正式提交共用城市移动校验；清单通过不授予迁城资格，正式操作仍重新校验城市、库存、落点及占用状态。
- 修复装备箱生成目录回退到旧图标的问题，前端目录与生成源共同使用现有装备箱图片。
