# 按钮音效

游戏保留两种按钮反馈音：「确认」（默认）和「清脆机械碰撞」。玩家在设置页可关闭按钮音效、选择声音并调节音量；选择立即试听，偏好保存在当前浏览器。旧版套装偏好不再使用，但原有的开关和音量仍会恢复，声音回到「确认」。

所有普通可点击入口，包括建筑、升级、地图和返回按钮，统一使用玩家选定的声音。设置区的开关、下拉框和试听按钮自行控制播放，避免一次点击叠加两声。背景音乐独立控制。

音效由 `frontend/js/constants.js` 定义，在 `frontend/js/sound.js` 中用 Web Audio 合成和缓存，不请求外部素材。首次用户操作才创建设备。禁用按钮、后台页面、鼠标右键和输入过程不会播放；快速连点有 65ms 冷却，最多三个声音并发。静音会立即停止当前声音。

运行 `node --test frontend/tests/sound.test.cjs` 验证默认值、切换、持久化、点击和静音；打开 `/tests/sound-preview.html` 可试听两种声音及实际按钮反馈。

# 场景音效扩展（军校将领调遣）

军校招募刷新使用独立的 `AcademyAudio`（位于 `frontend/js/officer.js`）纯算法实时合成，与全局偏好及音量无缝联动：
- **公文印章盖戳**：350ms 触发，正弦低频 140Hz->42Hz 下潜加三角波摩擦，模拟机密调令盖印。
- **卡牌轻翻转**：680Hz->380Hz 微弱正弦波，连贯卡牌阶梯翻转时的轻柔切牌声。
- **名将破晓和弦**：遇 5 星名将触发，C5/E5/G5/C6 琶音大三和弦共振配合晶莹扫频，出货仪式感拉满。
- **静音与跳过机制**：读取 `Game.Sound.get()`，全局静音时不发声；点击即时跳过（Skip）或极速刷新时自动停止后续触发。详细规范参见 `docs/ACADEMY_REFRESH.md`。

# 核心战术情境音效（出征、交火、战胜、升级）

针对战略沙盘与战斗指挥的情境反馈，系统在 `G.Constants.gameSound` 中新增四组战术情境音效，采用 Web Audio 纯算法多层参数化合成（无外部网络依赖，兼备无损 WAV 双模式支持）：

### 1. 🚩 部队出征（dispatch）
- **触发时机**：出征准备页点击【出发!】/【出征讨伐】/【立即出征】。
- **方案 A（推荐）· 战术军号与军鼓齐鸣**：120Hz/45Hz 行军军鼓低音踏步 + G3-C4-E4-G4 经典昂扬军号动机 + 坚毅踏步重低音（约 1.1s）。
- **方案 B · 重装装甲机动推进**：48Hz~82Hz 重型柴油引擎轰鸣 + 履带机械啮合金属咔嗒声 + 嘹亮出动哨音。

### 2. ⚔️ 拦截战交火（firefight）
- **触发时机**：大地图截击战相遇交火中、或抵达拦截空域双方空战开火。
- **方案 A（推荐）· 截击机炮点射与凌空空爆**：防空机炮/重机枪三连点射（“哒-哒-哒”，6500Hz 超音速破裂音 + 机械后坐）+ 破空尖啸 + 130Hz~32Hz 凌空爆炸震波（约 1.0s）。
- **方案 B · 防空阵地密集齐射**：五连发密集速射连轰 + 凌空近炸破片散布。

### 3. 🏆 战斗指挥战胜（victory）
- **触发时机**：在线战术指挥回合战结束且判定获胜时（`result.win === true`）。
- **方案 A（推荐）· 凯旋辉煌军乐号角**：大调上行三和弦号角 (C5/E5 -> E5/G5 -> G5/B5) + 宏大辉煌主和弦 (C4+G4+C5+E5+C6) + 璀璨钟琴泛音 (2093Hz/2637Hz)（约 1.4s）。
- **方案 B · 战术果决胜歌**：军号断奏冲锋短句 + 战胜重鼓爆鸣。

### 4. 🔨 建筑升级完成（upgrade）
- **触发时机**：建筑施工倒计时归零升级完成，或使用加速道具秒建完成。
- **方案 A（推荐）· 工坊锻造金鸣与落成音阶**：双重清脆坚实铁锤击铁金属碰撞 (1480Hz/1760Hz) + 晶莹大三和弦水晶钟琴音阶 (E5 -> G#5 -> B5 -> E6)（约 1.15s）。
- **方案 B · 重工落锁与城邦钟鸣**：三级机械棘轮就位 + 重厚门栓落锁 + 恢弘市政主城钟声。

### 设置联动与生效控制（严格遵循玩家设置）
所有情境音效通过 `Game.Sound.play(name)` 统一调度，执行硬性静音判定：
`preferences.enabled && preferences.volume > 0 && !document.hidden`
当用户在设置面板中关闭音效或将反馈音量拖至 0% 时，所有出征、交火、战胜、升级音效均**绝对静音**，不触发任何音频输出。

### 试听与验证
- 试听页面：直接打开前端页面 `frontend/sound-preview.html`（或浏览器访问 `http://localhost:8081/sound-preview.html`），可实时调节全局开关、音量并一键对比试听各方案。
- 本地终端试听：`afplay frontend/audio/dispatch.wav` 等。
- 自动化测试：运行 `node --test frontend/tests/game-sound.test.cjs` 验证音效合成、边界限制与设置开关联动。
