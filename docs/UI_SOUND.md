# 按钮音效

游戏保留两种按钮反馈音：「确认」（默认）和「清脆机械碰撞」。玩家在设置页可关闭按钮音效、选择声音并调节音量；选择立即试听，偏好保存在当前浏览器。旧版套装偏好不再使用，但原有的开关和音量仍会恢复，声音回到「确认」。

所有普通可点击入口，包括建筑、升级、地图和返回按钮，统一使用玩家选定的声音。设置区的开关、下拉框和试听按钮自行控制播放，避免一次点击叠加两声。背景音乐独立控制。

音效由 `frontend/js/constants.js` 定义，在 `frontend/js/sound.js` 中用 Web Audio 合成和缓存，不请求外部素材。首次用户操作才创建设备。禁用按钮、后台页面、鼠标右键和输入过程不会播放；快速连点有 65ms 冷却，最多三个声音并发。静音会立即停止当前声音。

运行 `node --test frontend/tests/sound.test.cjs` 验证默认值、切换、持久化、点击和静音；打开 `/tests/sound-preview.html` 可试听两种声音及实际按钮反馈。

# 核心战术情境音效（出征、交火、战胜、升级）

针对战略沙盘与战斗指挥的情境反馈，系统在 `G.Constants.gameSound` 中新增四组战术情境音效，采用 Web Audio 纯算法多层参数化合成（无外部网络依赖，兼备无损 WAV 双模式支持）：

### 1. 🚩 部队出征（dispatch）
- **触发时机**：出征准备页点击【出发!】/【出征讨伐】/【立即出征】并成功提交出征任务。
- **声学重构核心**：对标**中国三军仪仗队分列式正步（112~116 BPM）**声学特征重制，彻底废除虚假的电子正弦波合成音（`np.sin`）与同源复制梳状滤波涂抹，100% 采用多轨不同机位实录硬牛皮马靴砸击花岗岩、铁掌钉铿锵咬合与百人方阵混凝土齐踏采样，经毫秒级瞬态峰值锁定（Sample-Accurate Peak Alignment），在约 **2.0 秒**内踢出 **4 步雷霆万钧、刀切斧砍的正步**：
- **方案 A（已接入）· 三军仪仗队 · 长安街石板正步四连踏**（`dispatch.wav`, 2.00s, 116 BPM）：四记正步精准落于 `0.05s`、`0.56s`、`1.07s`、`1.58s`。融合硬牛皮靴底猛砸花岗岩石板的 5ms 脆裂爆音（“啪！”）、仪仗马靴金属掌钉撞击石板的清亮铿锵声（“咔！”）、百人仪仗方阵齐踏主体与长安街石板广场早期反射，字字千钧、威震长街。
- **方案 B · 阅兵重装步兵方阵 · 广场阔步四连踏**（`dispatch_b.wav`, 2.04s, 112 BPM）：四记重步落于 `0.05s`、`0.575s`、`1.10s`、`1.625s`。在保留硬底掌击与铁掌铿锵的基础上，大幅强化混凝土大道方阵与近景百人行军队列的实录胸腔震感及广场石板反射声场，展现千人重装受阅方阵铁流滚滚的磅礴气势。

### 2. ⚔️ 拦截战交火（firefight）
- **触发时机**：大地图截击战抵达交火空域、或 WebSocket 收到拦截战报通知（`intercept_scout`）。
- **方案 A（已接入）· 真实防空炮与重炮点射**（`firefight.wav`, 1.35s）：20mm/37mm 防空高射炮三联点射 + 榴弹炮爆鸣与低频爆震波，具备真实战场的空气撕裂感与远近距离感。
- **方案 B · 重机炮速射齐射**（`firefight_b.wav`, 1.2s）：机炮四连发超音速破裂音 + 机械枪机后坐跳壳声 + 目标处炸裂回响。

### 3. 🏆 战斗指挥战胜（victory）
- **触发时机**：在线战术指挥回合战结束且判定获胜时（`battle.finished && result.win === true`）。
- **方案 A（已接入）· 盛大凯旋典礼**（`victory.wav`, 4.8s）：军乐团交响终曲高潮实录，定音战鼓震天滚奏 + 交响铜管大调合奏 + 大擦撞击共鸣，大捷史诗感浓厚。
- **方案 B · 雄浑战胜号角**（`victory_b.wav`, 3.5s）：沉稳定音战鼓起拍 + 铜管雄浑号角干脆利落收尾。

### 4. 🔨 建筑升级完成（upgrade）
- **触发时机**：建筑施工倒计时归零升级完成（服务器 Tick 推送 `completedBuilds`），或在队列中使用加速道具秒建完成。
- **方案 A（已接入）· 重工装甲锻造**（`upgrade.wav`, 1.3s）：实心钢梁 65Hz 重锤震击 + 工业高压气压阀泄压（Psssshhh）+ 要塞气密锁闭。
- **方案 B · 战术电台广播**（`upgrade_b.wav`, 1.6s）：机械卡扣到位 + 经典 RTS 战术电台指令汇报 "Construction Complete"。

### 设置联动与生效控制（严格遵循玩家设置）
所有情境音效通过 `Game.Sound.play(name)` 统一调度，执行硬性静音判定：
`preferences.enabled && preferences.volume > 0 && !document.hidden`
当用户在设置面板中关闭音效或将反馈音量拖至 0% 时，所有出征、交火、战胜、升级、领取奖励、打开宝箱、发送邮件音效均**绝对静音**，不触发任何音频输出。

# 游戏背景音乐（BGM）· 慢节奏轻音乐

专为长时间推演、内政经营与大地图排兵设计。彻底杜绝轻浮燥杂的合成电子音，采用古典纯声学实录名作，并经 3.0~3.5 秒正弦等功率无缝交叉淡化算法（Equal-Power Circular Crossfade）处理，消除首尾跳变与突波，实现无限平滑循环（`audio.loop = true`）。

### 1. 默认曲目：套系 1 · 《山河行思》（已通过评审并正式接入游戏）
- **曲目出处**：J.S. 巴赫《G 弦上的咏叹调》（Air on the G String, BWV 1068）
- **录音版本**：美国空军室内弦乐团（US Air Force Strings）现场实录
- **音频格式**：`frontend/audio/bgm_strings.mp3`（3.3MB 高保真）及无损 `.wav`
- **速度与配器**：慢板 58 BPM。第一小提琴深情长线条 + 柔美中提琴内声部复调 + 大提琴沉着稳健的步行低音（Walking Bass）与通奏低音衬托。
- **游戏意境**：从容威严、深谋远虑。宛如统帅在沙盘前凝思运筹、整肃三军，兼具军旅纪律的沉着与历史长河的厚重从容。

### 2. 备选候选曲目（可在游戏设置中自由切换）
- **套系 2 · 《平原微光》**（`frontend/audio/bgm_piano.mp3`）：埃里克·萨蒂《裸体歌舞第一号》（Gymnopédie No. 1，66 BPM 漫步）。九尺三角大钢琴独奏，单音空灵如水滴，极度纯净降噪抗疲劳。
- **套系 3 · 《烽烟晚照》**（`frontend/audio/bgm_evening.mp3`）：弗雷德里克·肖邦《E 小调前奏曲》（Op. 28 No. 4，54 BPM 最慢广板 Largo）。弱音踏板独奏，塞外残阳与历史沧桑感。

### 3. 设置联动与生命周期规范
- **独立音乐设置**：在【设置】面板中独立提供【背景音乐（BGM）】设置卡片，包含开关（`bgmEnabled`）、曲目切换下拉（`bgmTrack`）与独立音乐音量滑块（`bgmVolume`），偏好持久化保存在本地 `wargame_bgm_v1`。
- **Autoplay 策略适配**：为遵循现代浏览器（Chrome/Safari）自动播放限制，除加载时静默尝试起播外，在玩家首次点击或键盘交互时顺带静默解锁并启动 BGM。
- **页面可见性切换**：切换到后台标签页（`document.hidden === true`）时自动暂停 BGM，切回前台时若设置开启则平滑恢复播放。
- **混音协调**：BGM 音频流与 SFX（出征/交火/战胜/升级/金币/宝箱/邮件）独立分轨播放，触发操作音效时不打断 BGM 循环。
