## 风险和上线前置项

- **支付未完成**：真实支付服务、回调验签、订单幂等、退款和对账未接入，不能以 V1.0 作为已开通商业充值的生产版本。
- **合规未完成**：正式公网运营前仍需处理 ICP 备案、网络出版/运营所需许可、实名与防沉迷接入、隐私和未成年人保护流程。
- **数据库验证边界**：本次自动化测试默认使用 H2；生产上线前必须在独立 MySQL 8 测试库执行完整 Flyway 迁移、备份恢复和升级演练。
- **运行配置边界**：生产 `.env`、JWT、数据库密码、SMTP 授权码和 HTTPS 证书必须在服务器上单独生成或配置，不能从本归档恢复。
- **编译警告**：`RankGiftReward`、`BattleSession` 存在 Lombok 父类调用提示，`PlayerCity` 和 `MarchService` 有废弃 API 提示，`MailService` 有 unchecked 提示；建议作为 V1.1 维护项处理。

## 审查结论

V1.0 的源码、构建入口、测试和版本证据已具备固定与软件著作权材料整理条件。它可以作为研发版本和软著代码样本归档；在真实支付、备案、正式实名/防沉迷和 MySQL 生产演练完成前，不应宣称已经满足完整公网商业上线条件。
