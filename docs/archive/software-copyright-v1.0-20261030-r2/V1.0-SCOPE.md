# 山河远征录游戏软件 V1.0 范围说明

本文件对应 `v1.0-softcopyright-r2`。r2 仅修正文档及名称一致性，沿用原 V1.0 功能范围。

## 软件定位

“山河远征录游戏软件 V1.0”是近代战争题材的文字策略网页游戏。玩家在共享世界中建设城市、管理资源、训练部队、培养军官并参与行军、战斗和军团协作。

## 纳入范围

- 账号注册、登录、QQ 邮箱验证与找回、账号注销冷静期。
- 城市建设、资源生产、税收、仓库、征兵、军校、科技研究和军事理论。
- 军官、装备、军衔、军衔礼包、VIP、商城和道具使用。
- 世界地图、野地资源、NPC 城市、雷达情报、行军、拦截、伏击、采集和撤回。
- PVP 练习、城市征服、城墙战场、战报、战俘、伤兵和战力保护。
- 军团、援防、外交、世界聊天、军团聊天、私聊、邮件、好友和排行榜。
- 新手引导、任务、签到、跨城管理、服务器大区和本地测试身份。
- Java 17 Spring Boot 后端、原生 HTML/CSS/JavaScript 前端、Flyway 数据库迁移和 Docker/Nginx 部署脚本。

## 固定技术边界

- 后端源码位于 `backend/src/main/java`，数据库迁移位于 `backend/src/main/resources/db/migration`，固定提交包含迁移至 V141 的现有迁移文件。
- 前端静态页面和脚本位于 `frontend/`；前端回归测试位于 `frontend/tests/`。
- 生产数据库目标为 MySQL 8；自动化测试默认使用 H2，MySQL 迁移测试需要单独的可丢弃测试库。
- 构建与运行基线为 Java 17、MySQL 8、Node.js 22。

## 不纳入 V1.0 的能力

- 真实支付渠道、充值回调、订单对账和生产支付密钥尚未接入；当前充值相关页面为关闭或预览状态。
- 正式实名、防沉迷和监护服务适配尚未接入；本地测试身份仅用于开发验收。
- 生产域名、ICP备案、HTTPS 证书、云安全组和第三方 SMTP 凭据不属于源码包。
- `output/` 中的历史验收输出和 `docs/archive/` 中的历史快照不属于源码包，作为独立证据留存。
