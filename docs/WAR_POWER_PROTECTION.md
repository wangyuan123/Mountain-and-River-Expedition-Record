# 城市战争实力差距保护

所有真实玩家账号（包括机器人）的城市战争使用同一门槛：编队战力和综合实力分别比较双方较高值与较低值，两项均不超过10倍才能宣战或进攻。恰好10倍允许；双方同一指标均为零视为同档，一方为零而另一方为正则禁止；缺失玩家数据时拒绝城市战争。账号所有城市使用相同评级。

战争评级分别取即时实力与近7个游戏日已记录峰值的较高值，不改变个人信息和排行榜的即时实力。HTTP游戏写操作在变更前后采样，实力计算在写事务中也会记录上涨；全服每5分钟采样覆盖离线和后台变更。无上涨时每5分钟最多记录一次。记录用精确游戏时间过期，停服期间计时暂停。上线前的历史无法追溯，首次操作和定时采样建立基线；后台直接改库、绕过游戏服务的操作只能由定时采样覆盖。

保护在宣战、派遣、抵达、建立战斗会话时检查，优先于敌对军团免宣战权限。战损不会立即降低战争评级；快速增兵导致超限时禁止新的城市进攻。在途行军失去资格时沿用既有取消逻辑归还兵力及随军物资。已开始的战斗继续结算，不回滚；战争计时保留，恢复资格后可在有效战争期内进攻。

新手保护、城市护盾、战后保护、友好军团、备战期仍独立生效。侦察、运输、援军、野地、NPC、演习不受本规则限制；侦察等仍须满足原有保护规则。该机制不限制多人围攻总兵力，也不按援军重新计算双方战争评级。

地图与城市列表返回 powerProtection，包含 allowed、reason、maxRatio 及双方两项战争评级；页面显示限制原因并禁用宣战、讨伐入口，服务端始终复核。暂定阈值10倍集中在 WarPowerProtectionService.MAX_RATIO。10倍仅是保护上限，不代表势均力敌。

部署时执行 Flyway V134，创建 player_power_snapshots，服务重启后定时采样启动。采样间隔可通过 game.war-power.snapshot-interval-ms 调整；game.scheduling.enabled=false 时不启动定时任务。
