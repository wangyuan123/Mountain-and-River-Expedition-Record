# 军官升级经验（2026-10-27）

等级上限100级，`E(L)`表示当前L级升至L+1级所需经验，满级返回0。

```text
E(L) = 200L
     + 75 × max(0, L − 20)²
     + 150 × max(0, L − 50)²
     + 300 × max(0, L − 80)²
```

1～20级保留原有需求；21～50级开始温和加速；51～80级进一步加速；81～99级加强长期培养成本。各段追加项在交界从0开始，避免需求突然跳升；这是一条分段二次曲线。

| 当前等级 | 升下一级需求 | 从1级升至当前等级累计经验 |
| --- | ---: | ---: |
| 1 | 200 | 0 |
| 20 | 4,000 | 38,000 |
| 21 | 4,275 | 42,000 |
| 50 | 77,500 | 886,625 |
| 51 | 82,425 | 964,125 |
| 80 | 421,000 | 7,181,000 |
| 81 | 439,725 | 7,602,000 |
| 99 | 956,325 | 19,399,425 |
| 100 | 0（满级） | 20,355,750 |

从1级到100级的累计成本为20,355,750，约2036万，符合满级约2000万的目标。原先的2,281,050经验现在从1级只能升至62级，剩余40,375经验；20,000,000经验可升至99级，距满级仍需355,750经验。前20级需求保持不变，二次项系数较上一版提高15倍，成本增长主要集中在中后期。

只使用高级经验书且初始经验为0时，需要204本；普通经验书仍提供10,000经验，高级经验书仍提供100,000经验，满级经验书仍直接升至100级。每升一级仍获得1点可分配属性，不改战斗经验产出及其他投放。

满级经验书按直升效果结算：1级且0经验的军官使用1本即可到100级并获得99点可分配属性，不受累计20,355,750经验门槛影响；其他未满级军官补足剩余等级的属性点。每次仅消耗1本，满级军官不再消耗。高级经验书按每本100,000经验累加，批量使用N本获得N×100,000经验。商城与仓库说明、用书预览保持一致。

已有军官保留等级、已分配属性、可分配属性点和未消耗经验原值。无需数据库迁移，不重新计算历史总经验，也不自动降级、升级或补发经验。下次升级按新需求扣减，因此旧经验条的百分比可能降低。满级后剩余经验仍按既有规则清零。

后端单级升级、一键升级、仓库经验书自动升级均调用`OfficerExperienceRules.expNeeded`。前端经验条、升级按钮、经验书预测与本地经验增长均通过`G.expNeeded`使用同一公式。军官页使用普通/高级经验书仍只增加经验，仓库使用经验书仍自动升级，保留两处原有交互。

前后端测试共用`backend/src/test/resources/officer-experience.csv`中的边界需求与累计成本，并检查完整等级范围的单调性。曲线参数是本项目的初版数值；实际培养时长需结合经验产出与玩家数据评估。发布时需同步部署并重启后端，前端已更新脚本缓存版本。
