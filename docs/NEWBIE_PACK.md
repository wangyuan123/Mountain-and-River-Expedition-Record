# 新手礼包

2026-10-14：删除旧倍数宣传与没有截止时间的“限时”标签，补齐资源礼包的购买、入仓和开启流程。

售价为 99 钻石，每个账号限购 1 份。购买只扣除钻石并将礼包放入账号共享仓库，提示玩家到“仓库 → 资源道具”开启。

开启一份后，为当前城市增加以下固定资源：

| 资源 | 数量 |
| --- | ---: |
| 粮食 | 20000 |
| 钢铁 | 20000 |
| 石油 | 10000 |
| 稀矿 | 5000 |
| 黄金 | 3000 |

发奖沿用资源道具规则，不受仓储容量截断，不增加钻石。城市资源数据缺失时恢复礼包数量，不发奖。

购买和开启共用账号锁，库存原子扣减与资源发放位于同一事务。重复请求不会重复购买或开启；已购买礼包开启后保留零库存行作为限购凭据，刷新、切换城市或更换设备不会恢复购买资格。旧版已经购买但无法开启的库存现在可以正常开启。

回归覆盖实际购买与开启、五类资源精确到账、重复请求、钻石不足、分城发奖、城市数据缺失和并发购买/开启；前端覆盖固定资源说明、仓库入口、已购禁用和礼包开启按钮。
