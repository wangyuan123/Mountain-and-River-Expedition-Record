# 玩家实力指标

两项指标是服务端的静态估值，与声望独立，不能预测战斗胜负。排行榜按指标降序、同分按玩家 ID 升序；个人资料和排行榜使用相同计算方法。

## 编队战力

对每个城市、行军和占领野地的现有兵力分别估值，取最高值。城市按实际出城迎战容量（军衔基础容量加一半基础容量，再计本城指挥官统率技能）从现有兵种中优先选择单位价值较高的兵力；行军按已有兵力计算，合并的野地驻军按军衔出城基础容量截取。陆空、海空分别计算并取较高值，不将陆军和海军拼成一个不可出征的编队。它是潜在编队估计，不是默认迎战配置或任意一支已保存的玩家编队。

单兵价值为 `sqrt(max(1, 最高对部队攻击) * max(1, 生命)) * (1 + 防御 / 100)`，基于战斗引擎的科技、兵种配装和指挥官属性；狂热和坚守按三回合一次的均值估计，司令部存在时计入本城司令官属性。它不模拟兵种克制、战场、距离、指令、动态技能或胜率。当前行军进入战斗时，攻击方按战斗会话剩余兵力计算；其他战斗中的兵力以结算后的持久化资产为准。

## 综合实力

所有城市驻军、行军及已占领野地驻军的同口径兵种价值之和，加上培养资产：建筑每级 100、科技每级 500、军官每级 100、每星 500、每点四维 10、每技能级 200、已穿戴军官装备每点基础属性 10。城市和行军兵种价值使用所属编队的指挥官和司令官静态加成；野地合并驻军不附加城市任职加成。未完成生产、伤兵和声望不计入。库存与其他尚未列出的资产不计入。

估值为设计基线，应根据真实玩家分布和对战数据调整权重。读取时实时计算，榜单使用批量查询后对全服排序，不按当前页重新排名；规模增长后应监控查询和排序成本并考虑快照机制。
