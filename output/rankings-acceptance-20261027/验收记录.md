## 结论与范围

本地 `8080` 服务的六类排行榜均通过实时接口核验：玩家声望榜、军衔榜、编队战力榜、综合实力榜，以及军团总声望榜、人数榜。当前符合上榜条件的玩家 57 位，共 3 页；军团 4 个，共 1 页。

本轮使用已授权的试玩账号 177 做只读接口验收，与 MySQL 的公开业务字段独立比对，没有创建账号或修改玩家资产。前端交互通过 Node 测试验证；本轮没有进行登录后的人工页面验收。

## 通过的检查

- 全量翻页核对名次连续、没有重复或遗漏，分页大小和总数正确；同分按照规则使用辅助指标及 ID 稳定排序。
- 榜单玩家集合与数据库有效账号集合一致；声望、军衔及军团声望与人数逐项一致。空榜、未入团、失效账号、封禁到期等边界由后端回归覆盖。
- 我的名次来自全榜，各页返回一致；前端可定位到个人所在页，并聚焦该行。
- 两种战力与同一玩家的资料接口一致，展示对应指标而非声望。
- 排行榜响应没有城市坐标、兵力明细、资源、口令等字段；未获有效侦察的玩家资料不返回主城坐标。侦察失效及迁城后的权限变化由集成测试覆盖。
- 负数和零页码归到首页，最大合法整数页码归到末页；未知类型或指标返回 400；未登录返回 401。
- 快速切榜、迟到响应、切换账号、错误重试、名称转义及头像白名单由前端回归覆盖。

## 发现并修复

### 非法页码误报服务器维护

修复前，`page=abc`、`page=2147483648` 返回 500 和 `SERVER_MAINTENANCE`。原因是参数类型转换异常落入全局兜底处理。

增加明确的参数转换异常处理，返回 400 和“请求参数 page 格式无效”。回归覆盖非数字、正负整数越界和小数，均在调用排行榜业务逻辑之前拒绝。该处理也适用于其他接口的同类参数错误。

### 下拉菜单重绘后第一次点击无反应

菜单展开后刷新，或在请求返回前展开菜单，重绘会生成已收起的菜单，但旧的 `dropdownOpen` 仍为 `true`。下一次点击只会关闭内部状态，用户看不到菜单展开。

榜单全量重绘前同步关闭旧菜单状态；回归覆盖刷新启动和异步响应两个重绘时点。
