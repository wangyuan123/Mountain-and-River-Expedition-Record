## 本轮发现与修复

1. **俘将/归降转籍丢失部位整备加成。** 军官和穿戴装备换了归属，整备行仍属于旧账号；实测防御从 277 降至 272。现已在俘将与和平移交两个入口同步转移整备，保留账号图鉴、任务与配装方案归属；冲突行取较高等级，不相加。`V125__transferred_officer_preparation` 修复历史数据。本机迁移成功，最终整备归属错误行数为 0，新旧俘将均复验通过。
2. **驻军与战斗兵力来源暴露登录名。** 现统一展示公开统帅名；已通过不同登录名/展示名的回归与真实支援页面数据复验。
3. **最高军衔城市提示误导。** 原本拥有 3 / 8 座城仍显示“已达到最高城市上限”。现改为“当前军衔最多可拥有 8 座城市”，实际占满时仍单独显示“城市数量已达上限”。新回归先复现失败再验证修复，页面已确认显示剩余 5 个名额。

## 新记录的体验优化点

军官能力栏把装备后的总属性与基础属性上限放在同一个分数中，例如本轮俘将显示“防御 277 / 219”“能力上限 219”。数值与服务端装备计算一致，但文案容易让玩家以为属性溢出或上限失效。建议明确区分基础属性、装备/共鸣/整备加成和最终属性，并把 219 标为基础属性上限。本轮记录该点，尚未调整能力栏展示。证据：`15-captured-officer-preserved.png`。
