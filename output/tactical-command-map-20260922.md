# 战术指挥地图展示优化实施记录

**日期：** 2026-09-22  
**状态：** 已实施并完成针对性前端验证

## 目标

改善战术指挥地图的可读性与回合反馈，使玩家能够在每次回合结算后直观看到敌我部队的相对位置变化，并在战斗结束后自动回到军情页面。

## 已实施内容

### 1. 敌我相同兵种横向对齐

战场按双方当前存活兵种的并集生成统一的纵向行序：

- 同一种兵种在敌我两侧使用同一行号，因此始终位于同一水平线上。
- 仅一方拥有的兵种仍会占用独立行，不影响其他兵种的对齐关系。
- 我军模型继续镜像朝右、敌军模型保持朝左，双方仍维持相向的行军与火力方向。

### 2. 回合坐标映射到地图位置

战术战斗服务端会在每回合结算后返回各兵种最新的一维战场坐标。前端现将该坐标映射为地图横坐标：

- 横坐标计算为 `战场位置 / 战场宽度`。
- 图标显示限制在地图的 `3%–97%` 内侧，避免 44px 单位徽标被地图边框裁切。
- 倒计时结束后自动提交本回合命令；返回下一回合数据并重新渲染时，单位将据新坐标显示推进、后退或在战场中央接敌的结果。
- 同一兵种的敌我单位可同时保持同一纵向行，并根据各自坐标处于不同横向位置。

### 3. 战斗结束自动返回军情

当回合结算接口返回 `finished: true` 时：

1. 清空已完成的战术指挥会话与本回合命令。
2. 自动跳转至军情（`alerts`）Tab。
3. 玩家可在军情页继续查看行军状态，并通过既有入口进入战报。

这样不会停留在已结束的战术指挥面板，也不会因浏览器返回或重复渲染重新打开该面板。

## 实现位置

| 文件 | 改动 |

| `frontend/css/style.css` | 敌我单位使用相同顶部基线和行距，确保共同行号处于同一水平线。 |

| `frontend/tests/tactical-facing.test.cjs` | 覆盖模型朝向、共同行序、坐标横向映射、自动结束后返回军情及批量命令操作。 |
| `frontend/tests/tactical-facing-preview.html` | 更新独立战术地图预览的脚本缓存版本。 |

- 双方处于相同战场位置的战斗机在地图中央相遇。
