# 山河远征录 · 建筑图标三套提案

日期：2026-09-17。共 21 种建筑 × 3 套 = 63 枚原创 SVG，画布 128 × 128，可直接缩放。

打开 `index.html` 查看交互对照页，支持整套选择、逐栋混搭、军事/资源区筛选、深浅底色和 20/32/48 px 预览。导出的 JSON 记录所选建筑、风格和文件路径。本次仅新增方案资产，未替换游戏图标。

## 风格

- **A / 滇缅微缩**：建筑主体采用斜俯视构图，军绿屋顶、暖砂岩墙体、红土色基座。更适合 48 px 以上建筑卡片，建筑感与游戏背景关联最强。
- **B / 军需铜章**：以独立绘制的正面设施轮廓置于橄榄色黄铜章牌中。更适合当前暖金色界面与紧凑图标。
- **C / 战地蓝图**：重新绘制设施平面、工程立面和功能示意。统一测绘蓝底、骨白线、橙色识别点，适合更冷静的战术界面。

三个方向不仅配色不同，也采用不同构图与图形。图形为原创 SVG 绘制，未使用 AI 位图生成；确认现有项目为 SVG 图标体系后，按 imagegen 技能的原生矢量适用规则直接制作。图形设计采用二战时代设施线索，不宣称具体建筑的历史复原。

## 设计依据与范围

- 背景依据：根目录 README.md 中的中国远征军、滇缅公路与前进基地设定。
- 建筑名称及用途：`frontend/js/data.js`。
- 界面分区：`frontend/js/build.js` 中 `Build.GROUPS`。军事区 17 种，资源区 4 种；仓库、运输站、交易所虽然数据类别是 res，但实际显示在军事区，故本提案按页面分区。
- 现有渲染尺寸：建筑卡片标题图标 20 px。本提案保留该尺寸的对照以暴露细节损失。A 的细节在 20 px 下会简化，正式使用推荐 48–64 px；B/C 可优先作为紧凑布局候选。
- 农田、炼钢厂、石油基地、稀矿厂均设计为设施本体图标，以区别资源数值栏中的粮食、钢铁、石油、矿石符号。

## 完整设计简报

用途：山河远征录军事区与资源区建筑选择。三个完整统一风格，每个建筑单独绘制。统一 128 × 128 画布、安全边距与可读轮廓。军事区覆盖市政厅、民居、军工厂、轻工厂、重工厂、机场、港口、军校、参谋部、科研中心、雷达站、围墙、停机坪、联络中心、仓库、运输站、交易所。资源区覆盖农田、炼钢厂、石油基地、稀矿厂。

A：斜俯视微缩基地；每栋建筑以可辨的体量与相关设施区分；砂岩、军绿铁皮、木材、低饱和工业色。B：正面象征性建筑轮廓；深橄榄章牌和黄铜图案；减少纹理，突出轮廓。C：测绘图纸；平面/工程图形；骨白线稿，琥珀标记，深蓝绿底。不得只对同一图形换色。所有方向避免科幻建筑、现代卫星锅、直升机停机坪 H 标识和现代集装箱。三种工厂和机场/停机坪必须分别可辨。

## 文件

- `manifest.json`：建筑名称、页面分区、设计线索和风格清单。

- `generate.py`、`gallery-template.html`：可再生成的原创图形与展示页源文件。
- `preview-a.png`、`preview-b.png`、`preview-c.png`：浏览器渲染的完整套图（生成后提供）。
