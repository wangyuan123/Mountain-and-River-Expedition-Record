# 首页 VIP 特勤弹窗领取验收

日期：2026-10-27，北京时间。

## 已修复问题

1. 四类领取按钮的前端路径与后端不一致，点击无法正常领取。现统一为：

   | 操作 | 接口 |
   | --- | --- |
   | 每日军饷 | `/api/game/vip/daily-salary/claim` |
   | 单个晋升礼包 | `/api/game/vip/level-pack/claim` |
   | 一键领取晋升礼包 | `/api/game/vip/level-pack/claim-all` |
   | 阶段军备箱 | `/api/game/vip/milestone/claim` |

2. 成功响应缺少最新游戏状态，客户端不能立即同步奖励。四类响应现附带当前浏览城市的状态，客户端同步资源和账号道具；奖励送到分城时不切换当前城市。
3. 领取接口原先接受不存在的城市槽位，可能消耗领取资格并将资源写入无法访问的城市。现发奖前验证城市归属、建设完成和归降冻结状态，失败时不消耗资格、不发奖。
4. 原先领取后的状态查询未完成就释放提交锁。现等待刷新领取状态后解锁，防止旧按钮连续提交。
5. 浏览器刷新验收发现，首页卡片无论实际是否已领取都固定显示“每日特勤军饷已就绪”。现游戏状态下发真实领取状态，首页与弹窗共用游戏北京时间的每日口径，已领取显示“今日特勤军饷已受领”。
