# 战术指挥空域封锁机制实施记录

**日期：** 2026-09-22  
**状态：** 已实施并完成针对性验证

## 目标

修正战术指挥战场中部队穿越对方阵线的逻辑，并为各兵种建立明确、易理解的推进约束：

- 地面部队接敌后不得穿越仍存活的敌军阵线。
- 空军可以越过普通地面前排进入纵深。
- 敌方存活空军和防空装甲车共同构成空中封锁线，阻止空军继续深入。
- 空军停在封锁线前时，仍可攻击自身射程内的合法敌军；玩家不指定目标或离线时，自动攻击最近目标。

## 最终规则

### 地面与海军

地面及海军单位沿一维战场向最近的可攻击敌军接敌。进入自身有效射程后停止前进并交火，因此不能越过仍存活的敌军部队。

### 空军推进

空军使用独立于地面接触线的推进规则：

1. 敌方存在存活空军时，该空军位置形成空中拦截线。
2. 敌方存在存活的 `armored`（猎鹿犬防空型装甲车）时，该单位位置形成防空封锁线。
3. 两类封锁力量同时存在时，空军以距离最近的一条封锁线为推进上限，并在进入自身射程后停留交火。
4. 敌方空军与防空装甲车均被歼灭或撤离后，空军可越过普通地面前排，继续向敌军纵深推进。
5. 空军越过地面前排后，目标距离按双方坐标的绝对值计算，因此位于空军前后两侧、且在射程内的合法单位均可被攻击。

### 空军目标选择

- **玩家指定集火：** 只要目标存活、在射程内且该兵种具备对应攻击能力，空军可攻击任意合法目标；地面重坦掩护不阻止空军选择地面后排。
- **未指定目标或离线：** 若敌方仍有空军或防空装甲车形成封锁，空军自动攻击射程内距离最近的合法目标。
- **无空中封锁：** 空军沿用常规索敌逻辑，并可在纵深位置选择射程内目标。

## 验证结果

以下命令均已通过：

```bash
node --test frontend/tests/tactical-facing.test.cjs
./mvnw -q -f backend/pom.xml -Dmaven.compiler.useIncrementalCompilation=false -Dtest=BattleServiceTest -DforkCount=0 test
```

说明：后端测试使用 `-DforkCount=0` 在当前 JVM 中执行，以规避测试进程分叉时对中文工作目录的路径编码问题；测试断言本身均已执行通过。
