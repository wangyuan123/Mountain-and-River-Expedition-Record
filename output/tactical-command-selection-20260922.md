# 战术指挥命令选中状态实施记录

**日期：** 2026-09-22  
**状态：** 已实施并完成针对性验证

## 目标

让战术指挥界面中每个兵种的“前进 / 后退 / 待命”命令具备明确的选中反馈。玩家点击命令后，无需等待回合结算，即可确认该兵种当前将执行的移动指令。

## 界面规则

- 当前选中的单兵种命令显示为深蓝背景、白色粗体文字和阴影。
- 选中命令前方显示 `✓`，与未选命令形成明确区分。
- 未选命令维持白色背景和浅色边框，避免与选中状态混淆。
- 鼠标按下有轻微位移反馈；键盘聚焦时显示清晰的焦点轮廓。
- “全部待命 / 全部前进 / 全部后退”在所有存活兵种均使用同一命令时，也会使用相同选中样式。

## 状态同步

命令按钮继续使用既有的 `ok` 类来表示已选状态，不改变命令保存或回合提交逻辑。同时增加 `aria-pressed="true|false"`：

- 当前命令对应按钮为 `true`。
- 其余两个命令按钮为 `false`。
- 每次点击后调用既有的 `setTacticalAction()` 并重新渲染，因此视觉状态始终与本回合实际命令一致。
