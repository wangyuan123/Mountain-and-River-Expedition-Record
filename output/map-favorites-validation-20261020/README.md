# 地图坐标收藏验收

日期：2026-10-20

- 地图右侧「海岸」下方增加「收藏」，沿用现有按钮及弹窗样式。
- 城市、野地、流寇和空地详情支持收藏/移除收藏。
- 玩家城市显示「玩家名称（x, y）」；野地显示中文类型；空地显示「坐标标记」。
- 点击收藏名称关闭弹窗、定位固定坐标并读取当前位置目标；不改变玩家城市实际位置。
- 收藏按账号保存到服务端，切换城市或重新登录可读取，最多100个，最近收藏优先，同一坐标不重复。
- 名称为收藏时快照，目标迁移后仍定位原坐标，弹窗明确说明此规则。
- 支持空列表、加载失败重试、写入失败保留数据、键盘关闭与焦点循环、全屏内打开。
