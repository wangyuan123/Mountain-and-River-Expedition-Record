若每个舰种各造1000，海军共4000单位，加权预算859万；每个陆军兵种各造1000（含卡车），共9000单位，加权预算405万。此为不同类别数量的总和，不是等编制对比。单个兵种1000单位之间，潜艇预算70万低于重坦89万与火箭车113万；驱逐舰109万略低于火箭车113万；战列舰300万与航母380万才显著更贵。

比如1000战列舰等预算3370重坦、2654火箭车或6000轻坦；1000航母对应4269重坦、3362火箭车或7600轻坦。等数量对打会给予主力舰明显更多的资源预算，不能用它直接判断跨军种性价比。要比较战力，需另以这些等预算数量运行实战模拟，计入射程、机动、科技、军官和克制。
