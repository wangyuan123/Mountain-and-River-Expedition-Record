# 造船厂（Shipyard）3D 写实微缩模型设计与重构归档 (2026-10-12)

## 一、设计背景与核心差异
系统新增的重工业军事建筑**造船厂（shipyard）**承担建造驱逐舰、潜艇、战列舰与航空母舰等海军核心主战舰艇的重任。
此前临时复用了物资码头【军港】（`port.webp`），存在以下视觉与体验痛点：
1. **职能混淆**：军港本质是物资吞吐、舰艇靠泊码头（石砌岸壁+仓库+小型巡逻艇）；而造船厂是重型造船工业母机基地，应具备鲜明的**干船坞、建造中龙骨/肋骨舰体、重型龙门吊/锤头起重机**等硬核造船特征；
2. **美术同质化**：独立造船厂模型上线后，可彻底拉开后勤港口与主战舰艇制造基地的视觉档次；
3. **风格统一性**：严格契合 A 套【花园卫城】1930s-1940s 建筑规范：米黄石灰石（cream limestone）、暗红砖装配车间、石板蓝灰屋顶、氧化青钢、35° 等轴测俯视与 384×384 透明 WebP 标准。

## 二、3 款候选设计方案

### 方案一：重型龙门架 · 龙骨干船坞 (`option-1-gantry-dock`) 【推荐主选】
- **核心构成**：一座深切石砌干船坞，坞底垫木上卧着一艘**正在铺设肋骨钢架与龙骨的战舰胚体**（极具造船初始/拼装震撼力）；
- **标志性设施**：跨坞行走的**大型桁架龙门起重机（Gantry Crane）**，高大挺拔；
- **配套厂房**：高大红砖波纹钢板机加车间，多组排气烟囱与铁轨；码头整齐堆放轧制钢板与缆绳盘；
- **多尺度表现**：龙门吊横跨干坞的剪影在 44px/64px/88px 缩略图下轮廓辨识度极高。

### 方案二：锤头起重机 · 斜向滑道船台 (`option-2-slipway-crane`)
- **核心构成**：经典**倾斜式下水船台（Inclined Slipway）**直插青绿海水，木质滑道与龙骨支架托举着一艘总装中的二战驱逐舰；
- **标志性设施**：高架轨道上耸立一座高耸的**黑色钢铁锤头悬臂起重机（Hammerhead Portal Crane）**；
- **配套厂房**：双坡顶红砖红瓦海军船体装配工坊，侧边设有型钢备料货架与木模工棚；
- **特色**：下水滑道的斜向动态感强烈，锤头吊充满年代感。

### 方案三：双门座吊车 · 战列舰级装配所 (`option-3-heavy-basin`)
- **核心构成**：深水石砌干船坞内正在为一艘体量庞大的主力战舰总装上层建筑与主炮塔，四周搭设精密脚手架，带有闸门隔绝海水；
- **标志性设施**：船坞两侧各布置一台**旋转门座起重机（Twin Portal Jib Cranes）**；
- **配套厂房**：带有通长采光天窗的高大砖石动力装配大跨厂房与高耸烟囱；
- **特色**：双吊夹持巨舰，体量厚重，极显大型海军造船基地的工业压迫感。
