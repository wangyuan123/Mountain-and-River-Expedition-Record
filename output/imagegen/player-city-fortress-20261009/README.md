# 玩家城市高端军事要塞微缩模型设计方案

日期：2026-10-09  
设计代号：`player_city_citadel`（玩家城市·近代要塞军政重镇）  
设计定位：沿用游戏 A「花园卫城」（Garden Citadel）微缩建筑美术体系，融合严整棱堡防线与近代军政中枢，打造气势恢宏、军事色彩浓厚、层级井然的玩家主城视觉资产。

---

## 一、 设计总纲与视觉基调

1. **高端大气（Grandeur & Authority）**：
   - 破除平民城镇散落民房的杂乱感，采用**四方筑城、中轴对称、主从有序**的经典军政重镇规制。
   - 以三至四层新古典主义花岗岩**市政厅**为全城视觉锚点与天际线制高点，主轴大道纵贯，展现“最高统帅部”与“大本营”的威严尊贵。
2. **浓厚军事色彩（Fortified Military Presence）**：
   - **外围重防**：近代钢筋混凝土与花岗岩筑成多边形低矮棱堡城墙，设有巡逻马道、防空炮台与重装闸门。
   - **内圈重装**：集**防空雷达站、战俘营、陆军重装整备区、战备机场停机坪、军需工坊**于一体，构成自成一体的高级战争堡垒。
3. **微缩写实与系统同源（Garden Consistency）**：
   - 严格继承军需仓库、军校与战俘营的经典材质：**暖奶油色/米色石灰石基座与墙体**、**低饱和红陶瓦坡顶**、**风化深色木构**、**军绿色涂装装甲战机**与**浅地坪石基**。
   - **35°~40° 俯视 3/4 等距视角**，既展现建筑宏伟立面与深窗阴影，又完整展现要塞内部功能区与兵力驻泊。
   - 杜绝浮空切块地台与厚地座，采用平整浅地坪，确保模型自然融入大地图 2×2 地貌。

## 六、 验收结论

1. **核心要素 100% 达成**：四方棱堡城墙、新古典市政厅中枢、金属桁架防空雷达站、红陶双排营房木构战俘营、以及集战备跑道（P-51/B-17）与坦克方阵为一体的军事基地全部清晰呈现。
2. **高端大气与军事氛围**：中轴对称主从有序，彻底破除旧版散落或高层民房违和感，具有一方诸侯大本营的宏大庄严气势。
3. **顶端逆透视拉近优化（拓宽 2% + 累计纵向拉近 20° 巍峨版）**：
   - 保持城墙方形不外扩（维持微拓宽 2.0%），将北端纵深向上拉近 16.0%（折合累计拉近约 20°）；
   - 市政厅穹顶、列柱与钟塔巍峨耸立，雷达站与战俘营直立迎面，彻底消除了躺平后仰感，同时避免了喇叭口变形；
   - 最终裁剪尺寸 1255 × 1222（纵横比 1.027），在大地图 88px/176px 下视觉焦点鲜明、气派巍峨。
4. **微缩体系与地图融合**：与奶油石灰石、红陶瓦及军绿战车材质完全契合游戏建筑群；平整浅地坪在深浅色背景下均无白边、无浮空厚地台。
5. **测试验证**：前端地图拾取与渲染相关单元测试全部通过。
