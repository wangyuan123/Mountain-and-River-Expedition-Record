## 三套方案（每套完整覆盖 21 栋）

- A 花园卫城配套：奶油石墙、红陶瓦、浅石铺地和绿植，最贴近现有花园卫城。
- B 滇缅战地营区：灰瓦、木材、军绿铁皮、红土院落，突出远征军前线基地气息。
- C 红砖工业基地：红砖、蓝灰金属屋顶、钢架和混凝土，突出军工与后勤体系。

统一要求：约 35 度斜俯视、自然日光、真实窗洞与屋顶层次、合理门窗尺度、柔和接触阴影；主体占画面约 75–82%，四周留白。设施本体为主体，不使用徽章、线稿、巨大麦穗或烧瓶代替建筑。军事区 17 栋，资源区 4 栋，按当前页面分区。

验收：军工厂/轻工厂/重工厂在厂房体量与设备上可辨；机场以机库和塔台为主体，停机坪以开放停机地面为主体；资源设施表现生产场所。缩至 64/96/128 px 检查辨识度，保留大图查看材质。图片生成后制作整套对照与逐栋选择页。选型阶段保留三套原稿；选定 A 后已替换建筑卡槽、详情与选建界面的素材。

`prompts.jsonl` 为 63 条请求草案；各方案目录内保留每栋完整提示词。拟采用 gpt-image-2，1024 × 1024，高质量，PNG。用户已明确授权沿用玩家城市素材的 API 方式，使用 gpt-image-2。之前使用的地址为 https://new.home.wuguokai.vip:81/v1；密钥已加载到工作区外的临时配置文件，权限 0600，凭据不写入此目录。

- index.html：整套选择、逐栋混搭、高清放大、48/64/96 px 预览、深浅界面及选择清单导出。
