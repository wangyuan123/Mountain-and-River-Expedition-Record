# 联防雷达（Guild Radar）3D 写实微缩模型设计归档 (2026-10-26)

## 一、设计背景与核心差异

在城防雷达与联防雷达拆分后（版本 `city-guild-radar-split-20261024`）：
1. **城防雷达（radar）**：原防空雷达站，负责本城基础防空与受袭告警、大地图扫描视野及科研前置；
2. **联防雷达（guild_radar）**：军团区域联防核心，按等级提供 1～10 格覆盖半径，对经过覆盖区且威胁团友的敌对行军提供实时预警。

### 原有痛点
拆分之初，联防雷达临时复用了城防雷达的素材 `img/buildings/garden/radar.webp`，导致在建筑卡槽与选建列表中出现两座完全相同的“单桅杆方形网格天线”雷达站（如图标所示），造成玩家认知困惑。

### 新版美术与视觉规范
严格契合 A 套【花园卫城】1930s-1940s 建筑规范：
- **核心构成**：35° 正轴测俯视视角（Isometric 35°），正交无畸变；
- **材质色彩**：奶油色石灰石、红陶瓦、暗橄榄绿钢架结构、战备沙袋与碎石地台；
- **用户提示与核心辨识点**：**雷达天线周围带有明显的向外扩散的同心圆电磁雷达波纹（Radar Wave Ripples）**，直观表达“广域发射、多方联防、主动扫描”的功能意象，与城防雷达的纯物理金属架形成强烈反差；
- **尺寸标准**：384×384 RGBA 透明 WebP，主体严格居中并保持规范留白（主体约 362×362 边界内），在 88px（详情）、84px（卡槽）、64px（选建列表）、44px（移动端）均保持清晰锐利。

## 二、3 套候选设计方案

### 方案 A：弧形网面扫描阵 (`option-1-parabolic-dish.webp`)
- **构成**：旋转式弧形金属抛物网格天线，外围环绕向四周扩散的淡蓝白色电磁脉冲光弧；基座设战壕沙袋掩体、通讯小屋与天线拉索。
- **特征**：兼顾二战早期经典探照与早期雷达特征，光环柔和。

### 方案 B：广域中继预警台 (`option-2-surveillance-relay.webp`)
- **构成**：暗橄榄绿钢架高塔承载大口径曲面微波监控天线，天线四周散发着层次分明的水平同心扩散雷达波波纹；基座配备加固水泥机房、柴油发电机组与厚重通讯屏蔽电缆。
- **特征**：构图整洁稳重，波纹形态清晰易读，84px/64px 缩放下抗噪极强。

### 方案 C：矩阵相控阵要塞 (`option-3-phased-array-bunker.webp`) 【用户选定 · 游戏已实装】
- **构成**：重型钢架承载二战早期远程相控阵大型矩阵天线网（仿早期弗雷亚/沃茨堡联防雷达），天线周围环绕高明度多重脉冲电磁波弧环；搭配战术情报地堡与外置发电机。
- **特征**：体量厚重，矩阵天线与城防雷达形成巨大形态代差，波纹能量感最强，兼具军团联防中枢的威严与广域监控震撼力。
