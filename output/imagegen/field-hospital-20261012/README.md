# 战地医院（Field Hospital）3D 写实微缩模型设计与重构归档 (2026-10-12)

## 一、设计背景与核心差异

在战地后勤与医疗科研体系中，新增的军事建筑**战地医院（hospital）**具有双重关键使命：
1. **救死扶伤**：作为前线伤兵营的救治入口，承担快速收治、分诊治疗与伤员康复的核心职能；
2. **后勤科研枢纽**：作为研发高级战地医疗技术（如输血救治、高级手术器械）的必要前置建筑。

### 此前临时方案的体验痛点
此前为了快速打通链路，临时使用脚本在普通民居（`house.webp`）屋顶平面通过几何算法贴了两个白底红十字色块：
- **建筑职能混淆**：建筑本体依然是平民住宅结构（门窗、楼层比例、院落均无医疗设施属性），缺少严肃专业的战地救护特征；
- **缺乏战救辨识度**：缺少急救帐篷、伤兵担架通道、战地急救车、医疗物资箱及防空识别标识等极具战地年代感的视觉元素；
- **美术同质化严重**：在军事区 20 栋建筑中容易与普通民居或战地兵站混淆。

### 新版美术规范遵循
严格契合 A 套【花园卫城】1930s-1940s 建筑规范：
- **材质色彩**：暖奶油石灰石（cream limestone）、红陶坡屋瓦（terracotta tiles）、深色老木架构件、帆布帐篷布纹（weathered canvas）、深橄榄绿金属配件与平整石灰碎石地面；
- **构图与视角**：35° 正轴测俯视（Isometric 35°），正交无畸变视角，主体建筑与附属设施占画面约 78%~82%，四周留白规范；
- **双主题与多尺度**：在深色战备模式（Dark Mode）与浅色沙盘模式（Light Mode）下均具极高对比度；在 88px（详情弹窗）、84px（建筑卡槽）、64px（选建列表）、44px（移动端紧凑模式）下轮廓与红十字医疗特征极度清晰。

## 二、3 款候选设计方案

### 方案一：红十字诊疗楼主楼与急救帐篷联组 (`option-1-pavilion-clinic`) 【推荐主选】
- **核心构成**：
  - 一座体量端庄的二层石木结构医疗主楼，奶油色石砌基座搭配整洁的双坡红陶瓦屋顶；屋顶正中喷绘醒目的白底红十字日内瓦公约医疗标识；
  - 侧翼延展出一顶大型全天候米白帆布野战救治大帐篷（Ward Tent），设置离地木板防潮地台与卷边透气窗帘；
  - 主楼正门前方设有木结构担架分诊雨棚；院内停放一辆二战经典帆布篷顶军用救护急救卡车（车厢侧壁喷有白圈红十字）；
  - 庭院整齐码放医疗物资木箱与便携折叠担架架。
- **视觉辨识度**：兼具永久性医疗中枢的威严与野战前沿救护的动态感，红十字屋顶与急救白帐篷双重强化“野战医院”特征，在所有尺寸下辨识度均居第一。

### 方案二：回字庭院式野战疗养院 (`option-2-courtyard-infirmary`)
- **核心构成**：
  - 采用低矮舒展的 U 型 / 回字形单层石膏与石灰石病房院落，四周环绕遮阳木质回廊；
  - 中央露天绿地平铺着一块巨大的空中防空识别白底红十字帆布（二战战地救护所防止敌机误炸的标准配置）；
  - 入口前院设轻型担架落客廊道与医护旗杆，木制药箱与水桶整齐陈列。
- **视觉辨识度**：庄严静谧，中央大红十字在空中俯视角度极具冲击力，侧重体现后方伤兵休养康复所的秩序感。

### 方案三：战地应急手术营地与十字帐篷集群 (`option-3-field-trauma-station`)
- **核心构成**：
  - 一座具备加固石砌防破片结构的战地手术室（带八角形采光通风穹顶与红十字坡顶）；
  - 两座高大的人字形大型战地医疗帐篷呈八字形拱卫，帐顶刷有巨大的红十字标识；
  - 建筑与帐篷间以防泥泞木栈道相连，前院配置应急发电机组、氧气钢瓶架、野战手术折叠担架床及救护吉普车。
- **视觉辨识度**：极富战火前线紧迫救护氛围，帆布与石体硬朗交织。
