# 登录页背景设计：雨林炮火 · 战场微缩模型

日期：2026-09-27
状态：第4轮（V4 步兵移至两侧·正面航路清空）主图已完成并就绪，保存在 `output/imagegen/login-battlefield-diorama-20260927.png`（及 `.jpg`），已完全移除坦克正前方阻碍推进的士兵，完整还原左侧履带与前方泥泞车辙，步兵全员分布于坦克左右两翼进行伴随掩护，空地协同与冲锋方向严谨统一。

## 画面目标

为「山河远征录」登录页制作一张完整的、具有摄影质感的二战缅甸山地雨林战场微缩模型图。第一眼能看到炮弹爆炸和浓烟，第二眼能辨认模型的手工涂装、湿泥、树叶和装备细节。山峦与雨林必须清晰存在，不能再次退化成纯色山形、卡通树冠或简单剪影。

本图是以二战缅甸战场为题材的艺术化微缩场景，不宣称复原某一场具体战役。

## 内容与层次

| 层次 | 必须呈现 | 视觉作用 |
| --- | --- | --- |
| 空中战况 | 低云与滚滚烟柱之间，二战战斗机与双发轰炸机**均朝向正前方山谷低空呼啸俯冲**，投弹扫射 | 与地面部队行进方向完全一致，形成压迫感极强的空地一体协同大攻势 |
| 远景 | 多层覆有植被的山脊、低云、穿过山谷的灰白烟雾 | 让山地雨林环境明确可辨，并建立纵深 |
| 中景 | 连续密林、竹丛、受炮击折断的树木；三至四处距离不同的落弹点 | 表达持续炮击，让战斗分布在整片地形中 |
| 主爆点 | 中右侧一处明亮橙黄色爆炸，周围湿泥飞溅、细碎残枝；上方升起厚重黑灰烟柱 | 成为画面第一视觉焦点；火光映亮周围湿叶和泥地 |
| 次爆点 | 更远处一至两处较小的火光与土柱；右侧林缘局部可见炮口闪光 | 建立远近关系，避免多个爆炸机械重复或尺寸相同 |
| 近景 | 低矮灌木、蕨类、泥泞车辙、积水弹坑、被烟尘遮蔽的补给小道 | 体现潮湿、难以通行的战场环境 |
| 军事模型 | 坦克向正前方隆隆推进，**坦克两侧士兵全员朝同一个前方方向压低重心边冲锋边射击，枪口喷吐火光与硝烟，形成步坦协同大突进**；部分士兵低姿掩护换弹 | 战意昂扬、高度统一的步坦协同突击战术，所有单位朝向一致，气势恢宏 |

保留大量未被烧毁的植被。炮火猛烈，但不能把整个场景画成光秃废墟或一片纯火海；烟雾需要浓淡、距离和形态变化，不能完全遮住山地与树木。无需血腥伤亡细节。

## 微缩模型风格

- 以精细的 1:35 比例军事沙盘摄影为质感目标，树脂模型、涂装旧化、泥土颗粒与手工植被可辨。
- 摄影机略高于模型地面，以斜向视角看入山谷；局部细节有近大远小的自然变化。
- 以中等偏深的景深保留战场信息，仅远处山谷和最靠近镜头的边角轻微虚化。
- 装甲涂装有擦痕、泥渍和雨湿反光，衣料与沙袋有细微纹理；杜绝玩具般的油亮塑料。
- 不露出沙盘底座、桌面、展柜或人手。微缩感由材质、制作细节和摄影体现。

## 色彩与光照

底色为湿润橄榄绿、泥土褐和烟灰色。阴雨天漫射光保留树林细节；炮火使用集中的暖白、琥珀与橙红色高光。火光可映在湿泥和水坑上，但不把整图染成橙色。避免黑色区域大面积丢失细节，也避免阳光明媚的旅游风景感。

## 登录页构图与裁切

先制作 1536 × 1536 的无字方形主图，以兼顾桌面接近方形或偏高的主视觉区与手机较宽的横向主视觉区。以下坐标为构图指引，不作为生成结果精确定位的保证。

| 区域 | 构图指引 |
| --- | --- |
| 左中部约 45% 宽度 | 保留偏暗、低对比但有林木和烟雾纹理的区域，供现有米白色标题和说明文字覆盖 |
| 右中部，约 30%–65% 高度 | 安排主爆炸与主要烟柱；使横向裁切后仍然能看出炮火连天 |
| 中上部 | 保留起伏山脊，烟雾之间仍可见林线，避免全是空白天空 |
| 中下部至右下部 | 安排坦克、步兵和车辙；人物与装备不能承担背景是否成立的唯一识别任务 |
| 四周边缘 | 作为可裁切延伸区，不放唯一的爆点或关键装备；不用硬边框或装饰线框 |

生成后按现有桌面、手机竖屏和手机横屏三种布局检查裁切。若同一张主图无法兼顾，优先调整背景位置；仍不理想时，再基于选定主图制作一张手机宽幅衍生图，保持相同战场、色调与模型风格。首轮只生成一张主图。
