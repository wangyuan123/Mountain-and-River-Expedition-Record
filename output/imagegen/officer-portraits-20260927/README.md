# 军校名将池：虚构军官微缩头像

状态：**设计与提示词已完成；图片尚未生成，游戏页面尚未接入。**

军校当前名将池有 36 个姓名。`briefs.json` 为每个姓名指定一个独立的虚构角色美术方案，顺序与 `frontend/js/data.js` 的 `officerNames` 一致。姓名只用于游戏内资源映射，**不会传入生图提示词**；提示词也明确排除真人、历史人物面部相似性与历史照片参考。每款在面型、年龄、头饰、服装、角度或色彩上有区别，统一为暗色六边形背景、写实比例的 3D 游戏微缩模型半身像。

这些图是架空角色艺术，不表示真实人物的面容或真实军服复原。名将池中有非二战将领或非军人（如梁思成、施瓦茨科普夫）；其方案仅按游戏设定设计虚构角色，不主张他们在相应年代或岗位任职。德军题材角色不使用政治标志。

`scripts/assets/build-officer-portrait-prompts.mjs` 将设计表与名将池逐项校验，生成 36 份独立 `.prompt.txt` 和 CLI 批处理输入 `batch.jsonl`，不调用生图服务。最终目标为 36 张 `1024×1024` 原稿和 `384×384` WebP 游戏资源，分别命名 `officer-01` 至 `officer-36`。生成后逐张检查，尤其检查有无真实人物相貌、角色重复、失真头饰与文字/徽章；未通过的单张重新生成。

`scripts/assets/prepare-officer-portraits.py` 会先确认 36 张原稿全部存在且尺寸合格，再导出游戏 WebP 和 6×6 验收总览；不会把不完整批次接入游戏。

预定的详情页映射将读取名将原始生平前缀，改名后仍保持同一头像；普通军官保留现有的星级通用头像。加载失败时也回退到通用头像。

## 当前阻塞

本机官方 Image API 域名不可达。现有游戏头像曾使用 `https://handai-code.hand-china.com/v1`，该域名可达，但自动审批拒绝了把 `/private/tmp/shanhe-imagegen.env` 内的本地密钥发送至该目标，理由是用户尚未明确授权该目标域名接收此密钥。不能绕过该拒绝。需要用户在检查本方案后明确授权该域名与该密钥的组合，才可继续调用该接口。
