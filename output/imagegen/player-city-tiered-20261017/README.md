## 二、 视角与尺寸规范（严密保持对齐）

1. **同源等距视角**：统一采用 35°~40° 俯视 3/4 等距视角，正方形地基，正南面横向城墙对齐大地图网格。
2. **地坪基座 0 像素偏移**：
   - 资产画布尺寸：`992 × 1024`（大地图规范无缝尺寸）；
   - 底端接地线：**严格统一锚定于 `y = 970`（`y = 971`）**；
   - 地坪模型宽度：**严格锁定为 `944 px`，水平居中（`x = [24, 967]`，中心 `x = 495.5 ~ 496`）**；
   - 效果保障：玩家在大地图中从 1 级一路升级到 10 级满级，地基底座稳如磐石、绝无半个像素抖动，城防与建筑天际线纵向拔地而起。
