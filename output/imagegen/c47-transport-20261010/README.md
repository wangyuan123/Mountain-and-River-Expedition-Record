# C-47 空中列车运输机写实微缩模型资源归档 (2026-10-10)

## 背景与问题诊断
在部队总览/兵种一览界面中，原运输机（`transport`）的模型图与轰炸机（`bomber`，B-17G 空中堡垒）在角度、橄榄绿单色涂装、机身与翼型轮廓上高度雷同。在游戏内 48px~64px 缩略图下，玩家无法快速区分两者。

## 重新设计方案
1. **采用历史最经典的空投部队专属涂装**：
   - 诺曼底登陆 D-Day 盟军空投部队专属高反差**黑白侵略条纹（Invasion Stripes / 斑马纹）**包裹机翼与后机身；
   - 即使在远距离与微小缩略图（48px/64px）下，强烈的黑白对比斑马纹也能让玩家一眼辨认出是空投/空运部队，与纯军绿色的重型轰炸机彻底拉开视觉差距。
2. **专属运输机机械与结构特征**：
   - 侧面清晰可见敞开的**空投跳伞货舱门（Open Paratrooper Jump Door）**；
   - 钝圆流线型货运机头与平滑机腹，无任何机枪炮塔或投弹舱门；
   - 经典双发星型发动机与旋转螺旋桨动效，起落架完全收起呈飞行姿态。
3. **图像处理与规范化**：
   - 采用 GrabCut 分割配合外轮廓连通闭合，完整保留机身与机翼上的纯白色侵略条纹；
   - 边缘抗锯齿与去白底去杂色（de-matting），在深色界面下无毛边无白边；
   - 翼展尺寸规范对齐 368px（居中于 384x384 透明画布），与轰炸机和战斗机保持严格一致的视口基准。
