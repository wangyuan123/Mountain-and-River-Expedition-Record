# 侦查装甲车写实模型重绘规格

日期：2026-10-09。状态：模型已生成并处理完毕，已无缝替换现有模型并生成深浅背景多尺度验收图。

现有防空装甲车使用写实装备模型，此前侦查装甲车的程序绘制低模与其风格不一致。本次重绘以 `frontend/img/units/models/armored.webp` 为风格参考，制作了独立的 M8 灰狗写实模型。

- 统一俯视角度、左前方三分之四视角、美军经典橄榄绿涂装、金属和橡胶材质细节。
- 六轮三轴底盘、低矮斜面车体、单门 37mm 平射主炮塔、长无线电侦查天线；完全区分于防空车的双联高射炮。
- 原稿使用 1024×1024 方形白底，经过背景剔除与天线/边缘保护，输出为 384×384 透明 WebP（`frontend/img/units/models/recon_car.webp`）。
- 验收深浅背景以及 240px、72px、56px 的识别效果，炮管、六轮和天线完整且辨识度鲜明。
- 验收对比图：`preview-dark.jpg`、`preview-light.jpg`。
- 游戏内映射 `Game.UNIT_MODEL.recon_car` 已自动应用全新写实模型。
- 通用兵种图标 `Game.UNIT_ICON.recon_car` 同样使用此 WebP；旧低模 SVG 和程序生成脚本已删除。
