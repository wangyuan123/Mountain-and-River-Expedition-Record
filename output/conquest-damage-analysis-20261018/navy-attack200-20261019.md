# 仅海军基础攻击+100%试算

本次仅离线分析，正式数值及数据库未改。

四种海军（驱逐舰、潜艇、战列舰、航母）的对地、对空、对海、对工事基础攻击均乘2；其他兵种攻击及所有兵种防御、生命、速度和射程不变。双方同步应用。与此前“仅提高海军对海攻击”的方案范围不同。

使用当前源码重新编译，在隔离类路径运行44种场景，每场32个固定种子，共1,408场候选模拟。对照为同一入口的当前值结果。默认满科技、无军官/技能/装备和司令官加成、自动前进、无墙。以下均为NPC距离。

| 场景 | 当前值 | 仅海军攻击翻倍 |
| --- | --- | --- |
| 等量战列舰 | 35回合超时，双方各剩68.6% | 仍超时，双方各剩47.1% |
| 1.5倍战列舰进攻 | 超时，守方剩49.3% | 仍超时，守方剩5.8% |
| 2倍战列舰进攻 | 超时，守方剩30.1% | 第26回合全歼守方 |
| 1.5倍混编舰队进攻 | 第33—34回合胜 | 第19回合胜 |
| 等量混编舰队 | 超时，攻方剩31.2%、守方27.6% | 仍超时，攻方剩23.8%、守方11.3% |
| 1.5倍航母进攻 | 超时，守方剩23.8% | 第25回合胜 |
| 等加权造价轰炸机进攻战列舰 | 超时，战列舰剩31.4% | 第21回合轰炸机全灭，战列舰剩74.7% |
| 等加权造价战斗机进攻战列舰 | 第30回合全歼战列舰 | 35回合超时，双方各剩约24.1% |

等加权造价空军对战列舰：10,000艘战列舰，对比约33,708架轰炸机或55,556架战斗机。造价权重为钢铁+2×石油+4×稀矿，未计粮食、人口、时间与战后回收；这不是按每种资源均可支付的实际生产数量。

玩家距离下，1.5倍战列舰进攻仍超时、守方剩10.8%；2倍战列舰进攻第28回合清军。不包含城墙，因此不能当作玩家攻城胜利。

判断：它能加强海军，并避免此前降低血防带来的额外承伤。海军对空/对地/攻坚也一起增强，跨军种平衡影响比只提升对海攻击更广。特别是等加权造价轰炸机对战列舰，结局从超时转为轰炸机全灭。若只想改善海军内战，应单独评估对海攻击；若希望全面加强海军，这套方案符合方向，但仍不足以保证均势海战35回合内全歼。

最近战报的初始兵力场景只采用统一科技和军官假设，未准确重现原场景，不用于宣称历史战报换方案后的真实胜率。指定场景32次重复均一致，不代表真实玩家总体胜率或超时率。
