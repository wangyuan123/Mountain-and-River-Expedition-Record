## 当前可验证的结论

基础击毁效率有显著分化：防空和反装甲专项火力不低，大型舰艇的血防使海战伤害明显偏慢。不能据此建议全部兵种统一翻倍攻击。

静态条件：攻守数量相同；攻击、防御、生命、火力密度科技均10级；无军官、司令官、装备、贴脸和技能；目标均在射程内，攻击方使用完整一轮额度。数值是首轮期望击毁数占守方初始数量的比例，不是完整战斗模拟。后续减员、随机取整、机动和先手均会改变实战结果。

| 攻击组合 | 每轮期望击毁率 |
| --- | ---: |
| 火箭车 → 重坦（专项×3） | 20.28% |
| 防空装甲车 → 战斗机（专项×2.5） | 25.77% |
| 重坦 → 重坦（无贴脸） | 3.38% |
| 战列舰 → 战列舰 | 1.11% |
| 潜艇 → 战列舰 | 0.76% |
| 火箭车 → 战列舰 | 0.29% |

数量比较不能直接代表经济平衡。补充的等加权造价比较（钢铁+2×石油+4×稀矿，排除粮食、时间、人口及战后回收）显示，潜艇对战列舰每轮约3.26%、战斗机约4.81%、轰炸机约3.69%；仍需要计入射程和承伤，不能据此直接宣称某兵种无用。

计算：`单兵伤害 = 对应领域基础攻击 × 攻击科技 × 专项倍率 × 100/(100+5×有效防御) × 火力密度`；`击毁率 = 攻方数量×单兵伤害/(守方数量×有效生命)`。完整数值见 `static-diagnostics.json`。
