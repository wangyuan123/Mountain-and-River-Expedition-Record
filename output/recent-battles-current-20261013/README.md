# 最近两场战报按当前规则演示

2026-10-13 离线模拟。兵力直接读取战报 3682、3684，调用当前 `BattleService.resolveWorldRound`，每场景使用种子 0～31。共 16 组、512 场模拟。仅新增分析材料，没有改动游戏规则、数据库或历史战报，也未部署服务。

- 沿用此前核对重建的参数：双方攻击、防御、军队生命、武器射程和三类引擎科技均 10 级，守方城墙 10 级，司令官与配装加成均为零。这些科技及防御属性不是原始 JSON 中的完整历史科技快照；依据见 `../battle-analysis-20261012/README.md`。
- 原战报没有火力密度；主场景双方 0 级。双方 5/10 级、仅攻方 10 级是研发后的假设对照，不代表原账号已经拥有。
- 原始兵力没有城防武器，本次两场都没有额外加入工事；不添加已经取消的城防 +500 距离。
- 数量为战场减员和幸存数，不是永久死亡数，未计算战后伤兵、战地急救或俘虏回收。表内是 32 次均值四舍五入到整数；分项取整偶尔会与总数差 1。

## 当前距离与移速

两场当前初始距离都为 6,900 点，所有场景首次交火均为第 4 回合。

距离按当前真实存活组合计算：

`D = max(3 × (攻方步长 + 守方步长) + max(攻方射程, 守方射程)) + 100`

决定这两场距离的组合是攻方火箭车与守方侦察机：

`3 × (375 + 825) + 3,200 + 100 = 6,900`

侦察机默认待命，但其科技移速仍参与当前开局距离公式。提高速度也会提高开局距离，不能按历史固定距离简单推断接敌会提前多少回合。

## 原指令与自动推进对照

主展示按原战报逐回合机动指令；第一场全程前进。第二场火箭车第9～11回合待命，第12回合前进，第13～24回合待命；第15～22回合集火防空装甲车，第23～24回合集火重坦。第25～28回合继续最后指令：待命并集火重坦。其余单位沿用日志机动，后勤默认待命。

机动行为从原日志读取。指定集火在敌目标不存在时没有日志标记，因此第二场集火时间段沿用此前核对的复现参数，不把没有标记误判为取消指令。延长回合的指令是明确的模拟假设。

另外运行双方默认指令作为对照。这组当前参数下，自动推进与原指令的逐回合兵力均值完全一致；机动坐标和日志可能不同。原因是当前速度下火箭车已更早接近存活敌方前排，后续推进被阵线阻挡，而原先集火目标在相应回合已被击毁。不能将旧距离模拟中待命造成的损失幅度直接套用到本次结果。

## 结果意味着什么

- 当前速度和回合上限仍不能保证这两场全歼。双方0级时，第一场第24回合攻方剩余624,887、守方662,269；延长到38回合，攻方额外减员约149,994，只增加守方减员约12,190。第二场第24回合分别剩余597,086、615,905；延长4回合增加攻方减员约28,414、守方约7,119。
- 双方增伤会同步提高守军火力。第一场守将、兵种构成与前排承伤使攻军更早失去输出；双方10级时守军总损失反而低于双方5级，原因是攻军第31回合已全灭，输出提前停止。
- 第二场双方10级终局，攻方防空装甲车已全灭，重坦约150,523、火箭车300,000；守方仍有8类完全无损，合计511,550。不是每一类守军都被伤害低的问题拖慢。
- 终盘火箭车主要打高耐久战列舰，使用弱项对海攻击；前排仍在承伤，原地后勤距其超过有效射程。第一场双方0级火箭车末轮只击毁约442艘战列舰，第二场约297艘。更多回合和火力密度均不能独立消除索敌、混编阵线与全歼条件造成的阻塞。

## 复算与证据

- `results.json`：源文件SHA-256、参数、每回合均值/范围、每兵种幸存数、种子0坐标。
- `*-auto-*.log` / `*-historical-*.log`：各场景种子0完整日志。
- `run.log`：16组终局摘要。
- `visual-verification.json`：实际浏览器交互检查。
- `CurrentBattleReplay.java`：独立离线复现工具。

使用当前后端编译产物及其依赖运行，不调用游戏服务：

```sh
battle_replay_cp="/tmp/fire-density-maven-target/classes:$(cat /tmp/fire-density-classpath.txt)"
mkdir -p /tmp/current-battle-replay
javac -encoding UTF-8 -cp "$battle_replay_cp" -d /tmp/current-battle-replay output/recent-battles-current-20261013/CurrentBattleReplay.java
java -Xmx512m -Dfile.encoding=UTF-8 -cp "/tmp/current-battle-replay:$battle_replay_cp" CurrentBattleReplay "$PWD"
```

本次先以隔离Maven输出目录重新编译当前源码，避免使用过期引擎；规则版本保存在结果JSON中。若源码再变化，应先重编译后复算。
