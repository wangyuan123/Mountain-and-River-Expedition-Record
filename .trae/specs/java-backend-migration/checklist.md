# Checklist

## 阶段一：后端基础设施
- [ ] Spring Boot 项目可正常启动，监听 8080 端口
- [ ] PostgreSQL 数据库连接正常，Flyway 迁移脚本执行成功
- [ ] JPA 实体类与数据库表结构一致（16+ 张表）
- [ ] Repository 接口可正常执行 CRUD 操作
- [ ] JWT 认证可用：注册/登录返回 token，受保护端点需携带 token
- [ ] Spring Security 配置正确：公开路由（/api/auth/**）+ 受保护路由（/api/game/**）
- [ ] CORS 配置允许前端域名访问

## 阶段二：核心逻辑迁移
- [ ] GameData 静态数据与 JS data.js 完全一致（建筑/兵种/科技/城防/野地/军官技能）
- [ ] getGameState() 返回的 JSON 结构与前端原有 state 对象兼容
- [ ] 世界生成逻辑产出的寇城/玩家城池/野地/流寇数量与 JS genWorld 一致
- [ ] Tick 资源产出公式与 core.js tick 一致（建筑等级 × 产出系数 × 状态加成）
- [ ] Tick 粮食消耗公式一致（部队消耗 × 科技减免 × 时间）
- [ ] Tick 黄金税收公式一致（人口 × 税率 × 市长智力加成）
- [ ] Tick 军官忠诚度变化一致（闲置+0.5/h，任职-0.2/h）
- [ ] 离线 tick 补算上限为 8 小时
- [ ] 行军创建：部队校验、行军时间计算（距离 × marchSecPerGrid / 最慢速度）与 JS 一致
- [ ] 行军到达后按 targetKind 正确分发（bandit/npc/player/wild/wild_gather/scout）
- [ ] 野地征服：战斗胜利后标记 occupied = true
- [ ] 野地采集：到达->采集->返程->资源入库->tile.mined 更新
- [ ] 战斗结算：兵种属性、城防、技能加成计算与 battle.js 一致
- [ ] 战斗结果：部队损耗比例、资源掠夺量与 JS 一致
- [ ] 建造队列：升级/取消/完成检查逻辑正确
- [ ] 科技升级：前置条件校验、效果应用正确
- [ ] 军官系统：军校刷新、招募、任命、赏赐、技能学习逻辑正确
- [ ] 征兵：人口校验、资源扣除、时间计算正确
- [ ] 城防：修筑/拆除、围墙等级上限校验正确
- [ ] 世界地图：移动、扫描半径计算、附近城池/野地查询正确
- [ ] 宣战：三阶段（倒计时/交战中/结束）时间线与 JS 一致

## 阶段三：API 层
- [ ] GET /api/game/state 返回完整玩家状态
- [ ] 所有操作 API 返回更新后的状态或明确错误信息
- [ ] 资源不足时返回 400，状态不变
- [ ] 部队不足时返回 400，状态不变
- [ ] 建筑等级超限时返回 400
- [ ] 无效 targetIdx 时返回 400
- [ ] 未认证请求返回 401

## 阶段四：WebSocket
- [ ] WebSocket 连接需 JWT 认证
- [ ] tick 结果每 5 秒推送给在线玩家
- [ ] 行军到达时推送事件
- [ ] 采集完成时推送事件
- [ ] 被攻击时推送战报
- [ ] 断线后可自动重连

## 阶段五：前端重构
- [ ] 前端不再有 G.save() / G.load() 调用

- [ ] 前端行军倒计时基于后端时间戳展示
